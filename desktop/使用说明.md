# 材料报价桌面版

这是基于 GEstimator 工程清单和单价分析模型制作的中文 Windows 桌面软件。材料库、价格历史和工程文件都保存在本机。

## 启动

当前电脑：双击工作区 `desktop/启动桌面版.bat`，或发行目录中的 `启动应用.bat`，即可使用已安装的 Python 启动中文界面。

发行版另提供 `材料报价.exe` 与完整运行时。受限构建环境中新进程 DLL 初始化失败，exe 尚未完成独立启动验证，验证记录见 `VALIDATION.json`。移动到其他目录或电脑时，复制整个发行目录，包含 `app`、`runtime` 和 `data`，不要只复制 exe。

首次运行会从随软件附带的材料库快照创建 `data/materials.db`。它是现有本地网页版材料库的副本，之后两套材料库分别维护。保存的工程默认在 `data/projects`。备份时退出软件，复制整个 `data` 目录。

## 做第一份报价

1. 在“材料库与价格”选择地区，新增材料并录入单价。也可导入 Excel/CSV；模板按钮会导出填写示例。导入先预览，勾选后才会写入材料库。
2. 在“工程报价”填工程名称、客户、价格地区、报价日期。
3. 点击“从材料库添加”，搜索和选择材料。材料的名称、单位和最新地区价格会带入工程清单。找不到价格时单价为 0，需要自行填写。
4. 双击清单，填写工程量、单价和损耗率。可用“自定义清单”添加施工项目。
5. 填写另计人工费、运费、其他费用和报价税率。已经在单价分析里包含的人工及费用，不要重复填写。
6. “保存工程”生成 `.estimate.json` 工程文件；“导出 Excel”生成可发送给客户的报价工作簿。

## 单价分析

工程资源页维护本工程的材料、人工和机具价格；材料库页维护通用价格历史。

选中一条工程清单，点击“单价分析”：

- “添加资源”从当前工程资源选择材料、人工和机具。“新建资源”可同时创建并加入分析。
- 双击资源行，填写**每 1 单位清单**所需的资源消耗量。例如 1 吨水泥需要 0.1 工日搬运人工，人工用量填 0.1，而不是整个工程的总工日。
- 资源分析用单价 = 基础单价 ×（1 + 资源税率 / 100）×（1 - 折扣率 / 100），按分舍入。资源单价已含税时，资源税率填 0。负税率调整用于把原有含税价折算成基价。
- 支持资源分组、小计、附加比例、乘数系数和舍入。与原 GEstimator 一样，附加比例以最近的资源分组或“小计”为基数；需要按全部累计金额计取费用时，先添加“小计”。
- 调整计算行的顺序后，请查看结果。“舍入”或“小计”通常应放在最后；新增附加费时应放在最终合计之前。
- “应用分析”保存分析内容，同时更新当前清单单价。

工程资源改价后，选中需要重新计价的清单，点击“更新单价”。材料库的最新价不会自动修改工程资源；可在工程资源里编辑价格，直接材料清单则可以通过“更新单价”从材料库取最新价。

## 工程量明细

选中清单，点击“工程量明细”，新增部位记录：

工程量 = 件数 × 长 × 宽 × 高 × 系数。

不需要的维度填 1，扣减部位的系数可填负数。点击“应用并更新工程量”后，明细之和写入清单工程量。

## 价格更新与报价快照

报价使用“指定地区 → 全国 → 其他地区”的取价顺序，导出时保留价格地区、日期和来源。

保存的工程保留当时的单价。更新材料库不会改变已发给客户的报价。需要新价格时，选择对应清单并点击“更新单价”。

材料库页面可手动检查国家统计局最新旬价，也可启用自动检查；软件打开时后台检查，之后每 6 小时再检查。联网失败会显示状态，材料维护和报价仍可正常使用。国家统计局价格是全国基准价；本地造价信息价可通过 Excel/CSV 导入。

## 导入 GEstimator 文件

“文件 → 导入 GEstimator .eproj”读取工程或定额库中的资源、清单、已有单价和单价分析，不改写原文件。导入后请另存为 `.estimate.json`。

自带 DSR 数据是印度定额，可能含 GST 等当地费用。用于国内项目前，应修改材料和人工价格、分析附加费及报价税率。导入工程的报价税率默认设为 0，防止与原分析中的 GST 重复计税。

本版提供常用尺寸工程量计算。原 GEstimator 自定义测量模板的原始数据会随导入工程保留，但不在本版执行；可以保持原数量，或重新录入本版工程量明细。当前工程文件不反向导出 `.eproj`。

## Excel 导出

工作簿包含：报价单、工程资源、单价分析、工程量明细、价格来源。报价单按清单的单价快照导出；单价分析表同时显示保存的单价与当前资源价格计算的单价，以便核对。

每条清单金额按分舍入后相加，再计算税额。人工费、运费和其他费用也按分舍入，金额采用十进制运算。
