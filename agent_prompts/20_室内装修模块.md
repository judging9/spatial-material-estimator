# 提示词 20：室内装修模块（精装）

> 用法：先贴 `00_共享上下文.md` 全文，再贴本文件。依赖 `05_造价平台骨架.md`。与土建模块互不依赖，可并行开发。

## 任务

利用现有的房间（`project.regions`）、墙（`walls`）和门窗开口（`openings`），一键生成**装修做法 + 工程量 + 造价表**。用户只需给每个房间选一个空间类型、选一个装修档次，点「生成」。

核心难点不是算面积，是**做法分层不重复计价**：找平、防水、粘结层、面层、踢脚线是五项，不是一项。

## 一、用户看到的三步

1. 「造价」→「装饰装修」页签：列出所有房间，每行一个下拉框（客厅/卧室/餐厅/厨房/卫生间/阳台/过道/书房），默认按房间名猜，猜不出默认"卧室"。
2. 顶部选档次：简装 / 中档 / 精装（一键套用到全部房间，也可单房间改）。
3. 点「生成装修造价」→ 得到按房间分组的清单，可展开看每个房间的地面/墙面/天棚/门窗/水电明细。

再加一个「一键精装」按钮：跳过确认，直接用默认空间类型 + 中档，一次生成（给不想点的用户）。

## 二、数据模型（`project.cost.modules.finish`）

```ts
type FinishGrade = 'basic' | 'standard' | 'high';
type SpaceType = 'living' | 'bedroom' | 'dining' | 'kitchen' | 'bath' | 'balcony' | 'corridor' | 'study';

type FinishRoom = {
  regionId: string;
  spaceType: SpaceType;
  netArea: number;      // m²，来自 regionMetrics
  perimeter: number;    // m
  wallArea: number;     // m²，扣门窗后的净墙面
  doorWidth: number;    // m，门洞总宽，用于扣踢脚线
  windowArea: number;   // m²
  wet: boolean;         // 是否湿区（厨房/卫生间/阳台）
};

type FinishConfig = { grade: FinishGrade; rooms: FinishRoom[] };
```

工程量全部由 `lib/geometry.ts` 的 `regionMetrics` 与 `lib/wall-solid.ts` 的墙面指标得出，**不要自己再算一遍多边形面积**（会和对不上）。

## 三、做法包（这是本模块的核心资产）

做法包 = 一个空间类型 × 一个档次 → 一组有序工序，每道工序是一条清单项。结构：

```ts
type Layer = {
  code: string;        // 清单编码
  name: string;        // 工序名，如"20 厚 1:3 水泥砂浆找平"
  unit: string;        // m² / m / 樘 / 个
  quantity: (room: FinishRoom) => number;
  price: { basic: number; standard: number; high: number };  // 参考单价
  includesBase: boolean;  // 是否已含基层处理，用于防重复
  note: string;
};
```

必须实现的工序（顺序即施工顺序）：

**地面**
1. 基层清理（并入找平，不单列）
2. 水泥砂浆找平 20mm —— `netArea`
3. 防水（仅湿区）—— `netArea + 0.3 × perimeter`（上翻 300mm）
4. 粘结层（瓷砖胶）—— `netArea`
5. 块料面层（地砖）—— `netArea × 1.03`（损耗 3%）
6. 踢脚线 —— `perimeter − doorWidth`，单位 m

**墙面**（净面积 = 墙面总面积 − 门窗洞 + 洞口侧壁，直接取 `wall-solid` 的裸露面指标）
1. 基层处理/界面剂 —— `wallArea`
2. 抹灰 15mm —— `wallArea`（瓷砖墙面也要抹灰，不能省）
3. 腻子两遍 —— `wallArea`（仅涂料/壁纸面层）
4. 涂料/壁纸/瓷砖 —— 按档次：简装乳胶漆、中档乳胶漆/局部壁纸、精装壁纸或瓷砖
   - 湿区墙面到 2.4m 高贴砖，其余涂料；瓷砖面积 = `perimeter × 2.4 − 门窗洞`

**天棚**
1. 基层处理 —— `netArea`
2. 吊顶龙骨 —— `netArea`（简装可取消吊顶）
3. 吊顶面板 —— `netArea × 1.05`
4. 跌级/灯槽 —— `0.3 × perimeter`（m），仅中档以上

**门窗**（从 `openings` 统计，按樘）
1. 门/窗本体 —— 樘数
2. 五金 —— 樘数
3. 安装 —— 樘数

**水电**（全部标「初步估算」）
1. 开关、插座、灯具 —— 按房间类型的点位系数（见下表），单位「个 / 套」
2. 配管 —— `netArea × 2.5` m（照明+插座综合），标估算
3. 配线 —— 配管 × 3
4. 给水管 —— 湿区 `15` m/间
5. 排水管 —— 湿区 `8` m/间

点位系数（写进代码常量表，可调）：

## 五、防重复计价的硬规则

1. 块料面层**不含**找平，找平单列；块料面层 `note` 写"不含找平层"。
2. 瓷砖墙面**不含**抹灰，抹灰单列；`note` 写"不含基层抹灰"。
3. 吊顶**不含**灯具安装与开孔，电气单列。
4. 防水**只算湿区**，上翻高度写进 `feature`。
5. 门**不含**门套，门套另列（精装档次才加）。
6. 每行 `feature` 必须写清规格（如"300×600 瓷砖，水泥砂浆找平 20mm"），否则后期无法核对。

## 六、单价

- 优先用材料库里的材料价（`lib/materials.ts`，含 `provenance` 的日期与来源）。
- 没有材料价时用档次参考区间，并在 `note` 标"参考值"。
- 档次差异体现在：面层材料品牌档次、是否吊顶、是否壁纸、五金等级；**工程量不因档次变化**。

## 七、界面

- 房间列表支持"批量设置类型"（多选 + 一次改）。
- 每个房间可展开明细，显示：净面积、周长、墙面净面积、湿区、门窗樘数。
- 顶部显示汇总：房间数、总净面积、总估算金额、估算项数量。
- 「一键精装」按钮放在页签右上角。

## 八、测试

`tests/finish.test.mjs`：

1. 4×3 房间，周长 14，门宽 0.9 → 踢脚线 13.1 m。
2. 卫生间 2×2，周长 8 → 防水 `4 + 0.3×8 = 6.4` m²。
3. 墙面净面积扣门窗洞后不为负；无门窗时不报错。
4. 档次从简装切到精装：工程量完全不变，单价变，合价变。
5. 空项目（0 房间）→ 返回空数组，汇总为 0。
6. 同一项目连续生成两次结果一致。

## 九、边界（写进 docs）

不做：家具、软装、家电、定制柜体内部结构、异形吊顶造型、地暖、中央空调、智能家居、幕墙。水电为**初步估算**（按面积与点位），不是管线综合算量；要精确必须导入机电图纸另行计算。不处理斜墙、弧墙。
