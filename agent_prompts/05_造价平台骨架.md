# 提示词 05：造价平台骨架（先跑这一个）

> 用法：把 `00_共享上下文.md` 全文贴在最前面，再贴本文件。这个提示词必须最先执行，后面三个模块都依赖它建好的契约。

## 任务

给现有软件加一层"造价"基础设施：一个统一的分部分项清单数据结构、一个全屏造价工作台、一套汇总与导出。**本步不实现任何算量**，只搭骨架和一张空表，三个专业模块之后各自往里填数据。

## 为什么要先做这个

三个模块（土建/装修/市政）都要出造价表。如果各写各的表格、各算各的税，最后合并时会重号、重复计税、单位不一致。所以先定契约：一张 `CostItem` 表 + 一个汇总函数 + 一种导出格式。

## 一、新建 `static/studio/lib/cost.ts`

```ts
export type CostSection = '土建' | '装饰装修' | '市政';
export type CostCategory = '分部分项' | '措施项目' | '其他项目' | '规费税金';

export type CostItem = {
  id: string;
  section: CostSection;
  category: CostCategory;
  code: string;        // 项目编码，如 010502001001（12 位，后 3 位为顺序码）
  name: string;        // 项目名称，如"现浇混凝土矩形柱"
  feature: string;     // 项目特征，如"C30，截面 400×400，高 3.0m"
  unit: string;        // m³ / m² / m / t / 座 / 套 / 樘 / 株 / 项
  quantity: string;    // 工程量，十进制字符串
  unitPrice: string;   // 综合单价（元），含材料+人工
  wasteRate?: string;  // 损耗率（%），仅材料类
  amount: string;      // 合价（元）
  estimate: boolean;   // true = 指标估算，界面必须标注
  note: string;        // 计算依据 / 来源 / 限制
  source: 'generated' | 'manual';
};
```

要求：

1. `amount` 由 `quantity × unitPrice` 得出，**必须用 BigInt 定点**。在 `lib/pricing.ts` 里补两个导出：`multiplyDecimal(a, b)`、`addDecimal(a, b)`（复用文件内已有的 `multiply` / `add` / `decimal`，不要改现有逻辑），`cost.ts` 只调这两个。
2. 提供 `createCostItem(input): CostItem`，负责校验（单位必须在白名单、数量与单价必须非负、编码必须 12 位数字）。
3. 提供 `summarize(items, { measureRate, taxRate })`，返回：

```ts
{
  bySection: { 土建: string; 装饰装修: string; 市政: string },  // 各专业合计
  byCategory: { 分部分项: string; 措施项目: string; 其他项目: string },
  subtotal: string,     // 分部分项合计
  measures: string,     // 措施项目 = 分部分项 × measureRate%
  other: string,
  beforeTax: string,    // subtotal + measures + other
  taxRate: string,
  tax: string,          // beforeTax × taxRate%
  total: string,
  estimateCount: number // 估算项数量，用于界面提示
}
```

4. 提供 `validateItems(items)`：重复编码、空单位、负数、金额与数量×单价不一致（允许 1 分误差）都要能报出来，返回 `{ ok, errors: string[] }`。

## 二、新建 `static/studio/cost-workbench.ts`

一个全屏覆盖层（不是新页面），结构：

```
┌ 造价工作台 ───────────────────────────────  [导出 CSV] [打印] [返回] ┐
│ 页签： 汇总 | 土建 | 装饰装修 | 市政                                  │
├──────────────────────────────────────────────────────────────────────┤
│ 内容区（由各模块渲染；未生成时显示空态 + 「生成」按钮）                  │
└──────────────────────────────────────────────────────────────────────┘
```

要点：

- 导出 `openCostWorkbench(project, {...})` 和 `closeCostWorkbench()`。
- 模块注册机制：

```ts
export type CostModule = {
  id: 'structure' | 'finish' | 'municipal';
  section: CostSection;
  title: string;
  /** 生成/刷新该专业的清单项，纯函数，不碰 DOM */
  calculate(project: Project): CostItem[];
  /** 渲染该页签内容到 host 元素；ctx 提供 getProject/updateProject/toast */
  render(host: HTMLElement, ctx: CostContext): void;
};
export function registerCostModule(module: CostModule): void;
```

- 未注册模块的页签显示"本专业尚未接入"，不能报错。
- 汇总页：三个专业的合计 + 措施费/税前/税金/总价 + "含 N 项估算"的黄色提示条。
- 所有金额用 `formatMoney` 显示，右对齐，等宽字体。
- 表格列：序号 / 项目编码 / 项目名称 / 项目特征 / 单位 / 工程量 / 综合单价 / 合价 / 备注。
- 估算行在备注列前加「估算」小标签，打印时也保留。

## 三、接入现有界面

1. `static/studio/index.html`：顶部 `nav.top-actions` 里加一个按钮 `<button id="open-cost" class="button subtle">造价</button>`；页面底部加 `<section id="cost-view" class="cost-view" hidden></section>`。
2. `static/studio/app.ts`：绑定点击 → `openCostWorkbench(project, { onClose, onChange })`；`onChange` 里把结果写回 `project.cost.lastResult`（可选，见下）并触发保存。按 Esc 关闭。打开期间不销毁画布状态。
3. `static/studio/studio.css`：新增 `.cost-view` 样式（全屏 `position:fixed; inset:0; z-index:50; background:#fff`），表格样式与现有 `.quote` 表保持一致。
4. 项目模型：在 `Project` 上加可选字段

```ts
cost?: {
  rates?: { measureRate: string; taxRate: string };   // 默认 2.5% / 9%
  modules?: Record<string, unknown>;                   // 各模块自己的参数与结果快照
  updatedAt?: string;
};
```

`lib/persistence.ts` 的 `validateProject` 要放行该字段；旧项目没有它也能正常打开。

## 四、导出

新建 `static/studio/lib/cost-export.ts`：

- `costToCSV(items, summary, meta)`：列顺序固定为
  `序号,专业,项目编码,项目名称,项目特征,计量单位,工程量,综合单价(元),合价(元),是否估算,备注`
  末尾追加 4 行汇总：`分部分项合计 / 措施项目合计 / 税金 / 含税总价`。
  沿用 `lib/export.ts` 的 `csvCell` 与 `\uFEFF` BOM、CRLF。
- `downloadCostCSV(...)`、`printCostReport(...)`：打印页包含项目名、日期、三专业分组合计、页脚"本表为方案估算，最终以施工图预算/结算为准"。

## 五、默认费率

- 措施项目费 = 分部分项 × 2.5%（安全文明施工等，可在汇总页改）。
- 税金 = 税前 × 9%（一般计税，可在汇总页改）。
- 两个费率都要能改，改完立即重算，并随项目保存。

## 六、测试

新建 `tests/cost.test.mjs`（`node --test` 风格，import 编译后的 `build/studio/lib/cost.js`）：

1. 正常项：10 m³ × 500 元 = 5000.00。
2. 小数：0.333 m³ × 1234.56 元，四舍五入到分。
3. 空表：全 0，total 为 "0.00"，不能抛异常。
4. 税率：10000 → 税 900.00 → 总价 10900.00。
5. 非法：负数量、空单位、13 位编码、金额不符，都要报错。
6. 分组：三个专业混合后 `bySection` 正确。
