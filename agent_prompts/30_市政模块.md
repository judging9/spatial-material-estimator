# 提示词 30：市政模块（道路 / 管网 / 路灯 / 绿化 / 桥梁）

> 用法：先贴 `00_共享上下文.md` 全文，再贴本文件。依赖 `05_造价平台骨架.md`。与土建、装修互不依赖，可并行开发。

## 任务

市政工程没有"户型"，是**线性工程**。做法：在画布上画一条中心线（或直接输入长度），填横断面参数，一键生成沿线工程量与造价表。

覆盖：道路结构层、雨水/污水管网、检查井、沟槽土方、人行道铺装、路缘石、路灯、绿化、桥梁（仅指标估算）。

## 一、用户看到的三步

1. 「造价」→「市政」页签 → 点「新建道路」→ 在画布上点两下画中心线（复用现有 `canvas.ts` 的画线工具），或直接输入长度（m）。
2. 一张横断面参数表，默认值已填好：
   - 道路等级：主干路 / 次干路 / 支路（影响默认宽度与结构层厚度）
   - 红线宽度：12 m（主干路 40 / 次干路 24 / 支路 12）
   - 车行道宽、人行道宽
   - 结构层：默认「4cm AC-13 + 6cm AC-20 + 20cm 水泥稳定碎石 + 20cm 级配碎石」
   - 管网：☑雨水 ☑污水，管径 DN600 / DN400，埋深 2.5m，检查井间距 50m
   - 路灯：☑，间距 30m，单侧/双侧
   - 绿化：☑，绿化带宽度 3m，乔木株距 6m
   - 桥梁：☐，跨径、桥宽（勾选后才出现，且标"仅指标估算"）
3. 点「生成市政造价」→ 按"道路 / 排水 / 电气 / 绿化 / 桥梁"分组出清单。

## 二、数据模型（`project.cost.modules.municipal`）

```ts
type MunicipalConfig = {
  road: {
    length: number;        // m，来自画的中心线或手输
    grade: 'arterial' | 'secondary' | 'branch';
    width: number;         // 红线宽 m
    carriageway: number;   // 车行道宽
    sidewalk: number;      // 单侧人行道宽
    layers: { name: string; thickness: number; unit: string }[];  // cm
  };
  drainage: { rain: boolean; sewer: boolean; diameterRain: number; diameterSewer: number; depth: number; manholeSpacing: number };
  lighting: { enabled: boolean; spacing: number; side: 'left' | 'right' | 'both'; height: number };
  greening: { enabled: boolean; beltWidth: number; treeSpacing: number };
  bridge: { enabled: boolean; span: number; width: number };
};
```

## 三、算量规则

设 `L` = 道路长度（m），`W` = 车行道宽，`Ws` = 单侧人行道宽，`t` = 结构层厚度（m）。

**道路**

| 分项 | 公式 | 单位 |
| --- | --- | --- |
| 路床（槽）整形 | `L × (W + 2Ws)` | m² |
| 垫层/基层/面层 | 各类 `L × (W + 2Ws) × t` | m³ |
| 沥青面层（按吨） | `面积 × t × 2.4` | t |
| 人行道块料铺设 | `L × 2Ws` | m² |
| 路缘石 | `2 × L`（两侧） | m |
| 路基挖方 | `L × (W+2Ws) × 0.3`（按平均 30cm 清表） | m³ |
| 路基填方 | 同上 × 0.8（估算系数） | m³ |

**排水**

| 分项 | 公式 | 单位 |
| --- | --- | --- |
| 管道铺设 | `L`（按管径分列） | m |
| 检查井 | `⌈L / 间距⌉ + 1` | 座 |
| 管道基础 | `L × (D + 0.4) × 0.1` | m³ |
| 沟槽开挖 | `L × (D + 0.6) × (埋深 + 0.2) × 1.15`（放坡与超挖系数） | m³ |
| 沟槽回填 | `开挖 − 管道体积 − 井体积` | m³ |
| 余方弃置 | `开挖 − 回填` | m³ |

**路灯**

| 分项 | 公式 | 单位 |
| --- | --- | --- |
| 灯杆（含灯具） | `⌈L / 间距⌉ + 1`，双侧 ×2 | 套 |
| 电缆 | `L × 1.1 × (双侧 ? 2 : 1)` | m |
| 手孔井 | 灯杆数 | 座 |

**绿化**

| 分项 | 公式 | 单位 |
| --- | --- | --- |
| 乔木 | `⌈绿化面积 / 株距²⌉` | 株 |
| 灌木/色带 | `绿化面积 × 0.3` | m² |
| 草坪 | `绿化面积 × 0.7` | m² |
| 种植土 | `绿化面积 × 0.3` | m³ |

**桥梁（仅指标）**

| 分项 | 公式 | 单位 |
| --- | --- | --- |
| 桥面面积 | `跨度 × 桥宽` | m² |
| 综合造价 | `桥面面积 × 指标单价`（3000–6000 元/m²，按跨径分档） | 元 |

桥梁必须在页面上写："按桥面面积综合指标估算，不含征地拆迁、管线迁改、交通导改，误差可达 ±40%，仅用于投资匡算。"

**措施项目（市政特有，别漏）**

- 施工围挡：`2L` m（或按实际封闭长度）
- 交通导行：`L` m 或按「项」计
- 临时排水：按 `L` 计

## 五、界面

- 画中心线复用 `canvas.ts` 现有工具，画完自动回填长度，允许手改。
- 参数表按「道路 / 排水 / 电气 / 绿化 / 桥梁」五个折叠分组，默认只展开道路。
- 生成后显示一张**横断面示意图**（内联 SVG：路缘石、车行道、人行道、结构层分层色块，标厚度）。
- 沿线工程量用一个简单的"里程桩号表"呈现（每 100m 一段），让别人能核对。
- 桥梁分组默认折叠，勾选才出现，且整组标黄色"估算"。

## 六、单价

同土建：参考区间 + 可编辑 + 标注"参考值"。市政材料（沥青、水泥稳定碎石、管材、灯杆、苗木）默认单价必须写进 `note` 为"参考值，需按当地信息价/苗木市场价替换"。

## 七、测试

`tests/municipal.test.mjs`：

1. L=1000、W=12、无人行道：路床 12000 m²。
2. 4cm 沥青面层：`1000×12×0.04 = 480 m³`，按吨 `×2.4 = 1152 t`。
3. 检查井：1000m / 50m = 20 跨 → 21 座（两端各一）。
4. 路灯：1000/30 → 35 套（单侧）。
5. 沟槽开挖随管径与埋深单调递增；L=0 时全部为 0 且不抛异常。
6. 桥梁未勾选时，清单里不能出现桥梁项。

## 八、边界（写进 docs）

不做：纵断面设计、土方平衡调配、管网水力计算、管径选型、桥梁结构计算、交通组织设计、征地拆迁、管线迁改、地铁与隧道。桥梁只做指标匡算。所有量都是**方案级估算**，不能直接用于招标控制价。
