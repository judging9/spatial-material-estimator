# 自然墙体连接、绘图边界与圆弧

本轮根据 `next_improvements.txt` 增加自然墙体连接、自定义绘图边界及圆 / 圆弧墙工具。运行入口仍为 `start-studio.bat` 或原 `启动.bat`；现有 Windows 1.2.0 ZIP 没有更新。

## 整理墙体连接

新建平面图默认使用「自然连接」。独立墙端采用平齐端面，L 接点使用偏移边界的实际交点进行斜接，T 接点的分支墙在贯通主墙的近侧边界收齐，不再通过每段加方形端帽造成外伸小块。锐角使用有限斜接，限制尖角长度；无法生成可靠轮廓的短墙或极端角度明确提示调整。

二维填充、三维实体、边界检查、净房间轮廓及墙面用量共同使用厘米坐标下的真实墙体占地。重叠实体只计并集的裸露面，已被裁掉的端部不再产生虚构面积。开孔若进入实际已裁掉的部分会拒绝。

此前保存的项目缺少 `wallJoinStyle` 时沿用原连接方式，保留原有用量。点击左侧「绘图设置 → 整理墙体」即可升级当前项目；中心线、单价及配置保留，真实面积和报价按新实体重新计算。该操作可按 `Ctrl+Z` 撤销。

在原连接项目中新增圆形或圆弧墙，也会统一启用自然连接，以保证曲线接点使用同一实体边界；现有用量会同步重算，整次操作可撤销。

## 定义绘图范围

点击左侧「绘图设置 → 绘图边界」，填写矩形的左侧位置、上侧位置、宽度和进深（m），点击「应用矩形边界」。也可以点击「手动画多边形」，逐点绘制不规则边界，点击首点或按 `Enter` 闭合，`Esc` 取消。

边界以柔和虚线显示，范围外淡化。墙体的完整厚度、连接处、曲线墙、施工区域与家具占地必须在边界内；不仅检查中心线或四个角点。凹多边形会检查穿越缺口的边段以及真实面积交集。

设置边界、画墙、生成曲线、修改尺寸或放置家具时，越界操作整次拒绝，不留下半条墙、部分曲线或错误报价。已有物体超出新边界时，原项目保持，需调整范围或物体；系统不会擅自删除它们。可以清除自定义边界，清除操作也支持撤销。

## 画圆形墙

1. 在「01 绘图」点击悬浮工具栏的圆形工具，或按 `C`。
2. 点击圆心，移动鼠标预览半径，再点击完成。
3. 圆形墙闭合后自动生成房间。左侧以一个圆形墙组显示，可点击后设置半径、圆心位置、墙高和墙厚。
4. 添加「整组墙面材料」为整圈配置材料、价格、损耗与人工。

选中圆形或圆弧墙后，按 `Delete` / `Backspace` 或点击属性面板「删除整组墙体」删除整组，撤销可恢复全部几何与价格。

## 画圆弧墙

1. 点击圆弧工具或按 `A`。
2. 依次点击起点、经过点、终点。三点决定实际圆和所经过的弧，支持大于半圈的弧。
3. 可继续用直墙连接圆弧端点，闭合后形成房间。
4. 左侧选择圆弧组，可编辑圆心、半径、起始角和转角。0° 向右，90° 向下；正转角顺时针、负转角逆时针。

需要精确输入时，在左侧点击「圆 / 圆弧」，填写尺寸后生成。共线三点、过小弧、越界或超出墙段预算时明确提示，不生成部分结果。装修阶段请先返回「01 绘图」再使用这些工具。

## 计算与保存口径

曲线采用确定性的墙段采样，每步不超过 5°、最大弦偏差不超过 0.5 cm。二维、三维和报价使用同一实际折线实体，面积不是直接用 π 或大语言模型估计；显示的半径是实际绘制参数。当前最多支持 200 段墙，生成时不降低精度来绕过预算。

曲线整组按实际裸露左右侧面计量，单侧范围与高亮同步。组的采购损耗、人工、手工数量、固定费用及税按原十进制报价规则计算，不重复乘墙段数。周长使用整组真实边界，共享的竖向接缝抵消；不会因为圆被分为数十段而产生数百米虚构施工边界。

墙体连接方式、边界、曲线参数、成员几何、材料快照与用户价格随项目保存，并支持 JSON 导入导出。CSV / 打印 PDF 按有报价的曲线整组列示。

目前圆与圆弧是参数曲线墙，不提供自由样条；曲线整组尚未提供跨段门窗编辑，门窗可在直墙上设置。后续源码已增加多楼层设计、Loft、楼梯、楼板洞和天花板，见 [多楼层使用说明](loft-and-furniture.md)。土建方案仍按当前层户型及原参数计算，要求正交户型或矩形方案。

## 模块与验收

`lib/wall-joins.ts` 管理真实平面占地，`lib/wall-solid.ts` 生成并集实体与开孔，`lib/wall-plan.ts` 按同一占地计算净房；`lib/drawing-shapes.ts` 生成参数曲线，`lib/plan-boundary.ts` 验证完整边界，`lib/wall-shapes.ts` 管理曲线分组，`lib/wall-shape-selection.ts` 抵消实际共边。UI 位于 `plan-tools.ts`、`canvas.ts` 和现有工作台。

新浏览器验收通过实际按钮、鼠标点击、表单、保存及导出操作验证。运行命令：

```powershell

npm.cmd run typecheck
npm.cmd test
npm.cmd run test:e2e:authoring
```
