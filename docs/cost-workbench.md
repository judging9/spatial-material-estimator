# 造价工作台操作与计算口径

顶部「造价」打开独立工作台，页签为汇总、土建、装饰装修和市政。「返回图纸」或 Esc 回到图纸；已经生成的专业参数和价格随项目保留。

## 从户型到总造价：五步走

1. **准备真实尺寸。** 从墙线绘图开始，闭合后生成净房间；或上传图片 / PDF，先做比例校准再圈选房间。识别候选区域需人工核对。土建也可明确选择矩形外轮廓方案，市政可手输真实长度。
2. **生成土建。** 核对结构形式、层数、层高、基础和混凝土强度，点击「生成结构」检查参考柱网与算量口径，再点击「生成造价表」。按当前户型计算时，轮廓包含净房间与实际墙占地的并集；矩形方案输入外轮廓尺寸。
3. **配置装修。** 选择空间类型、全局或单房间档次，核对湿区、吊顶、灯槽、门套和建议水电点位，再点击「生成装修造价」。「一键精装」使用中档方案，保留空间类型；价格取实际配置或已选材料，缺价不自动补数。可批量设置房间类型并填写不同档次的真实工序报价。
4. **添加室外工程并定价。** 按需在市政中输入长度或画中心线、设置横断面和施工范围，再生成清单。逐行核对三专业规格、工程量、施工范围与综合单价，补齐待定价项。没有相关专业工程可以跳过。
5. **统一汇总和交付。** 在汇总页设置措施费率、其他项目 / 暂列金额和税率，保存项目，导出总表 CSV 或打印 / 保存 PDF。点击总表行可跳到对应专业，点击「含 N 项估算」可筛选估算行。

单价修改实时重算合价和总额；参数表修改后点击本专业生成才应用。生成的派生清单不加入撤销历史，价格确认和手工项修改加入历史。更换电脑前导出完整项目 JSON；造价参数与图纸、材料快照一同加载。

## 每行金额与费用公式

清单合价为 `工程量 × 本行单价`，采用十进制计算，每行按分舍入后再求和。材料采购行的工程量已经包含约定损耗，不再额外乘一次损耗；安装人工按净施工量计算。以地面为例，材料供应工程量为净面积 ×（1＋损耗率），铺装人工工程量为净面积。

| 变量 | 汇总口径 |
| --- | --- |
| S：分部分项合计 | 三专业所有「分部分项」行合价之和；各专业汇总栏也是这个分类的小计 |
| M：已列措施 | 分类为「措施项目」的模板、脚手架、运输、围挡等行合价之和 |
| R：费率措施 | S × 措施费率，默认 2.5%，可修改 |
| O：其他项目 | 「其他项目」清单合价之和＋汇总页填写的暂列金额，默认暂列金额为 0 |
| F：规费 | 清单中「规费税金」分类合价之和；当前不自动按地方规定另算规费 |
| B：税前合计 | S＋M＋R＋O＋F |
| T：统一税金 | B × 税率，默认 9%，可修改 |
| 含税总价 | B＋T |

软件先按分计算 R、B 和 T。例：S＝1000.00、M＝100.00、其他及规费为 0，措施费率 2.5%、税率 9%，则费率措施为 25.00、税前合计为 1125.00、税金为 101.25、含税合计为 1226.25。

专业清单中的显式措施不混入分部分项费率基数，也不在各模块各算一遍项目税。费率措施与已经列出的措施在汇总中分别展示；按实际合同口径调整费率，避免相同施工范围同时计入两者。项目规费清单应填写税前规费，不再次手工添加已经由统一税率计算的税金。

**造价总表不叠加画布底部原材料报价。** 原材料报价保留其材料、人工、损耗及附加费流程；装修模块可读取已选材料供应单价和人工单价形成对应清单，随后只在造价表计一次。原报价中的区域 / 项目附加费及税率不会自动搬入此总表，需要在造价工作台按施工范围单独核对。

## 价格状态与施工范围

| 状态 | 含义与处理 |
| --- | --- |
| 待定价 | 未提供可靠单价，以 0 占位。非零工程量的待定价项会使总额标题显示「已定价部分含税小计」 |
| 参考价 | 使用任务书区间中值、示例材料或材料供应参考价，备注保留依据，需确认适用性 |
| 已确认 | 用户编辑的本行报价，或模块接受的已配置真实报价。价格确认不改变工程量是否为估算 |

生成模块保留来源、日期和规格等已有材料信息。土建匹配到供货材料时，只在备注显示原料参考价，综合施工单价仍待填写；只有明确声明为未税综合施工报价的数据才可作为综合价参考。清单行编辑的价格覆盖优先，并随项目保存；同一清单重新生成后保留覆盖。材料库后续更新不会直接覆盖已保存清单单价，需重新取价并核对。

单价栏名为「综合单价」，实际计价范围以每行项目名称、特征和备注为准。比如「材料供应」行仅填供应价，「铺装人工」行仅填人工价；不得在供应价里再次包含已单列人工、找平或粘结层。门窗本体、五金和安装分列，门套可选；吊顶龙骨、面板、饰面与电气灯具分列。材料库单价不自动等于完整安装综合报价。

装修档次本身不改变净面积、周长或相同工序数量。档次差异使用用户提供的实际工序报价；吊顶、灯槽和门套由独立施工范围开关决定。软件没有可靠报价时保持待定价。

## 导出与保存

- **总表 CSV**：顶部「导出 CSV」导出全部专业及手工项，共 11 列：序号、专业、项目编码、项目名称、特征、单位、工程量、单价、合价、是否估算、备注。尾部列出分部分项、措施、其他、规费、税前、税金和含税汇总。文件名为 `项目名-造价表-YYYYMMDD.csv`，非法文件名字符自动替换。
- **本专业 CSV**：专业页「导出本专业」只导出该专业清单，按项目费率列出该专业参考费用，不重复带入全项目暂列金额。由于费用基数及按分舍入不同，各专业导出的含税数字不作为项目总价直接相加的依据，正式总价以汇总总表为准。
- **打印 / PDF**：顶部「打印 / PDF」打开按专业分组的 A4 纵向报告，表头可跨页重复；在浏览器打印中选择保存 PDF。报告保留估算、待定价、参考价和计量依据；页码由浏览器打印支持决定。
- **完整项目**：顶部保存与原工作台共用保存流程。返回图纸后可导出 / 导入项目 JSON，保留 `cost` 中的专业参数、单价覆盖、手工项、其他费用和费率。加载后重新生成清单金额，无造价字段的旧项目仍有效。

「手工项目」可补充核对后的施工项目，填写独立的 12 位编码、单位、工程量、单价、规格和依据；编码重复会提示。删除手工项和工作台级「清空本专业」有确认及撤销支持。模块内生成或清空的操作请先保存项目备份。

## 精度和实现边界

面积使用区域坐标、孔洞及真实比例，墙面使用实际实体表面和开口轮廓；画布缩放不改变工程量。仅上传图片且没有墙体模型时，装修墙面按输入高度与周长初估并标记。土建层数复制标准层地上工程量，基础和土方只计一次，不扩展当前单层三维模型或自动复制装修。

各专业通过 `registerCostModule()` 接入，共用 `CostItem`、`summarize()` 和导出服务。专业状态位于 `project.cost.modules`，不会改动原数据库结构；金额通过 BigInt 十进制模块按分计算，几何和工程量为可测试纯逻辑。工作台缓存各专业结果，市政参数或单价变化不重建装修房间模型。

钢筋、水电、桥梁及自动布局仍为指标或方案算量，不能替代施工图预算与招标控制价。全部专业的详细计算假设、未实现范围和价格依据见 [造价总览](cost.md) 中的模块文档。
