# 1.2.0 造价平台验收记录

日期：2026-11-07。沿用当前 TypeScript、Canvas 2D、WebGL 和 Python 架构，没有新增依赖，没有修改第三方源码包、用户数据库、图纸或历史发行包。

## 功能范围

- 统一造价工作台：汇总、土建、装饰装修、市政四页签；清单分组、估算筛选、明细跳转和高亮、改单价、撤销重做及手工补项。
- 土建：当前正交户型净区域与墙体占地并集，或明确指定矩形外轮廓；标准层柱网、基础、梁柱板、砌体、模板、钢筋指标及土方。基础和土方只计一次，地上构件按层数复制。
- 装修：房间分类、批量配置、装修档次和真实工序报价；地面、内墙、天棚、门窗、水电分层。材料含损耗，人工按净量，共墙门窗本体不重复收费。
- 市政：手工长度或米制中心线；道路分层、雨污水管井、沟槽回填与外运、路灯、绿化、措施和可选桥梁指标。
- 共用十进制金额引擎、税费汇总、本地保存和旧项目兼容，支持总表 / 分专业 CSV、A4 打印和保存 PDF。

## 性能与视觉

100 个实际共墙房间与 1000 m 道路，三个专业共 2009 行。独立冷态计算、校验与汇总约 78 ms；全套测试并行运行时测得约 139 ms，均低于 300 ms。浏览器实际导入并渲染 500 项清单约 126 ms。时间是本机验收值，不代表所有设备的性能承诺。

实际包内桌面验收同时运行两个 Chromium 会话时，500 项清单渲染约 529 ms，仍完成全部 15 项操作流程。完整报告见 `artifacts/release-validation/native-package-validation.json`；测试通过 `RUN_COST_ACCEPTANCE=1` 将造价脚本连接到真实 EXE 启动的包内服务，未使用源码测试服务器替代该项验证。

检查 1440×960 与 1100×800 布局：页面无整页横向溢出；房间中文名保持一行，批量选项、道路层厚度 / 单位 / 范围 / 密度排列正常；明细表横向滚动限制在表内。已检查空态、选中、估算、缺价、输入和撤销状态。截图与机器记录在 `artifacts/cost-*.png` 和 `artifacts/cost-acceptance.json`。

每个专业缓存自己的计算依赖。修改市政参数或综合单价不重建另外两个专业的清单；几何改变会使土建和装修缓存失效。

## 实际边界

待定价项以 0 占位，总额显示已定价部分；参考价需替换或核对当地信息价与施工报价。材料供应价不会自动冒充完整安装价，原画布材料报价不会再次叠加进造价总表。

钢筋、水电、灯槽、桥梁与自动布局仍为指标或方案估算。当前模型仍为单层正交墙体，土建层数只是标准层算量复制，没有生成多层三维梁柱模型；不支持曲墙、斜墙、CAD/IFC 直接解析或结构与机电设计验算，不替代施工图预算和招标控制价。未上传图纸时可以明确指定土建矩形方案，市政也可使用已知实际长度；没有可靠依据时不自动猜测工程量。

各模块说明见 [造价总览](cost.md)。
