# 地形、道路纵断面与管网计算

继续使用原来的 `启动.bat` 或 `start-studio.bat`，进入「04 市政」。本轮保留原绘图、装修、土建和预算流程，在场地工作台增加三个计算入口。

## 建立测量地形

左侧「场地分析 → 测量地形」可选择或拖入 CSV、粘贴数据，或逐点填写 X、Y、Z。三个坐标均为 **m**，X/Y 相对于图纸原点，Z 为共同高程基准。至少 3 个非共线点形成真实三角网，最多 1000 点。也可切换栅格模式导入 ASC，高程位于像元中心，NoData 保持未知，具体坐标方向与覆盖范围见 [高级场地操作](municipal-advanced.md)。

读取 CSV 后先查看点坐标、覆盖面积与预览，再点击「应用地形」。关闭窗口不会修改项目；错误文件不会覆盖好数据。已应用的测点可以继续编辑，支持撤销 / 重做、本机保存和 JSON 导出再导入。

二维显示测点及三角网，三维显示真实坡面；「显示地形背景」只控制显示，隐藏仍保留测量计算。测点凸包外没有高程，不会外推或生成假地形。练习用示例见 [演示测点](../examples/municipal/演示测点.csv)，该文件是明确标注的教学数据，不能作为实际项目测量。

## 设置道路纵断面与路床土方

画道路或「按尺寸添加」后，选中该道路，在右侧滚动到「道路纵断面」，点击设置 / 编辑。填写变坡点的里程和高程，均使用 **m**。起点固定为里程 0，终点始终对应真实水平路线长度，中间可添加或删除变坡点。

图表显示原地面、设计路面和路床线，以及各段纵坡；没有测量覆盖的原地面会留空。图表的采样间距只影响显示，不能改变精确挖填量。三维道路顶面、底面和结构层随纵坡变化，不再是统一高度的平板。

路床高程 = 设计路面高程 − 主层厚度 − 附加结构层厚度。挖方和填方分别对设计面与测量 TIN 的实际交叠范围积分，保留不规则净边界与孔洞，不将正负体积相抵。结构层已经单独计价，不能再次当路床填土收费。

勾选「土方计入预算」，分别填写挖方、填方综合施工单价，按 m³ 计价。完整覆盖时合入市政总预算，项目附加费、税金只计一次；不完整覆盖时显示实测部分和未知面积，已测部分可进入已知小计，完整总价保持待确认。未填单价同样保持待确认；明确填 0 为有效报价。

修改道路节点后，变坡点里程按新路线长度同比更新，保留高程。启用纵断面后主标高表示起点顶面标高，修改会平移全部变坡点；锁定几何后仍可修改土方价格。相同平面或相同纵断面几何保留施工面去重；不同纵断面的道路分别计量，交叉接坡需明确设计，系统不自动编造接坡做法。

教学数值：10 m × 2 m 道路，路面从 −1 m 升到 +1 m、主层厚 0.1 m，实测地面为 0 m，得到路床挖方 **6.05 m³**、填方 **4.05 m³**。两项单价分别填 10、20 元/m³ 时，土方小计为 **141.50 元**；这只是公式验算，不是市场单价。

## 计算压力供水或重力排水

左侧「管网水力」打开独立分析窗口，可从场地管线建立网络，也可手工添加节点和管段。实际 XYZ 路径确定源管长，只有真正重合的三维端点自动连通；途中交叉不会误连，T 接应把干管拆成两条。

| 模式 | 用户需要填写 | 计算结果 |
| --- | --- | --- |
| 压力供水 | 固定总水头 m、节点需求 L/s、内径 mm、Hazen–Williams C、局部损失 K | 节点总水头 / 压力水头、管段流量 / 流速 / 损失、供出量及守恒误差 |
| 重力排水 | 节点外来汇入 L/s、出口、两端管底高程 m、内径 mm、Manning n、明确分流 | 管段汇流量、坡度、正常水深、充满度、流速、充满及最大自由表面输水能力 |

外径不自动充当内径，空需求不自动充当 0，边界和粗糙系数也不自动编造。压力网支持支状、环状、并行管和多个固定水头；负流量表示真实反向流。重力网支持无环汇流与明确分流，反坡、回路、不守恒分流和超能力会明确提示。

源管线中间节点修改后，水力计算采用当前管长。端点变化或源管删除后显示待确认，需重建并核对连接；重建保留匹配源管线的参数以及相同端点的需求和边界。编辑窗口是独立副本，应用后才保存。结果可单独导出水力 CSV，网络参数保存在完整项目 JSON，计算不自动改管径或添加材料费用。

## 当前适用范围

地形支持本地米制测点 TIN 和 ASC 栅格 DEM，暂未接入地图投影、GeoTIFF、地形断裂线或土方调配。道路支持线性纵坡、抛物线竖曲线、左右横坡和路床两侧放坡；暂不自动设计规范超高过渡、交叉口接坡、挡墙或分级平台。

压力网使用 Hazen–Williams 模型，支持用户泵曲线、阀门启闭 / 节流、止回和储水池时序，暂不包含水锤压力波、水质或自动调压阀。重力网为圆管均匀流与无环汇流，不包含暴雨产流、回水、井室蓄水、出口淹没或动态波。新增操作见 [高级场地操作](municipal-advanced.md)，详细公式见 [地形](terrain.md)、[纵断面](road-profile.md)、[水力](hydraulics.md)。

构建与类型检查沿用原命令。基础验收入口为 `npm.cmd run test:e2e:terrain`、`npm.cmd run test:e2e:road-profile` 和 `npm.cmd run test:e2e:hydraulics`。基础轮记录见 [基础验证](../artifacts/municipal-engineering/final-validation.json)，扩展后的记录见 [高级验证](../artifacts/municipal-advanced/final-validation.json)。当前源码启动即生效，旧发行 ZIP 未更新。
