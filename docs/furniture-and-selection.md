# 家具、斜墙与选中高亮

本说明对应当前源码的斜墙、装修模式、家具与连续墙面功能。已发布的 `release/空间材料估算-1.2.0-Windows-x64.zip` 尚未重新打包，不包含这些更新。运行当前源码仍使用原有入口：

```powershell
python app.py --port 8770 --no-auto-update
```

打开 <http://127.0.0.1:8770>，或双击 `start-studio.bat`。修改 TypeScript 后需先执行 `npm.cmd run build`，无需更换应用架构或安装新的依赖。

## 画任意角度直墙

1. 点击「开始画平面图」，在画布放置起点，继续点击画墙。
2. 默认可画斜墙，端点和墙上的连接点会自动吸附。按住 `Shift` 临时锁定水平 / 垂直方向。
3. 需要精确输入时，在底部填写下一段墙的中心线长度，选择「自定角度」并输入方向，再点击「画下一段」。角度以画布坐标为准：0° 向右、90° 向下、180° 向左。
4. 连回起点形成闭环后自动生成房间。点击「完成绘制」或按 `Enter` 结束墙链；`Esc` 取消当前绘制。

选中已有墙后，可在右侧修改长度、墙高和墙厚，展开「墙线方向」调整角度。方向由墙起点朝终点确定，角度留空时保持当前方向；修改墙尺寸会同步维护相连墙及 T 接点。只修改墙高不改变地面净面积，修改墙厚会重新计算净面积。

房间面积由几何算法计算：中心线围成的区域减去真实墙体占地，保留孔洞与共享边界。画布缩放不会改变面积。墙厚过大、净区域被分裂、内部死端和同一直边厚度突变等不能可靠生成净轮廓的情况会显示原因，暂停对应计量，不用近似面积填补。已增加圆形墙和圆弧墙、自然连接及绘图边界，见 [绘图工具说明](natural-walls-and-shapes.md)；通用样条暂不支持。土建方案模块仍要求正交户型，斜墙项目可在土建中另选矩形方案。

## 选择墙面施工范围

在二维点击墙线、在三维点击墙体，或从绘图左侧「墙体」列表选择墙，在右侧选择「左右两侧墙面」「左侧墙面」或「右侧墙面」。二维与三维会高亮对应的实际施工面，右侧立面预览显示实际完整轮廓与孔洞。

左右是相对于墙起点朝终点的局部方向，与屏幕左右或相机方向无关。计价范围以右侧属性面板为准，三维点击某个面不会静默改变材料施工范围。单侧只计相应侧面，双侧只计实际裸露的左右两面，不计独立墙端面、洞口内壁、墙顶和墙底。实际门窗孔形和相接墙体埋藏面会从用量中扣除。转角共面的延续部分归属邻墙连续侧面，真实侧面面积守恒。

连续面的外轮廓与孔洞来自真实几何分片的共边抵消，保留凹形边界和开口，消除内部接缝；若实体被通高孔洞或相接墙隔开，则显示多个实际独立面。净尺寸 6 × 4 m、墙厚 20 cm、墙高 2.8 m 的闭合房间，双侧面积为 116.48 m²，1 × 1 m 贯通孔再扣 2 m²。旧项目打开后采用该口径重新计算，不改用户单价。

墙、门窗、房间与家具分别选中，右侧切换到对应属性。三维「低墙查看」只调整展示，真实墙高与报价保持不变。

## 添加与摆放家具

1. 先画出闭合房间，点击顶部「02 装修」或「开始装修」。上传已有图片 / PDF 后也可进入装修；返回「01 绘图」可继续修改户型。
2. 从左侧「家具 · 设备」常驻预设库选择产品，再在图纸点击放置，`Esc` 取消。当前提供 93 种预设，包括常用家具家电、九种楼梯以及新增 35 种水电点位、灯具、智能与暖通设备，可搜索或按分类筛选。系统提供可修改的外形尺寸，不预填价格；原「添加家具」入口仍保留。
3. 拖动二维图纸中的家具调整位置，拖动外侧圆形手柄自由旋转，按住 `Shift` 以 15° 吸附，`Esc` 取消并恢复。右侧可修改名称、宽、深、高（cm）、离地高度和精确旋转角，或点击「旋转 90°」。三维中可点选家具查看与修改属性，摆放位置在二维调整。
4. 填写同型号数量（整数件数）、单价（元 / 件）和本项安装 / 运费，左侧家具小计、右侧属性与底部报价立即更新。

一个图示代表一组同型号家具或设备，数量增加不会生成多个摆放实例。需要分别摆放时，使用「复制一件」或再次点选预设；复制保留尺寸和单价，新项数量为 1，可单独修改与撤销。家具实际尺寸为 1–2000 cm；图示按宽、深与旋转显示，三维同时使用实际高度。插座等小点位另外显示易于点选的二维符号，三维仍采用真实厘米尺寸。装修模式屏蔽画墙和区域绘制快捷键，返回绘图后再修改区域边界。

图片或 PDF 需要先校准比例，才能按真实尺寸显示家具；未校准时仅显示位置标记，按件数量与报价可以先填写。家具占地不直接改变地面材料面积；楼梯匹配或独立绘制的楼板洞按真实轮廓扣除地面和天花板用量。当前不做家具与墙体的自动碰撞或摆放优化。

左侧眼睛按钮可隐藏 / 显示家具，隐藏仍计入报价。点击删除、右侧「移除家具」，或选中后按 `Delete` / `Backspace` 可移除；使用 `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。输入框编辑时快捷键保留正常文本操作。

## 插座、灯具与水电线路

新增的 35 种设备分为三个分类：

- 「水电点位」20 种：五孔、防水、地插、USB、空调插座、三脚插头，单联、双联、三联、双控、调光开关，配电箱、弱电箱、网络面板、电视面板，冷 / 热水出水口、地漏、水阀和分水器。
- 「灯具」6 种：筒灯、射灯、灯带控制器、壁灯、吊灯和线性灯。
- 「智能与暖通」9 种：无线路由器、无线 AP、暖气片、新风口、排风扇、温控器、烟感探测器、智能控制面板和可视门铃。

面板、插孔、按钮、设备圆形外壳、风机叶片和栅格均为原创参数几何。默认尺寸和离地高度可调整；离地高度表示设备底部距本层地面的距离。原生平面图中，壁装设备靠近墙面时按点击的一侧吸附，背板贴墙，正面朝外，宽度沿墙。远离墙面、地插、地漏及吸顶设备保持自由摆放，不自动进行碰撞或施工规范校核。

电线、网线和管道在「水电 · 管线」绘制，共 27 种可编辑预设，包括自定义线材 / 管道。逐点画实际走向，按 `Enter` 或双击结束，`Esc` 取消；可拖动节点、修改高度、添加竖向段。长度按真实三维折线计算，材料采购量包含预留、并行条数和损耗，人工按净用量计价。管线和设备分别填写单价，独立计费，合并进入全楼层总报价。操作、公式与范围见 [室内设备与水电管线](indoor-services.md)。

## 楼梯、扶手与楼板洞

「楼梯」分类提供直跑、平台直跑、L 型左右转、U 型折返、左右螺旋和左右弧形共九种预设。在右侧「楼梯连接与扶手」设置到达楼层、双侧 / 单侧 / 无扶手及 50–150 cm 扶手高度；螺旋和弧梯还能修改内圈比例与旋转圈角。楼梯高度仍代表总升高，扶手高度另加在实际模型上。

先在下层放置楼梯并选择「到达楼层」，填写「洞口留量」，点击「自动匹配楼梯口」。洞口按楼梯实际轮廓生成，并按上层房间边界裁切；以后移动、旋转或修改楼梯尺寸，洞口会同步更新。「查看楼梯口」前往上层，「改为手动洞口」保留洞形并停止跟随。

上层二维显示同一部楼梯的踏步、上行箭头和来源标记，左侧「通往本层的楼梯」可返回来源层编辑；三维「只看当前层」也保留通往本层的下层楼梯及真实标高。查看全部楼层时，同一部楼梯只显示一份，采购和安装价格只在起始层计一次。

上层选中房间后，可在「楼板与挑空」选择矩形、圆形、椭圆、圆环或自由绘制。简单形状拖出即完成，自由绘制逐点圈选并按 `Enter` 闭合；「输入洞口尺寸」提供精确尺寸和位置，已有洞口的编辑按钮可改尺寸。靠墙和墙角自动吸附，贴边或稍微出界会按实际房间裁切，重叠洞口不会重复扣量。圆环中央保留楼板，分裂出的地板片段仍共用原房间材料与固定费用。完整流程见 [楼梯与楼板洞设计](stairs-and-floor-openings.md)。

## 家具与项目报价口径

```text
家具材料费 = 同型号数量 × 单价
家具小计 = 家具材料费 + 本项安装 / 运费
税前项目小计 = 所有楼层的区域、墙面与天花板材料费 + 人工费 + 家具设备小计 + 管线小计 + 各项固定费用 + 项目附加费
项目税额 = 税前项目小计 × 项目税率 / 100
含税总价 = 税前项目小计 + 项目税额
```

金额使用十进制计算，按分 `ROUND_HALF_UP` 舍入。本项安装 / 运费是该家具项的一次性费用，不再乘数量；家具没有额外的损耗率或面积人工费。

例如 2 件椅子，单价 125.25 元，本项安装 / 运费 30 元，家具材料费为 250.50 元，税前小计为 280.50 元。项目统一税率为 9%，且无其他报价项和附加费时，税额为 25.25 元，含税总价为 305.75 元。

未填写单价与明确填写 0 含义不同：空白单价标为「待填单价」，项目正式总价保持待确认，不能导出正式报价；0 是有效的已确认价格。画布底部项目报价合并所有楼层的区域、墙面、天花板、家具设备和实绘管线，顶部「造价」工作台仍按当前层原参数独立汇总土建、装饰装修和市政三专业清单，不自动合并家具或画布底部原材料报价。

## 保存与交付

家具设备与管线随工作台项目自动保存，也可点击顶部「保存」。项目 JSON 包含绘图 / 装修阶段、类型、名称、尺寸、位置、旋转、离地高度、数量、单价、本项安装 / 运费和隐藏状态，以及全部楼层、楼梯目标层、扶手参数和联动洞口；管线另保留 `serviceRoutes` 的节点、规格、直径、损耗、预留和报价参数。通过「打开项目」重新加载，二维、三维与报价会根据数据重建。旧项目没有 `furniture` 或 `serviceRoutes` 字段时按空列表兼容，没有阶段字段时默认绘图。

「导出报价」中的完整 CSV 保持原有列结构，包含家具设备明细、管线明细及汇总，记录件数或真实长度、单价、规格、固定费用和总额；家具净面积、周长列留空。Excel 可直接打开。打印 / 保存 PDF 包含设备规格、按件明细和实绘管线报价；图纸示意只画未隐藏且已校准的对象，隐藏对象仍保留在报价明细中。用量或单价尚未确认时，先补齐后再导出正式报价。

更换电脑、浏览器或端口前导出完整项目 JSON 并在新环境导入。项目 JSON 中当前页图像的保存范围及原 PDF 备份方式见 [README](../README.md#保存与原有数据)。

## 当前范围

原八种原创本地三维网格包含倒角、坐垫、柜门与抽屉等外形细节，已调用本机 Steam 安装的 Blender 5.2.3 LTS 生成，素材约 210 KB；生成脚本也保留纯 Python 的离线方式。建模源保存在 `development_assets/furniture-presets.blend`，八种家具按真实米制尺寸分为独立集合、部件及材料。当前另有 85 种原创参数模型和 SVG 预览，共 93 种预设，包含设备屏幕、滚筒、柜门、九种带可选扶手的楼梯，以及 35 种水电、灯具、智能与暖通点位。楼梯模型与二维踏步和匹配洞口共用真实几何，螺旋与弧梯采用薄踏板、支撑梁及连续扶手，保留下方空间。软件运行不依赖 Blender，按真实尺寸、旋转和离地高度显示。尚无 GLB / GLTF 模型导入、品牌产品模型、定制柜内部结构精算、自动布局或墙体碰撞约束。

当前源码支持多楼层设计、部分二楼 Loft、上下层同源楼梯显示、自动匹配与五种形状楼板洞，以及天花板材料、设备点位和实绘管线，全部楼层的原材料、家具设备及管线报价统一汇总。操作与范围见 [多楼层与家具家电](loft-and-furniture.md)、[楼梯与楼板洞设计](stairs-and-floor-openings.md)和[室内设备与水电管线](indoor-services.md)。土建的标准层复制仍仅用于方案工程量，三专业造价方案按当前层和原参数生成。以上新功能当前在源码中，既有 1.2.0 Windows ZIP 尚未更新。
