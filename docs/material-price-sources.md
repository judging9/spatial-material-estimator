# 材料价格来源与刷新

使用原 `启动.bat` 或 `start-studio.bat` 启动。价格来源和材料库保存在当前浏览器，项目保存其实际单价与来源快照；刷新不会直接覆盖工程报价。

## 添加实际报价

在「设置 → 材料库」添加或编辑材料，填写产品名称、单位、实际单价，再展开「价格来源与刷新」填写来源名称、地区、报价日期、供应商和规格。来源类型可以是手工 / 文件、供应商 / 地方网页，或国家统计局生产资料。网页需填写完整网址，来源中的产品名称、规格和单位应与报价表一致。

手工保存的价格会明确标为手工录入；只修改颜色、描述或损耗，不会改动已刷新记录的日期与录入方式。少量内置材料是明确标注的 Demo，没有在线报价源，不能刷新为真实市场价。可替换为自己确认的采购报价。地区由来源提供，不限全国；没有地区信息时明确显示未注明。

## 关联到工程

选择房间、墙面、吊顶、家具、门窗、管线、土建构件或市政设施，在右侧「价格来源」点击「关联报价来源」。选择同单位材料，核对产品及规格，确认后应用其单价。材料外观、几何、净施工量、人工、损耗和固定费保持原设置。

按吨报价不能直接应用到按平方米计价的地砖。模板、钢筋、桥墩、栏杆、挖填方和运输等独立专业价格继续在原专业工具中填写，本轮只给主单价字段提供材料来源关联。

## 刷新并核对

点击分项「刷新报价」，或材料库「刷新来源报价」，读取实际来源的报价表。网页可保存表格编号、表头与列映射；首次存在多个可用表格时，先通过「导入报价」明确映射。国家统计局读取最新发布列表，保留文章地址与实际原始计价单位。

刷新只匹配同产品、规格、单位、地区、来源及供应商；未匹配、旧日期、重复报价、连接失败均提示原因并保留原价。来源不提供发布日期时不会沿用旧日期。页面依赖 JavaScript 动态生成、登录、反爬或不提供 HTML 表格的来源，可以手工录入或导入表格。

确认选中的报价后，先更新材料库。项目有关联分项时，随后打开「将最新报价应用到项目」，显示前后总预算与来源。选择应用范围，确认后可一次撤销；也可保留项目原价，之后在材料库点击「同步项目单价」。同价但新日期也可同步来源记录。用户手工改工程单价后显示「用户调整单价」，不把调整后的数值归于原网站。

## 保存与交付

保存及完整项目 JSON 保留关联材料 ID、原始报价、来源网页、地区、规格、供应商、日期和表格映射。工程总览 CSV、用量清单和打印报价页保留来源说明。项目文件保留报价快照，材料库独立保存；导入项目到另一台电脑后可在当地材料库重新关联来源。

浏览器验收使用明确标注的确定性上游夹具验证失败和更新流程，不代表验证了互联网实时市场行情。实际采购应核对具体产品、地区、发布日期及报价包含范围。
