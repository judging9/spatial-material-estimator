# 门窗与墙孔定位、自填报价

继续双击原来的 `启动.bat` 或 `start-studio.bat`。本次修改在当前源码工作台中生效，原发行 ZIP 未重新打包。

## 添加与移动

1. 在「01 绘图」画出墙体，或打开已有平面图。在左侧展开「墙体」，选择墙后，右侧点击「门」「窗」或「开孔」。
2. 填写宽、高、距墙起点、离地高度和形状。添加弹窗按米填写，门扇和窗框厚度按厘米填写。支持矩形、圆 / 椭圆及可编辑多边形。
3. 二维直接拖动墙上的开口条形标记，可沿所属墙体移动；斜墙按自身方向计算。拖动不会改变门底、窗台或孔底高度。
4. 三维先点击选中开口，再拖动。窗与孔可同时沿墙和上下移动；门沿墙移动并保持门底高度。低墙查看仍显示完整开口定位轮廓，正式用量按真实墙高计算。
5. 右侧「墙体立面」中拖动绿色开口，可以更清楚地调整位置。同墙的其他开口作为浅色轮廓显示。

普通移动按 1 cm 网格定位，靠近墙端、中心及同墙开口边缘时提供吸附。按住 `Alt` 可关闭吸附进行精细移动；三维与立面拖动按住 `Shift` 可约束到主要移动方向。`Esc`、失焦或切换对象取消尚未提交的移动；松开鼠标提交一次修改，可用一次撤销恢复。

右侧位置输入使用 **cm**，支持小数。距墙起点沿墙中心线的起点朝终点计量，离地高度相对于当前楼层。门通常从 0 cm 开始，也可明确输入非零门底。数字输入严格校验，超出墙体、负高度、重叠或碰到无效接点时保留原设计，并显示原因。

## 锁定、复制与删除

勾选「锁定」会禁止直接拖动、修改位置以及编辑尺寸和形状，仍可选中查看、修改名称和报价。锁定的是相对所属墙体的位置和尺寸；修改整个墙体或楼层时，开口仍随宿主墙体和楼层移动。墙体尺寸变化不能使开口越界。

「复制」保留开口的尺寸与形状，为副本生成独立名称和编号并解除副本锁定。先在弹窗核对位置，确认后加入设计；空间不足时可调整宽高或离地高度，禁止直接创建重叠副本。修改、锁定、复制和删除均支持撤销。

## 自填门窗与开孔报价

选中一个门、窗或墙孔后，在右侧「本体与安装报价」勾选「计入预算」。已有项目和新建开口默认不启用本体报价，仍按原规则扣除真实墙面面积，不会自动增加供应或施工费用。启用后的单价由用户填写，默认留空；未填写时显示待填写状态，正式 CSV 和打印 / PDF 导出会要求补齐，允许另行导出明确标识的报价草稿。填写 `0` 表示用户明确报价为零。

可选择三种计价单位：

- **件**：手填报价数量，适合成品门窗供应及按件安装。数量只影响预算，不会在图纸上生成额外开口或重复扣墙面面积。
- **m²**：按当前真实开口轮廓面积计价，支持矩形、椭圆和不规则多边形。修改开口尺寸或形状会立即更新用量。
- **m**：按当前真实封闭轮廓的周长计价，可用于孔边加工、收口等按延米计价的施工。

采购量 = 净用量 ×（1 + 损耗率）；材料费 = 采购量 × 单价；人工费 = 净用量 × 人工单价；该开口小计 = 材料费 + 人工费 + 固定附加费。金额按分精度处理，项目附加费与税率在工程总额中统一计取一次。

修改单价、损耗率、人工单价和固定费后，当前开口小计与底部项目总价同步更新。锁定开口位置和尺寸后仍可修改报价；关闭计价开关会暂时移除其费用，重新启用保留此前填写的价格。复制开口时保留独立报价快照，副本改价不会影响原对象。报价、锁定和几何修改均支持撤销，并随项目保存、JSON 导出和重新加载保留。

CSV 与打印 / PDF 各自列出门窗和墙孔的名称、真实宽高、位置、轮廓计量、用户价格及费用，使用当前项目报价。墙面饰面的开口扣除和门窗本体报价分别计算，二者不会重复计量。

## 计量与保存

三种定位方式共用真实多边形和墙体占地校验，考虑墙厚、自然接角、斜墙 T 接点与同墙开口碰撞。连续拖动不会跨过薄开口或穿过被阻挡的墙接点；窗口位于低矮分支墙上方时按真实高度判断。

移动不改变开口自身面积；所属墙面的真实裸露面积、材料采购量、人工与项目报价会重新计算。窗和孔上下移动时，若与相邻墙体的实际遮挡关系改变，净量和对应报价也会改变。选中范围只高亮当前开口，保留孔洞的真实形状。椭圆显示与计量使用同一轮廓。

名称、位置、形状、锁定和所有楼层配置随项目保存在本机，也可导出完整 JSON 再导入。自动保存会等待拖动结束，避免保存预览中的临时位置。CSV 和打印 / PDF 继续使用当前实际报价数据。

更换图片、切换 PDF 页或移除图纸时会清除旧区域、墙体、开口、家具、管线、土建构件及设计楼层，可撤销恢复。独立材料库与手工造价配置仍保留。

## 当前范围

墙面开口依附于原生绘制的墙体；上传图片仍需画墙或使用二维区域流程。拖动在所属直墙段内进行，跨墙移动需在另一面墙重新添加。曲线墙不支持跨多个折线段的整体门窗。

画布工作台已支持每个门窗或墙孔独立自填一组单价、人工、损耗与固定费，并计入装修报价。需要逐条拆分五金、门套和其他供应安装明细时，可继续使用已有造价清单；材料价格由用户核实填写，不自动推断市场报价。PDF 通过报价打印页面的浏览器「另存为 PDF」生成。
