# 市政场地设计与预算

继续双击 `启动.bat` 或 `start-studio.bat`，在顶部选择「04 市政」。这是可实际绘图的场地工作台；原「造价 → 市政」方案清单继续保留。

## 从一条道路开始

1. 无图纸时直接进入市政，自动创建按厘米计量的空白场地。不需要上传图片或再次校准。
2. 点击左侧「道路」，逐点绘制中心线，按 `Enter` 或点击「完成」结束；按 `Esc` 取消。支持斜线，`Shift` 临时限制水平 / 垂直方向，`Alt` 关闭节点吸附。
3. 选中道路，在右侧输入路宽、主层厚度和顶面标高，再填写材料单价、损耗、人工单价及固定费用。点击「附加结构层」的 `+`，添加基层或垫层，分别填写厚度与价格。
4. 添加铺装、绿地、管线或单点设施。左侧项目列表、二维画布和三维预览同步选择，只有当前设施高亮。选中后拖动节点调整，或展开节点列表输入准确坐标。
5. 底部实时显示场地净面积、材料费、人工费和市政预算。点击总价查看明细；设置中可以填写项目固定费和税率。
6. 保存到本机，或导出完整项目 JSON、CSV、打印 / PDF 报价单。关闭后可从「打开项目」继续工作；JSON 可转交其他使用同版本软件的人导入。

「按尺寸添加」可用起点、长度、方向角与尺寸快速创建设施。起点和长度使用 **m**，道路宽度、管径、厚度和标高使用 **cm**；矩形铺装及绿地宽度使用 **m**。各输入标签明确标注单位。检查井默认井底 −150 cm、井深 150 cm；管线默认中心标高 −80 cm，均可修改。

已有 PNG / JPG / PDF 也可使用；先校准比例，再绘制市政设施。图片坐标与用户校准比例共同确定真实用量。未校准时不显示精确面积或长度，正式报价导出会要求先完成校准。图片背景作为不可误操作的底图；市政三维预览目前支持原生绘制的场地。

## 七类设施

| 类型 | 绘制方式 | 计量与尺寸 |
| --- | --- | --- |
| 道路 | 画中心线 | 实际宽度轮廓的净面积；按 m² 或主层 m³ 报价，可加基层、垫层 |
| 场地铺装 | 圈选多边形 | 凹形、不规则边界净面积；按 m² 或面积 × 厚度计 m³ |
| 室外管线 | 画节点路线 | 实际 XYZ 三维长度计 m；可切为水平投影长度 × 矩形沟宽 × 沟深计 m³ |
| 检查井 | 点击放置 | 井体宽、深、井深和井底标高；按用户填写件数报价 |
| 路灯 | 点击放置 | 灯杆直径、高度与底标高；按用户填写件数报价 |
| 绿地 | 圈选多边形 | 按净面积 m²，或净面积 × 覆土厚度计 m³ |
| 路缘石 | 画中心线 | 路线长度计 m；或长度 × 宽 × 高计外形体积 m³ |

管线节点的 `Z cm` 是绝对高程。修改整体中心标高会同时平移所有节点的 Z，保留原有竖向形状。道路、铺装和绿地的标高为顶面，主层及附加层向下；井标高为井底，路灯与路缘石标高为底部。道路可在右侧「道路纵断面」设置里程、高程及土方报价；启用后主标高输入表示起点顶面，修改它会整体平移纵断面。地形测点、纵断面和水力节点使用 m，管线绘图节点仍使用 cm，输入标签注明单位。

一个井或灯图示代表同规格预算项；数量可填写多件，但不会自动复制摆放位置。需要分别指定位置时使用「复制设施」，副本有独立编号与价格。隐藏只影响显示，仍计入预算；锁定保护几何，价格和名称仍可编辑。删除、复制、节点修改和改价支持撤销 / 重做。

## 计算口径

同标高的道路、铺装及绿地按真实多边形差集分配重叠施工范围，依持久化的放置顺序归属，避免重复计算净面积。不同标高作为不同施工面计量。缩放、平移和三维相机操作不参与计算。自交边界、重复节点和导致道路轮廓自交的宽度 / 转角会明确拒绝并保留原设计。

材料采购量 = 净工程量 ×（1 + 损耗率）；材料费 = 采购量 × 材料单价；人工费 = 净工程量 × 人工单价。主项、结构层及固定费用分别计入小计，项目附加费和税金只加一次。金额使用现有十进制运算与整数分汇总；几何量先稳定量化再计价，避免旋转的极小浮差影响半分舍入。

模板只提供可修改的尺寸，不提供市场价。空白单价显示待填写，明确填写 `0` 是有效报价。有待填写单价或待校准工程量时显示已填写小计，完整总价保持待确认，不能将其导出成正式完整报价。

市政对象保存在项目根级，不随建筑楼层复制。顶部切换绘图、装修、土建与市政会保留各自设计及独立报价。项目设置中的固定费、税率由工作台共享；需要跨专业总价时，通过[工程总览](project-overview.md)勾选装修、土建与市政，先合并专业税前金额，再计算一次工程固定费及税金。原「造价」方案总表不自动加入。

## 保存与导出

本机项目和 JSON 保存中心线、多边形、逐点高程、尺寸、隐藏 / 锁定、结构层和价格参数。市政 JSON 导出包含当前重新计算的预算汇总，以及项目中保留的建筑设计。CSV 包含主项及结构层净量、采购量、单价、损耗、人工、固定费和税费；打印页面可由浏览器保存为 A4 PDF。

更换图纸、切换 PDF 页或移除图纸会清除该图纸对应的市政及建筑设计，确认提示列出清理范围，可撤销恢复。独立材料库与旧手工造价配置仍保留。

## 当前范围与扩展

当前支持最多 500 项设施、每项 200 个节点。测点地形支持最多 1000 点；道路可设置分段线性纵断面，管线支持逐点高程，并可建立独立水力网络。路床土方按测量地形与实际道路设计面精确积分；管沟 m³ 仍为矩形沟估算。尚未提供地图坐标系或栅格 DEM 导入、边坡扩挖、井坑、土方调配、竖曲线、道路横坡超高及桥梁结构设计。压力网为固定边界稳态计算，重力网为无环圆管均匀流，不包含暴雨动态波或泵阀调度。

几何引擎支持导入的铺装 / 绿地内部孔洞并真实扣除；当前市政绘图界面主要创建外边界，未提供专用孔洞绘制工具。管线采用用户画出的路线，不会自动推断连接、选管径或避障。

本轮参考 `development_resources` 中 QGIS / GDAL 的线缓冲和偏移曲线接口，以及 IfcOpenShell 的件、面积、长度计量语义。实现为本项目原创模块，无新增运行依赖；详细依据见 [市政几何参考](municipal-geometry-reference.md)。后续可以独立接入地形、CAD / GIS 导入和专业工程规则。

地形、纵断面和水力计算的具体操作见 [市政分析说明](municipal-engineering.md)，详细算法及范围分别见 [测量地形](terrain.md)、[道路纵断面](road-profile.md)、[管网水力](hydraulics.md)。
