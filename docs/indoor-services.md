# 室内设备与水电管线

保留原启动入口：`start-studio.bat` 或 `启动.bat`。家具与设备按件计价，电线、网线、水管、风管和灯带按真实路径长度计价，均使用用户填写的价格。

## 从点位到线路

1. 新建二维平面图并按真实尺寸画墙，或上传图纸并先校准比例。
2. 进入装修工具，在「家具 · 设备」摆放插座、开关、灯具、网络面板、配电箱及给排水等点位。点位尺寸、任意角度、安装高度、数量及单价可编辑。
3. 切换「水电 · 管线」，选择电线、网线、水管、暖通管道或灯带。清单共有 27 项，含「自定义线材 / 管道」；未列出的型号可填写自己的名称、规格、显示直径和价格。
4. 在画布逐点画实际走向。端点、设备点位及墙边提供吸附，按 `Shift` 锁定方向，按 `Enter` 或双击结束，按 `Esc` 取消。
5. 选中线路，在右侧填写材料单价、人工单价、损耗率、并行条数、每条预留长度及本项固定施工费。预设没有默认市场价格；单价留空会显示「待完善」，明确填写 `0` 表示本项价格为零。

## 路径编辑与三维表示

选中后拖动线路节点调整平面走向，也可输入节点 X、Y 实际坐标和离本层地面高度。X、Y 输入单位是米，节点高度单位是厘米。安装高度支持 -100–2000 cm，允许地暖、地面暗埋及走顶。

「添加竖段」在路线末端增加同一平面坐标、不同高度的节点，例如由吊顶走线下降至插座。重新绘制保留原线路的报价参数；删除节点、复制、隐藏及删除线路可在属性面板操作，修改支持撤销。

二维显示平面走向，三维显示实际节点高度和管线直径。三维沿用真实尺寸平面图功能；上传图片的路线在校准后可以计长，三维建筑预览需要原生平面模型。相同路线的「并行条数」增加采购和施工数量，不凭空生成多条独立摆放模型。隐藏仅控制显示，仍纳入报价。

## 真实计长与报价公式

原生平面图每坐标单位对应 1 cm；上传图纸的 X、Y 使用校准的米 / 像素，Z 始终使用实际厘米。每段长度为：

```text
段长（m）= √((ΔX × 比例)² + (ΔY × 比例)² + (ΔZ × 0.01)²)
路径长度 = 所有实际线段长度之和
净用量 =（路径长度 + 每条预留长度）× 并行条数
采购量 = 净用量 ×（1 + 损耗率 / 100）
材料费 = 采购量 × 材料单价
人工费 = 净用量 × 人工单价
线路小计 = 材料费 + 人工费 + 本项固定施工费
项目总价 = 全楼层各项小计 + 项目固定费用 + 统一税额
```

材料费、人工费、固定费分别四舍五入到分，再汇总。金额及用户输入的预留长度、条数、单价和百分数以十进制整数运算处理；几何长度由实际三维折线计算。画布缩放、视角、显示直径、隐藏状态和设备数量不会改变路线实际长度。

图纸未校准时，路径长度、净用量和采购量均为「待校准」，包括同一平面位置的竖段，避免把部分已知尺寸冒充完整用量。单价留空时不生成完整总价，保留可确定的人工和固定费小计；未校准时只能保留固定费用。

## 楼层、保存和导出

每层独立保存点位和线路。切换楼层不会带入上一层线路；复制布局会复制实际坐标与自填价格，并为新对象生成不同编号。跨层高度从本层地面计算，项目总报价按全楼层汇总，项目固定费用与税只计算一次。

保存与工程 JSON 保留节点坐标、规格、安装高度、价格、预留、损耗及并行条数。CSV 和 PDF 报价明细包含线路计量数据，与家具设备费用一起导出。重新加载依据真实坐标重新计算，不信任导入的汇总数值。

这些点位和线路用于空间布置、用量估算和用户自填价格预算。设备靠近线路提供绘制辅助，不自动建立电气回路或给排水拓扑，也不自动选择导线载流量、保护器件、管径、排水坡度和施工规范参数；规格与施工做法由项目人员填写。
