# 空间材料估算

版本：1.3.0  
平台：Windows 10 / 11，64 位

按真实尺寸绘制房间与场地，查看三维空间，为材料、家具设备、实际管线及市政设施配置单价并生成报价。运行环境随软件提供，无需安装 Python、Node.js 或 Blender。

## 本版本更新

- **绘图与装修**：任意角度直墙、圆与圆弧、自然墙体连接、连续墙面选择、门窗及自定义开孔；地面、内墙和天花板分别选材，按真实裸露面积计算用量。
- **家具与室内水电**：93 种家具设备预设、自由旋转和尺寸编辑；设备按件计价，27 种线路预设按实际三维路径计长，支持损耗、预留长度、人工及固定费用。
- **多楼层与楼梯**：最多 8 层独立布局、Loft、9 种带可选扶手的楼梯；自动匹配上层洞口，支持矩形、圆、椭圆、圆环和自由多边形楼板洞。
- **市政场地**：道路、交叉口、环岛、信号灯、桥梁、河流及管线设施；支持按尺寸添加、二维编辑、三维定位和独立设施报价。
- **地形编辑**：测点及 DEM 导入、概念地形创建和地形塑形；道路纵断面、竖曲线、横坡、边坡、土方和平衡调配，保留真实高程及缺测状态。
- **穿山隧道**：矩形或拱形、区间里程、净空和衬砌，按真实三维长度独立计价；三维增加查看道路、洞口和洞内入口，被山体遮挡时可剖视查看。
- **设施高度**：米制标高、整体升降、贴合地形以及离地高度或埋深；道路可直接设置起终点高度。
- **管网分析**：支持已有管网水力、泵阀及控制参数分析。计算结果取决于用户填写的管径、高程、粗糙度、供需和设备参数。
- **材料价格与项目交付**：地区、日期和来源关联、批量调价、保存单价快照；项目保存重开，支持完整项目 JSON、报价 CSV 和打印 / 保存 PDF。

## 保留的多专业造价

- **统一造价工作台**：汇总土建、装饰装修和市政，统一计算措施费、其他项目费和税金。支持手工清单、价格确认及估算筛选。
- **土建方案**：按现有正交户型或矩形外轮廓，设置结构形式、标准层层数、层高、柱板尺寸与基础，生成参考柱网和基础、梁柱板、砌体、模板、钢筋及土方工程量。
- **装饰装修**：按房间类型与施工范围生成内墙、地面、吊顶、门窗及水电做法。材料采购和面层铺装人工、基层及安装工序分列；支持批量空间类型和实际档次报价。
- **市政方案**：手工输入路线长度或在已校准图纸画中心线，设置横断面、管网、路灯和绿化，生成工程量与里程表；桥梁为可选指标估算。
- **完整交付数据**：项目保存并重新加载造价参数与确认单价；导出总表 / 分专业 CSV，以及打印 / 保存 PDF，保留工程量、特征、来源和估算说明。

## 原有绘图和材料功能

- 画墙生成房间，支持室内净尺寸房间模板、墙长、墙高和墙厚设置。
- 二维图纸导入、比例校准、多边形区域编辑和实际面积计算。
- 三维空间旋转、缩放、低墙查看、材料预览与图片导出。
- 墙面材料配置、裸露面积计量，以及门窗和矩形、椭圆、多边形贯通孔洞。
- 独立材料库，官方公开参考价格入口及地方文件、粘贴、网页表格报价导入。
- 材料损耗、人工单价、附加费用与税率，保存单价快照。
- 项目自动保存、重新加载、完整项目 JSON、CSV 报价和打印 / 保存 PDF。

完整解压后双击「空间材料估算.exe」。三维显示需要可用的 Microsoft Edge 或 Google Chrome 及 WebGL。详细步骤见同目录「使用说明.html」。内置材料价格为操作示例，正式报价应使用实际产品规格、地区价格与施工单价。

从旧版升级时，请先关闭旧版窗口，再将新版完整解压到新文件夹后启动。已有用户数据保留；升级前建议备份完整项目与材料数据。旧版仍运行时，新启动会回到旧窗口。

## 使用范围

绘图支持多楼层，土建方案的层数只复制标准层的地上方案工程量，基础及土方计一次，不自动创建多楼层布局或复制装修房间。图片与 PDF 不会自动还原三维墙体；公开网页读取需要网络连接和来源网站可用。每条道路目前支持一个连续隧道区间，未提供自动围岩支护、通风消防或结构规范设计。

图纸工作台可为门窗本体启用独立报价；装修方案清单也会按实际门窗记录分列本体、五金与安装，应核对实际采用的计价范围。画布项目预算汇总实际绘制的全楼层区域、墙面、天花板、家具设备、管线和市政设施；顶部「造价」工作台的三专业方案按其参数独立汇总。两套汇总不直接叠加。

缺少实际施工单价的清单标「待定价」并按0占位，当前金额只代表已定价部分。内置参考值需换为当地信息价或实际施工报价，材料供货单价不能直接冒充包含人工、机械及安装的完整综合价。采购损耗计入材料数量，面层人工按净施工量计算。

部分钢筋、水电和桥梁方案项目采用指标估算；实际绘制的设备和管线使用对应数量或长度。本软件不进行结构承载力 / 抗震设计、钢筋翻样或机电管线综合，不能替代施工图预算、招标控制价及施工依据。
