# 土建设计与构件预算

当前源码新增顶部「03 土建」，与「02 装修」并列。继续双击原来的 `启动.bat` 或 `start-studio.bat` 运行。此前发布的 1.2.0 ZIP 没有包含这些源码更新。

## 从设计开始

1. 打开「03 土建」。没有图纸时，会创建按厘米坐标绘制的空白画板，无需上传图片或校准。
2. 选择左侧构件，在画布中点击放置。提供矩形柱、圆柱、梁、楼板、独立基础、条形基础、筏板、垫层、砌体墙、挡土墙、开挖与回填。
3. 选中构件，在右侧输入宽、深、高和相对本层地面的底标高，或拖动边框调整平面尺寸。拖动旋转手柄调整方向。圆柱按同一直径调整。
4. 「按尺寸生成框架」根据范围长宽、柱网最大间距、层高及截面尺寸，生成真实可编辑的柱、梁、板和可选基础。不会填写材料价格。
5. 在右侧填写材料单价、损耗、人工费和固定费；需要模板时填写模板单价。钢筋可选择指标估算或自行填写实际公斤数。
6. 切换到 3D 查看实际构件。已有多楼层项目保留各层实际标高，可只看当前层或查看全部楼层。
7. 保存到本机；通过 CSV 或浏览器打印为 PDF 导出预算，JSON 保存完整设计以便重新导入。

楼板、筏板放在已划分房间内时，自动关联真实房间轮廓，保留楼板洞，并随房间变化更新尺寸。关联期间需要先点击「独立编辑」才能移动、旋转或改平面尺寸；解除关联会保留当时的异形轮廓、洞口与中央岛。隐藏构件只影响视图，仍保留预算。数量用于同规格计价，不自动复制实体。

## 尺寸与锁定

家具、室内设备和土建构件支持边缘及角点手柄。拖动保持对侧边或对角点固定，按物件旋转后的局部坐标计算尺寸。拖动中实时预览，松开作为一次历史操作；Esc 取消，Ctrl+Z 撤销、Ctrl+Shift+Z 重做。

锁定后仍可选中查看或填写名称和价格；位置、旋转与尺寸禁止鼠标和数值修改。解锁后继续编辑。高度通过数字输入设置，不通过二维边框改变。

楼梯锁定也保护目标楼层、扶手和曲线参数。修改层高若会改变已锁定楼梯的升高，会提示先解锁该楼梯。

## 计算口径

厘米尺寸换算为 m²、m³。图片图纸必须先校准，未校准时工程量显示待校准。

- 混凝土、挡土墙和砌体的交叠按基础、柱、梁、板、砌体顺序进行空间归属；通过真实多边形差集与高度分片扣量，跨楼层也检查实际标高。同类按物理几何稳定排序，完全同形的构件由先放置者优先计量，随机编号与价格变化不会改变归属。
- 材料采购体积 = 净体积 × 数量 ×（1 + 损耗率）。
- 主材费 = 采购体积 × 单价；人工费 = 净体积 × 数量 × 人工单价。
- 模板根据外露侧面计算；梁、板另计算需要支模的底面，扣除实体接触部分。垫层、砌体与土方不自动计模板。
- 钢筋指标估算 = 扣量后净体积 × kg/m³ 指标；实际模式使用自行填写的单件公斤数，乘数量后计价。
- 本组固定费只计一次，项目附加费和税金在全楼层汇总后只计一次。采用现有十进制金额内核，分项按分舍入后汇总。
- 开挖与回填属于不同施工操作，允许同一空间分别计量；目前为直壁体积，未加入放坡、工作面或地质分层。

土建与装修分别报价，未选地面材料不会阻止土建预算。旧「造价」中的方案清单仍可使用，其金额不自动叠加到新的构件预算。

空白单价表示待填写，明确输入 0 表示零费用。未启用模板或钢筋时不会要求相关价格。钢筋指标模式会明确标记估算。

## 当前范围

这是尺寸设计与预算工作台，不提供结构承载验算、规范配筋、钢筋翻样或施工图设计。圆柱使用与三维相同的 200 边轮廓进行曲线近似并注明。暂不支持坡屋面、异形梁截面、钢结构节点、施工进度或工程定额自动套价；市政继续使用已有方案清单工作台。

纯逻辑分布在 `lib/civil.ts`、`lib/civil-pricing.ts` 和 `lib/furniture-resize.ts`；二维交互在 `canvas.ts`，土建属性界面在 `civil-panel.ts`，三维在 `lib/scene-civil.ts`，保存适配在 `lib/levels.ts` 和 `lib/persistence.ts`。
