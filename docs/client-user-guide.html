空间材料估算

二维绘图 · 三维空间 · 材料选配 · 多专业造价

版本 1.3.0 · Windows 64 位

本说明适用于空间材料估算 1.3.0。运行环境随软件提供，无需安装 Python、Node.js 或 Blender。建议先完成一个房间或一段道路，再逐步添加材料、设备及工程费用。

开始使用

  1. 将压缩包完整解压到一个文件夹。不要直接在压缩包中运行程序。
  2. 双击 空间材料估算.exe。软件以独立工作窗口打开，运行环境已随软件提供。
  3. 使用 Windows 10 或 Windows 11 的 64 位系统，并保留 Microsoft Edge 或 Google Chrome。选择支持 WebGL 的浏览器，可正常查看三维空间。
  4. 关闭软件工作窗口即可退出。再次启动后，点击顶部文件夹按钮打开已保存的项目。

从旧版升级时，先关闭旧版软件窗口，再将新版完整解压到新的文件夹并启动。新旧版本共用本机项目数据，已有项目和材料库保留；旧版仍在运行时，启动新版会回到已打开的旧窗口。升级前可按下方备份说明保存完整数据。

从房间尺寸开始

  1. 点击「开始画平面图」，再点击「完成绘制」，在右侧选择「用长宽快速画房间」。
  2. 输入室内净宽、净深、墙高和墙厚，自动生成房间；也可直接点击画布逐段画墙，连回起点后生成房间。
  3. 点击地面区域，在右侧添加材料，填写实际单价、损耗率和人工单价。
  4. 点击「3D 预览」查看空间。拖动旋转、滚轮缩放，右键或按住 Shift 拖动平移。

房间模板输入的是室内净尺寸。逐段画墙时输入的是墙中心线长度，净施工面积会扣除墙厚。墙未闭合时，先补齐墙线，再生成正式报价。

墙面材料、门窗与开孔

  1. 点击墙线、三维墙体，或展开左侧「墙体」选择目标墙。
  2. 在右侧设置墙长、墙高、墙厚，并为墙面添加材料。可选全部侧面、左侧或右侧，方向按墙起点朝终点确定。
  3. 点击「门」「窗」或「开孔」，填写宽高、距墙起点和离地高度。门扇、窗框厚度独立设置。
  4. 开孔支持矩形、椭圆或自定义多边形。自定义轮廓可重绘并拖动顶点，三维和报价同步更新。

本版本的墙面费用只计算实际裸露的左右侧面，内部重合面不重复计量，独立端面、洞口内壁、墙顶和墙底不计饰面。选中时显示连续完整边界，孔洞留空，右侧立面预览同步显示。转角共面的延续部分归属该侧面，不漏计。例如净尺寸 6 × 4 m、墙厚 20 cm、墙高 2.8 m 的房间，内外侧面合计 116.48 m²；1 × 1 m 贯通孔扣双侧 2 m²。旧项目重新加载后按该口径计算用量，保留用户单价。选中门窗后可在「本体与安装报价」勾选计入预算，并填写用户单价；装饰装修方案清单也会按实际门窗记录分列本体、五金及安装，请核对所采用的计价范围。

装修界面、家具与斜墙

新建户型默认使用自然墙体连接，L 接点斜接、T 分支收齐，避免端帽凸起。旧项目可在左侧「绘图设置 → 整理墙体」升级，并可撤销。该区域还可设置矩形或手绘多边形边界，墙体、区域和家具实际占地不得越界。

在「01 绘图」点击圆工具（C）后依次点圆心和半径；圆弧工具（A）依次点起点、经过点、终点。也可在左侧「圆 / 圆弧」精确输入尺寸。曲线作为整组修改半径、墙高、墙厚并选材报价，不按墙段数重复费用；最大弦偏差 0.5 cm，面积和费用使用实际折线实体计算。圆弧可与直墙连接成房间，当前不提供跨段门窗编辑。

  1. 先画出闭合房间，点击顶部「02 装修」或画布「开始装修」；上传图片或 PDF 后也可进入装修。点击「01 绘图」可继续修改户型。
  2. 左侧「家具 · 设备」提供 93 种预设，包括常用家具家电、九种楼梯以及 35 种水电点位、灯具、智能与暖通设备。使用搜索或分类查找，再在图纸点击放置，按 Esc 取消；预设区可以独立滚动。
  3. 拖动家具调整位置，拖动外侧圆形手柄自由旋转，按住 Shift 以 15° 吸附；右侧可以精确输入角度、尺寸和离地高度。二维、三维均可点选家具查看属性。「复制一件」保留尺寸与单价，生成独立摆放项，新项数量为 1，支持撤销。
  4. 填写同型号数量、单价与本项安装 / 运费。一个图示代表一组同型号家具或设备，数量增加不自动复制摆放；模板只提供尺寸，价格由你填写。
  5. 可以直接画任意角度直墙；按住 Shift 临时锁定水平 / 垂直，也可在底部选择「角度」输入精确方向。选中墙后可在「墙线方向」中修改角度。装修模式禁止绘图快捷键，返回「01 绘图」再继续画墙或修改区域。

家具小计 = 数量 × 单价 + 本项安装 / 运费，安装 / 运费只加一次，税率在项目设置中统一计算。未填单价时不能导出正式报价，明确填 0 为有效价格。家具占地不直接扣除房间面积；配置楼梯口后按实际洞口扣除地面和天花板用量。隐藏仍计价，删除可按 Ctrl+Z 撤销。图片需先校准才显示真实家具尺寸。

本版本的二维 / 三维墙面高亮随右侧「左右两侧墙面 / 左侧 / 右侧」施工范围更新，左右始终相对于墙起点朝终点，不随相机改变。原 8 种 Blender 家具模型与其余 85 种原创参数模型均按真实尺寸显示，包含屏幕、柜门、滚筒、面板插孔、按钮、设备圆形壳体与栅格等外形。楼梯有直跑、平台直跑、L 型左右转、U 型折返、左右螺旋和左右弧形共九种，具有真实踏步、平台、立柱和连续扶手；螺旋与弧梯采用薄踏板及支撑，保留下方空间。软件运行无需 Blender 或网络，尚无 GLB / GLTF 模型导入。斜墙用于平面绘图、三维和材料报价，土建方案仍要求正交户型，可另选矩形方案。

水电点位和实际管线

「水电点位」包含五孔、防水、地插、USB、空调插座和三脚插头，单联、双联、三联、双控及调光开关，配电箱、弱电箱、网络与电视面板，冷 / 热水口、地漏、水阀和分水器。「灯具」包含筒灯、射灯、灯带控制器、壁灯、吊灯和线性灯；「智能与暖通」包含路由器、无线 AP、暖气片、新风口、排风扇、温控器、烟感、智能面板和可视门铃，共新增 35 种设备。

  1. 在「家具 · 设备」选择点位或灯具，在图纸点击摆放；壁装设备靠近墙面时按点击的一侧吸附，背板贴墙，正面朝外。地插、地漏、吸顶设备或远离墙的位置可自由摆放。
  2. 在右侧修改尺寸、角度、离地高度、件数和单价。离地高度是设备底部距本层地面的距离；小型点位在二维有清晰符号方便点选，三维仍保持真实厘米尺寸。
  3. 切换「水电 · 管线」，从 27 种电线、网线、光纤、电视线、给排水、空调暖通、地暖、灯带及自定义预设中选择，逐点画实际走向。端点、设备与墙边提供吸附，Enter 或双击结束，Esc 取消。
  4. 选中线路后拖动节点，也可精确输入位置和离本层地面高度。「添加竖段」可让走顶线路下降至插座；可重绘、删除节点、复制、隐藏或移除，并支持撤销。
  5. 填写材料单价、人工单价、损耗率、并行条数、每条预留长度和本项固定施工费。线路长度使用实际三维折线，不按房间面积猜测；设备按件计价，线路按米计价，价格由你填写。

管线净用量 =（实际路径长度 + 每条预留长度）× 并行条数；采购量再增加损耗。材料按采购量计费，人工按净用量计费，本项固定施工费只加一次。每层独立保存，底部总价合并全楼层设备、管线与其他材料，项目附加费和税只计一次。隐藏仅改变显示；图片未校准时不输出精确长度，单价留空时保留待完善状态，明确填 0 是有效价格。完整项目 JSON、CSV 和打印 / PDF 均保留线路和设备信息。

二楼、Loft 与天花板

  1. 画出一楼户型后，点击画布顶部楼层选择旁的 +，添加空白楼层或复制本层布局。通过楼层下拉菜单切换，最多支持 8 层，各层独立保存墙体、材料和家具。
  2. 二楼可以只画部分面积形成 Loft。编辑二楼时，下层墙体以淡色显示供参考；三维可切换「只看当前层 / 查看全部楼层」。楼层设置可修改层高与楼板厚度，墙高仍可独立设置。
  3. 回到下层「02 装修」，在左侧「楼梯」分类放置预设，在右侧「楼梯连接与扶手」选择「到达楼层」。设置「栏杆扶手」为双侧、左侧、右侧或无扶手，并填写扶手高度；楼梯总升高会随层高更新，扶手高度另算，不改变层间升高。
  4. 填写「洞口留量」，点击「自动匹配楼梯口」，按实际楼梯轮廓生成上层洞口。点击「查看楼梯口」前往上层；移动、旋转或修改楼梯尺寸后，联动洞口同步更新。上层二维显示踏步、上行箭头和来源标记，左侧「通往本层的楼梯」可返回下层编辑；三维「只看当前层」仍显示到达本层的下层楼梯。
  5. 需要独立绘制时，在上层选中房间，使用「楼板与挑空」的「矩形」「圆形」「椭圆」「圆环」或「自由绘制」。矩形、椭圆拖出范围，圆形和圆环从圆心拖出半径；自由绘制逐点圈选并按 Enter 闭合。也可点击「输入洞口尺寸」填写精确尺寸和位置。已有洞口旁的编辑按钮可改尺寸；编辑联动洞口会转为手动，或在楼梯属性点击「改为手动洞口」保留洞形并停止跟随。
  6. 选中房间后切换「地面 / 天花板」，启用天花板、填写离本层地面高度，再添加材料、单价、损耗和人工费。三维隐藏天花板只影响显示，已配置费用仍计入预算。

洞口靠墙或墙角自动吸附，可以贴边，也可稍微画出边界；只扣除房间内实际相交部分，重叠洞口不重复扣量。圆环中央保留楼板，分裂出的楼板仍属于同一房间，材料和固定费用只计一次。完全不相交或移除整个楼板的操作会拒绝，原工程保留。

画布底部报价统一汇总所有楼层的地面、墙面、家具设备、管线和天花板，项目附加费和税金只计一次。同一部楼梯在上下层二维和三维显示，价格只在起始层计一次。完整项目 JSON 保留楼梯参数、联动洞口和全部楼层；CSV 与打印 / PDF 包含各层明细和小计。

市政道路与场地

  1. 点击顶部「04 市政」进入场地工作区。可以创建按真实尺寸绘制的场地，也可以使用已有底图并先完成比例校准。
  2. 从左侧选择道路、交叉口、环岛、河流、桥梁、路灯或其他设施。路线逐点绘制，按 Enter 或双击结束；也可使用「按尺寸添加」输入位置、长度、宽度与方向。
  3. 点击场地项目列表选中对象，拖动节点修改走向，在右侧填写结构层、净尺寸、单价、损耗、人工和固定费用。单位、实际工程量和已填费用实时更新。
  4. 有地形时，左侧「新设施放置高度」可选择「贴合地形」或「手动标高」。选中设施后在右侧「标高与地形」输入米制标高，或使用 ±1 m；「贴合地形 / 设置离地高度」可填写离地高度或负埋深。
  5. 道路可在右侧「设置起终点高度」生成均匀纵坡，也可配置完整纵断面、竖曲线、横坡及边坡。采用新的贴地或起终点设置会替换旧变坡点与竖曲线，可撤销。

上传图纸及设施预设不提供实际市场单价。未校准、地形缺测或单价留空时，应先补齐必要参数，系统不会以随机高程、面积或价格代替真实工程数据。

地形与土方

在市政工作区创建概念地形，或导入测点、栅格 DEM。地形塑形工具可以制作凸起、凹陷和河槽，工程设施与地形共用同一米制高程基准。概念地形用于方案表达；需要实测工程量时应导入测量数据并核对坐标、单位和缺测范围。

道路纵断面、横断面和边坡参数用于挖填方及土方平衡分析。跨道路调配需核对土质系数、运距和施工单价；测量覆盖不足或必要参数缺失时结果保留待确认状态。

穿山隧道：先画路，再设置区间

  1. 在二维选中道路，把道路设置到希望穿山的标高。例如山顶标高为 60 m，道路标高为 30 m，路线才可能位于山体内部。
  2. 右侧「标高与地形」点击「穿山隧道」，勾选「启用此道路的隧道区间」。
  3. 填写「开始里程」「结束里程」「道路以上净空」和「衬砌厚度」，选择「拱形」或「矩形」。里程是从道路起点累计的水平距离，有地形时窗口会给出建议区间供核对。
  4. 点击「应用隧道」。二维显示隧道区间和洞口标记，真实长度和工程量进入保存及报价流程。
  5. 点击右侧「查看道路 / 隧道」，或在三维悬浮栏点击「查看道路」「洞口」「洞内」。查看道路会自动定位，发现被地形遮挡时使用剖视；路面和衬砌使用不同颜色方便分辨。
  6. 需要独立报价时，勾选「独立计入隧道施工费用」，填写每米综合施工单价、人工单价及固定费，再应用。

三维地形可切换「实景」「剖视」「隐藏」。实景保留山顶及真实遮挡，地下道路与隧道主体在俯视时可能被遮住；剖视或隐藏地形可查看它们。这些查看操作不会改变高程、工程量、项目或报价。每条道路当前支持一个连续隧道区间，尚不自动设计围岩支护、洞门、通风消防或结构规范。

管网分析

绘制实际管线及节点后，按现有水力分析入口设置管径、高程、粗糙度、供需、泵阀及控制条件。先检查节点连接和参数，再运行计算；水力分析与按长度计价使用各自的明确输入，不能由报价金额推测供水能力。

使用已有图纸

  1. 点击「上传已有图纸」，选择 PNG、JPG 或 PDF；PDF 可选择要使用的页面。
  2. 点击「校准图纸比例」，选择图上两个已知端点并输入真实距离。
  3. 逐点绘制区域，点击起点或按 Enter 闭合；拖动顶点调整边界。
  4. 为区域添加材料并查看报价。未校准时不生成精确面积。

图片与 PDF 用于二维选区。三维墙体由实际绘制的墙线生成；图纸中的文字、门洞和扫描噪声可能影响封闭区域识别，请核对候选区域。

维护材料价格

点击左侧底部「更新 / 导入材料价格」，可读取官方公开参考报价，或导入地方 CSV、Excel、粘贴表格及网页表格。检查材料、计量单位、地区、日期和来源后再提交。网页读取需要联网，且取决于来源网站是否允许访问。

已保存项目保留原单价。需要更新某个项目的价格时，在材料属性中点击「应用材料库单价」。内置示例材料与参考价格用于熟悉操作，请在正式报价前替换为实际产品和单价。

从户型到总造价：五步走

造价工作台将土建、装饰装修和市政合并为同一份项目清单。

  1. 准备房间。画墙闭合生成户型，或上传图纸、校准真实尺寸并圈选区域。
  2. 生成土建。点击顶部「造价」→「土建」，设置结构、层数、层高和基础，依次点击「生成结构」「生成造价表」。只做装修可跳过这一步。
  3. 配置装修。在「装饰装修」选择房间类型、档次、吊顶和门套等施工范围，再点击「生成装修造价」。「一键精装」使用中档方案；请核对湿区、水电建议点位和各工序实际报价。
  4. 补充室外工程并定价。按需在「市政」输入道路长度或在图纸画中心线，设置横断面、管网、路灯和绿化后生成清单。逐行填写并核对各专业的规格、施工范围和单价。
  5. 统一汇总并交付。回到「汇总」设置措施费率、其他项目 / 暂列金额和统一税率，保存项目，再导出总表 CSV 或点击「打印 / PDF」。

总价按三专业分部分项、已列措施、费率措施、其他费用及规费统一加税。费率措施默认 2.5%，税率默认 9%，均可调整；请按实际计费口径填写。造价总表独立汇总，不再加上图纸底部原材料及家具报价，原报价的附加费和税率也不会自动带入。

待定价项目以 0 占位，当前小计只包含已定价部分。参考单价需按当地信息价及施工报价确认。装修材料供应、基层、人工和安装等分列，请按每行范围报价，材料供应价不能直接当作完整安装综合价。供应数量含约定损耗，面层人工按净面积计算。

点击汇总清单行可查看对应专业明细，「含 N 项估算」可筛选估算项。参数修改后点击本专业生成按钮应用，单价修改即时更新金额；生成后价格覆盖随项目保存。总表与分专业 CSV 保留工程量、规格、来源与估算备注，PDF 通过浏览器打印保存。

多楼层项目中的三专业方案仍按当前层户型和原有参数生成，土建层数只复制一个标准层的方案工程量，基础及土方计一次，不自动创建设计楼层或复制装修房间；全楼层材料、家具设备、实绘管线和天花板报价使用画布底部汇总。三专业方案中的钢筋、水电管线和桥梁使用指标估算；「水电 · 管线」则按你实际画出的三维路径计长报价。当前不进行结构设计、抗震验算或管线综合，不能替代施工图预算与招标控制价。可在各专业页面查看工程量口径与清单备注，核对实际施工范围。

保存、导出与备份

软件自动保存项目，也可点击顶部「保存」。点击文件夹按钮打开项目，点击「导出报价」导出 CSV、打印或保存 PDF，也可导出包含图纸和配置的完整项目 JSON。

交接项目或更换电脑时，先导出完整项目 JSON，再在接收电脑导入。需要完整备份材料库、图纸和全部项目时，退出软件后复制 %LOCALAPPDATA%\PlanMatter 整个目录。不要删除此目录或清除软件的浏览器数据。

若软件提示端口被占用，请先关闭原工作窗口再重开。若不能启动，确认已完整解压、浏览器可用；运行日志位于上述数据目录的 logs 文件夹，可提供给维护人员排查。
