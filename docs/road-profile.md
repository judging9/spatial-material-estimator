# 道路纵断面与路床土方

在原启动方式打开软件后，进入「04 市政」，绘制道路或按实际尺寸添加道路。选中道路，在右侧打开「道路纵断面」。

## 简单的操作流程

1. 在地形编辑中先导入或填写真实测量点，所有 X、Y、Z 都使用米，相对于项目图纸原点。
2. 选中一条道路，点击「设置纵断面与土方」。起点为 0 m，终点为实际中心线路线长度；所有纵断面高程使用绝对米制高程。
3. 修改起终点高程，或点击「添加」插入变坡点。中间节点里程必须严格递增；可在「曲线长 m」填写对称竖曲线长度，0 保持原折线。
4. 查看原地面、设计路面和路床三条线，以及每段实际纵坡。原地面线有缺口表示该位置不在测量地形覆盖范围内，软件不会补造地形。
5. 在「横坡、边坡与曲线精度」按需设置左右横坡；需要变化横坡或超高过渡时开启「按里程设置横坡 / 超高」，填每个里程点的左右百分数，可添加控制点或用「起止过渡」只保留首尾。
6. 需要计算路床及边坡土方时，勾选「计入预算」，自填挖方、填方综合单价。应用后回到工作台，三维路面、边坡和当前市政预算同步更新。
7. 要核对土方供需时，展开「土方平衡与运输」，启用平衡，填写可利用挖方比例、每压实方所需天然方、天然方转松方系数。需要的借料和运输项目分别勾选并填写单价、运距；与原挖填预算开关相互独立。

关闭分段纵坡会恢复道路原统一标高。锁定道路后保持几何不动，已有土方价格仍可调整。变坡点和计价设置随项目保存和完整 JSON 导入 / 导出保留。

## 高程和计量

纵断面里程是沿真实水平中心线累计的距离，斜线、折线均按实际坐标长度计算。未设置曲线时相邻变坡点采用线性高程插值；纵坡 = 高程差 / 水平长度，界面按百分数显示。PVI 是两条切线交点，不代表竖曲线中点的实际路面高程。

设竖曲线长 L、两端切线坡 g₀/g₁，BVC = PVI 里程 − L/2，EVC = PVI 里程 + L/2；曲线上 x = 里程 − BVC，实际高程为 **z = zBVC + g₀x + (g₁ − g₀)x² / (2L)**。导数坡度连续连接切线；界面显示曲线两端切线坡，最大绝对纵坡采用真实导数。中心线设计长度以 `∫ √(1 + g²) ds` 的解析积分求得；图表采样不影响此长度。

左右横坡各自从中线到名义半宽计算，输入单位为百分数；负值向外下降，正值向外抬高。三维路面含真实中线折脊，允许非对称横坡。弯道 miter 边缘仍使用名义半宽高差，以保证共用边缘连续；不提供按设计速度自动生成超高过渡。

「按里程设置横坡 / 超高」对应独立 `crossfallPoints` 表。相邻控制点之间左右百分数分别线性插值，起点固定 0 m，终点与实际路线长度一致；路线改长时所有横坡里程按比例归一，图形反向时里程反序并左右交换。添加点沿已有插值放置，不改变设计；「起止过渡」保留当前首尾值并移除中间点。所有坡度均由用户填写，软件不根据道路等级猜测超高值。

不开启过渡的旧项目继续使用原 `crossSection` 常量配置与既有控制面。开启后常量输入禁用，由过渡表控制路面、横断面预览和边坡；关闭则恢复常量横坡。保存和完整 JSON 保留启用的横坡控制点及单价，锁定道路后可改价格、不能改过渡几何。

道路三维设计面在路线转角和变坡点处分段，截面沿实际道路偏移轮廓生成，使用与场地净面积一致的施工范围。重叠施工面的归属仍由市政几何引擎决定，净轮廓中的内孔也真实扣除。画布缩放和三维相机不参与计算。采样间距只控制纵断面图表的原地面采样密度，不改变精确土方积分。

路面和基层等现有材料仍按水平净面积、用户填写厚度计价。土方单独按实际路床与测量地形的差值计算：

**路床高程 = 设计路面高程 − 主层厚度 − 所有附加结构层厚度。**

计算将道路设计面三角形与测量地形 TIN 三角形按真实平面交集裁分，对各交集内的线性高程差分别积分正负部分。挖方、填方分别累计，不用二者净差代替两种施工量，也不把已经计入材料费的路面 / 基层体积重复当作填土。金额采用现有十进制金额模块，按分汇总。

例如一段 10 m × 2 m 的道路，设计顶面从 −1 m 升到 +1 m，主层 0.1 m、无附加层，原地面为 0 m，则真实路床挖方为 6.05 m³、填方为 4.05 m³。改变图表采样间距不会改变这两个结果。

## 放坡与离散精度

每个控制断面的左右路床边缘沿实际外向射线寻找测量 TIN。挖方侧为 `z = 边缘高程 + 横距 / 挖坡比`，填方侧为 `z = 边缘高程 − 横距 / 填坡比`。射线在每个 TIN 三角形内裁分，并用该三角形的真实仿射高程求第一个交点；覆盖缺口不跨越、不外推，超过用户设置的最大宽度保持待确认。

例如平地上一段 10 m × 2 m 的道路，顶面 1 m、路面厚 0.1 m、双侧填坡 2:1，则每侧找坡宽 1.8 m，路床填方 18 m³、双侧边坡填方共 16.2 m³，合计 **34.2 m³**；填方价 2 元/m³ 时土方价 **68.40 元**。路面材料体积不会再次计入填土。

竖曲线设计面以用户设置的路面高程误差上限控制采样，默认 2 mm，允许 0.1–50 mm；基本曲线弦高项为 `|z″| Δs² / 8`。横坡过渡控制面进一步约束三角形内部的高程误差，避免只检查中线与路缘。

在一个不跨纵坡、横坡或转角节点的区间，参考面为 `z(s,r)=z中线(s)+r·d(s)`，r 为中线至路缘的比例，d 为该侧横坡乘名义半宽。转角 miter 的沿线平面映射为 `X=s+r(a+ks)`。使用的误差上界是：

`E ≤ |z″|Δs²/8 + |d′|Δs/4 + (max|纵坡|+|d′|)|k|Δs / [4·min(1,1+k)]`。

左右两半幅取较大的界，并求解细分数，让区间内全部三角片满足指定上限。第一项为竖曲线，第二项为横坡的面内双线性项，第三项控制 miter 的站距映射；直道 k=0。首尾、横坡点、变坡点、曲线起终点和路线转角都进入真实控制面。折返路缘使 `min(1,1+k)≤0` 时明确拒绝，需要拉长相邻段或缩小路宽。最多 4000 个设计控制断面，超出时提示调整，绝不静默降低精度。该上界适用于本模块的名义半宽断面参考面，不构成连续任意地形土方误差保证。

放坡纵向由独立断面间距控制，默认 2 m，并加入道路节点、竖曲线控制点、路缘与 TIN/净轮廓交点、挖填变号点。横向每个断面的 TIN 求交精确；纵向坡脚之间仍采用三角面片离散。土方对这些指定三角面片与测量 TIN 的差值精确积分，**不等于对任意崎岖连续地形的通用误差保证**。敏感工程应缩小断面间距并比较结果，必要时由专业工程师接坡设计。

同路转角边坡相交时排除冲突片，并保持完整量待确认；边坡与其它道路或边坡相交时本路边坡暂不计量，需统一交接设计。道路净轮廓被其它施工面部分扣减时，也暂不放坡；完全扣空的道路则零量且无额外坡面。软件不会沿已被扣掉的中心线重复收取完整边坡费用。

## 数据缺失与预算状态

未校准的图片道路不输出精确设计面或土方量。地形未完整覆盖道路施工范围时，仅显示覆盖区域的挖填结果及剩余未知面积，保持完整土方预算待确认。空白土方单价表示待填写，明确填写 0 为合法报价；不启用土方计价时，已有路面及结构层预算继续独立工作。

图纸坐标必须经过正确比例校准。地形点使用物理米制坐标，不能把图片像素直接导入为米。高程应统一采用同一测量基准，不能将某一点离地高度当作全项目绝对高程。

## 当前设计范围

本轮实现可编辑的折线 / 对称抛物线道路纵断面、左右横坡、原地面比较、测量 TIN 找坡、真实三维路面与边坡及土方预算。支持最多 100 个变坡点。相邻竖曲线不能重叠或越过相邻 PVI，起终点不能设曲线；极尖回头路线明确提示调整。

尚未提供按等级或速度自动计算超高值、通用交叉口接坡、排水边沟、清表分层、跨道路自动调配或按土质自动推断转换系数等专业设计。纵断面图表不自动判定符合道路等级规范。挖方和填方综合单价由用户明确运输、土质及压实等范围；软件不会自动推断市场价格。

## 单条道路土方平衡与运输

`earthwork-balance.ts` 独立处理供需换算，保留几何引擎的**天然挖方 C**和**压实填方 F**。可利用比例 p 使用百分数，其余两个系数分别是每压实 m³ 所需天然 m³（k）和每天然 m³ 对应松方 m³（s）。三项均由用户填写，不设置土质、压实率、松胀率或运距默认值。p 允许 0–100%，k、s 必须大于 0；数值上限 1000 仅用于防止不可用输入，并非推荐工程参数。

天然方供需按以下公式计算：

- 可利用天然挖方 U = C × p / 100。
- 填筑天然方需求 D = F × k。
- 场内复用 R = min(U, D)。
- 借方 B = D − R。
- 弃方 S = C − R，包含不可利用挖方及剩余可利用挖方。
- 三类运输松方分别为 R × s、B × s、S × s。

因此 R + S = C、R + B = D，不会先抵填再重复借料，也不会把复用土再次计入弃方。当前每条道路独立平衡；即使相邻道路一条全挖一条全填，也不会自动把两者调配，须后续由明确的调配方案处理。

例如仅用于说明算法的一组自填参数：天然挖方 100 m³，压实填方 80 m³，可利用比例 70%，k = 1.1，s = 1.25。得到可用天然挖方 70、天然需求 88、复用 70、借方 18、弃方 30 m³；对应复用 / 借方 / 弃方松方为 87.5 / 22.5 / 37.5 m³。这些数字不会自动填入用户工程。

可单独勾选四项额外费用：借方材料按 **B 天然 m³ × 元/m³**；场内复用、借方及弃方运输分别按 **对应松方 m³ × 自填 km × 元/(m³·km)**。不勾选的项目不要求单价或运距；确认数量为零时无需单价或运距，金额为零，原空单价仍保留。明确填写零单价或零运距也合法。软件不把运输自动加到原挖填综合单价，用户须核对综合单价是否已包含借料、挖运或弃运，避免范围重复。

任何必需系数缺失、测区覆盖不足、边坡冲突或设计源关闭，均使完整平衡量和报价保持待确认。原始已测挖填仍可核查，但不拿部分挖方抵完整填方。一个非零运输项目缺单价或运距时，只影响其费用，已知的其它费用保留；关闭整个平衡模块不会影响原路床和路面计价。

弹窗体积及费用明确对应**单条实绘道路**。项目预算份数先乘各项原始用量，再逐项按分舍入，不能将已舍入的单条小计直接乘份数。例如已验收的 6.05 m³ 天然挖方 / 4.05 m³ 压实填方道路，自填 70%、1.1、1.25，借料 10 元/天然 m³，复用运输 2 km × 0.5 元/(松方 m³·km)，借方运输 5 km × 0.8，弃方运输 3 km × 1.2：单条小计 16.76 元，预算两份为 33.53 元。这是按项金额舍入的正常差异。预算份数不会改变三维道路几何或引入跨路调配。

换算及费用使用精确十进制运算；原始几何在既有九位体积精度边界转为十进制，低于半个量子的小浮点碎片视为零，不能先用 `toFixed` 预舍入。转换参数、计价开关、运距、单价和体积依据均随项目及报价导出保留。几何锁定后仍允许修改这些计价参数，实际顶面、路床和边坡不变；改变价格或系数也不会使几何缓存失效。
