# 高山、山脉与低谷设计

仍使用原来的 `启动.bat` 或 `start-studio.bat`。进入「04 市政」，打开左侧「场地地形」，在「设计高山与低谷」中操作。无需安装额外软件，也可以修改已经导入的测点或 DEM。

## 从预设开始

展开「新建地形与地貌」，选择「高山」「山脉」或「峡谷」，填写场地宽、长、网格间距、基准高程及起伏高度 / 谷深，点击「生成地形」。也保留平地、丘陵、盆地和河谷。

- 高山在基准高程上增加山高；山脉生成连续起伏的山脊；峡谷在基准高程下减少谷深。
- 首次选择高山、山脉和峡谷时，建议起伏分别为 500、300 和 180 m。手动填写过的起伏值会保留，不被切换预设覆盖。
- 基准高程是绝对高程，山高 / 谷深是相对变化。例如基准 20 m、山高 500 m，中心高程最高可到 520 m；谷深 180 m 最低可到 −160 m。
- 「山脉 / 峡谷走向」按平面中的实际米坐标旋转，0° 从左向右，90° 从上向下。地形中心保持不变，长方形场地也保持真实走向。

实际最高、最低高程以生成后的高程范围与剖面为准。山顶位于采样点之间时，最高采样值会低于指定山高；减小网格间距可更准确表达山顶。网格过密会给出明确提示，不会静默改变用户设定的尺寸或高度。

## 在现有地形上塑造地貌

选择「山峰」「低谷」「山脊」或「峡谷」，填写「影响半径」与「山高 / 谷深」，均为米。

1. 山峰、低谷：在预览中点击中心后松开鼠标，一次完成。按住拖动可移动中心并预览形状，松开后提交。
2. 山脊、峡谷：在预览中按住鼠标画路径，松开后一次成形，适合斜向和弯曲的山谷。单段最多 200 个路径点，长地貌可分段绘制。
3. 移动过程只显示草稿，每次从本笔开始前的地形计算。同一条路径交叉或重复经过某处，不会重复增加这一笔的山高或谷深。
4. 按 Esc、取消指针操作或切出窗口，可取消当前一笔。「撤销」恢复前一次生成或塑形，最多保留 20 步。

这些工具以原地面为基准，加高或降低有效高程，边缘连续衰减。它们保留原测点坐标、点编号、DEM 定位及缺失值。若半径内没有有效采样点，操作会明确报错，可以增大半径或移动位置。

原有「凸起」「凹陷」「平整」「平滑」与逐点「河槽」仍可配合使用。它们适合局部修整；河槽可独立设置河底宽、深与岸坡。

## 查看剖面并应用

高程预览下方显示真实高程剖面。切换「左右方向」或「上下方向」，移动鼠标可查看该行或列的地形起伏。横轴为真实距离，纵轴根据当前实际高程范围自动缩放；缺失高程处断开，不补成平地。三维地形使用实际顶点高程，以克制的坡度与高程颜色增强山体表达。

点击「应用地形」才更新工程；关闭窗口放弃草稿。应用后项目的撤销 / 重做、保存、重新打开和完整 JSON 导出沿用原流程。高程变化进入现有道路纵断面、地形三维与挖填计算。

## 范围与验证

自建或塑形地形标记为概念设计或人工塑形，用于方案设计，不替代实测地形。当前不包含地貌侵蚀、河流回水、洪水或动态水流模拟。

自建地形使用等距方格，最多 16384 个采样点；宽、长向上取整到完整网格。采样点从场地起点开始，内插范围终止于最后一个采样点，栅格外缘半个单元格不外推。坐标使用米，高程范围为 −100000 至 100000 m；超出范围的生成或塑形会被拒绝。

计算测试在 `tests/terrain-landscape.test.mjs`，覆盖预设真高度、真实物理旋转、局部形状、交叉路径、NoData、输入不变性、剖面内插以及高程进入三维和精确挖填量。原地形笔刷测试继续保留。
