# 地形文件、横坡过渡与液位自动调度

继续双击 `启动.bat` 或 `start-studio.bat`，进入「04 市政」。本轮新增功能在当前源码中，旧发行 ZIP 尚未更新。

## 导入 GeoTIFF 地形

打开「测量地形」，选择栅格高程，导入 `.tif` / `.tiff`。软件读取真实单波段高程、像元尺寸、NoData 和地理信息，不把普通图片的颜色当作高程。

默认选择放到项目左上角 `0,0`，便于在本地画板开始设计。原地图坐标、投影标识、像元信息及高程缩放参数保存在来源记录中；也可以选择保留原始米制位置。这是明确的平移放置，不是地图投影转换。应用前检查地形与道路是否采用相同的位置、尺寸和高程基准。

文件明确声明米制坐标时可直接导入。缺少单位声明的文件，需要用户实际确认本地米制；明确的经纬度和非米制数据须先在 GIS 中转换。支持范围和格式错误会直接显示，失败导入保留已有地形。

目前支持经典 TIFF、单波段整数及浮点高程、条带或瓦片、无压缩、Deflate 和标准 TIFF LZW，整数水平差分 Predictor 2 与 LZW / Deflate 浮点 Predictor 3。最多 16384 个像元、文件 8 MB；BigTIFF、多页、多波段、旋转或非等距网格、旧 LSB LZW、JPEG/ZSTD 暂未支持。可以在 GIS 中裁切工程范围并导出支持的 GeoTIFF 或 ASC。新增格式的独立参考验证见 [地形兼容说明](municipal-operations.md)。

NoData 继续作为未测范围，不跨缺口填面，也不外推边缘半个像元。地形编辑、三维显示、道路土方及项目保存共用同一实际网格。详细范围见 [地形说明](terrain.md)。

## 设置沿线横坡过渡

选择道路，打开「道路纵断面」，启用横坡里程表。逐行填写里程、左侧横坡与右侧横坡，起点为 `0 m`，终点为道路实际长度；可以使用快捷过渡，再修改其中的设计值。

横坡沿里程线性变化。正值向外升高，负值向外下降，左右以路线起点指向终点为准。例如左右从 `−2%` 逐渐变为 `+2% / −2%`，可表示用户设计的冠形到单向坡过渡。软件不根据道路等级或设计速度自动猜超高。

里程表启用时覆盖原恒定横坡，关闭后恢复原设置。路线改长时，里程表按原比例同步移动，横坡数值保留。实际路面、路床、边坡与土方报价采用同一控制面，修改地面图表采样不会改变计量。

路面高程误差参数同时控制竖曲线与渐变横坡的面内近似精度，达到设计控制断面上限时需要调整参数；复杂折返和无法可靠映射的转角会报错。边坡纵向仍按用户断面间距离散，未覆盖地形和交接冲突保持待确认。详细公式见 [道路说明](road-profile.md)。

## 让水池自动控制泵阀

先在「管网水力」设置真实水池尺寸、液位、需求和设备参数，然后进入「时序分析」，在「液位自动调度」中添加策略：

1. 选择监测水池、控制设备和设备所在管段。
2. 选择「补水 · 低开高关」或「排水 · 高开低关」。
3. 输入低、高液位，阈值必须位于水池范围内，至少相差 `0.001 m`。
4. 启用策略并运行，查看水位曲线与控制动作记录。

两个阈值之间保留当前设备状态，避免在一个水位附近反复开关。同一管段最多启用一条自动策略。定时事件先执行，再由液位规则判断：在滞回带内保留定时设置，到达切换条件时自动规则生效。没有启用策略时继续按原设备状态和定时事件运行。

积分求解实际阈值触达时刻，在该时刻切换设备并重新计算后续流量。日志记录时间、液位、设备和开停原因，时序 CSV 包含控制动作。达到水池上下限时先执行该时刻的事件和液位规则；如果后续流量仍会使储水越界则停止，不补水、不裁切超量储水。

返回编辑器后点击「应用到项目」保存参数。项目保留初始条件与策略，临时曲线和控制日志重新计算。现在还可填写泵的额定转速比例和定时调速事件；自动液位策略仍只控制启停，不自动调节转速。此功能是准稳态管网与储水调度，不包括水锤、重力动态波或自动调压阀。详细计算见 [水力说明](hydraulics.md)。
