# 装饰装修方案估算

本模块使用已有房间、墙体和门窗模型，生成按房间、施工部位分组的装修清单。计算与材料库、页面操作分离；所有金额由统一 BigInt 定点计价内核计算，专业清单不单独计税。

## 三步操作

1. 在绘图工作台画墙闭合生成房间；也可上传图纸、校准真实距离后圈选区域。
2. 打开「造价」→「装饰装修」，为房间选择客厅、卧室、餐厅、厨房、卫生间、阳台、过道或书房，选择简装、中档、精装。多选房间后可批量设置空间类型；单房间可覆盖全局档次。
3. 点击「生成装修造价」，核对工程量，在清单填写实际综合单价，最后到「汇总」统一设置措施费、其他项目费和税率，导出 CSV 或打印 / 保存 PDF。

「一键精装」采用中档方案、保留空间类型、恢复房间跟随全局档次，一次生成。这个名称不代表已取得实际市场报价。输入参数修改后需点击生成应用；有效的参数草稿在专业页签之间切换时保留，正式项目保存的是已生成或已保存的配置。

房间测量可展开查看净面积、边界周长、内墙面积、门窗樘数以及水电点位。内墙缺少实际模型的部分显示估算边界长度。修改几何后，已启用的专业会重新算量；清单行 ID 与房间 ID、工序 ID 绑定，已确认的手工价格继续保留。

## 工程量与做法口径

| 部位 | 工序 | 工程量 | 包含范围 |
| --- | --- | --- | --- |
| 地面 | 水泥砂浆找平 | 房间净面积 | 建议 20 mm 厚；包含基层清理，基层清理不再另列 |
| 地面 | 涂膜防水 | 净面积 + 边界周长 × 上翻高度 | 只用于厨房、卫生间、阳台；默认上翻 0.3 m |
| 地面 | 地砖粘结层 | 净面积 | 不含找平、防水、面层材料和面层铺装人工 |
| 地面 | 楼地面材料供应 | 净面积 ×（1 + 采购损耗率） | 默认损耗 3%；不含找平、粘结层及铺装人工 |
| 地面 | 面层铺装人工 | 净面积 | 材料损耗不扩大人工工程量 |
| 地面 | 踢脚线 | 边界周长 − 落地门洞真实水平宽度 | 门洞宽度按门的真实轮廓，不按椭圆的外包矩形扣除 |
| 墙面 | 基层处理 / 界面剂 | 内墙实际裸露面积 | 与抹灰分列 |
| 墙面 | 抹灰 | 内墙实际裸露面积 | 建议 15 mm；瓷砖区域同样需要抹灰 |
| 墙面 | 腻子两遍 | 涂料 / 壁纸区域净面积 | 瓷砖区域不计腻子 |
| 墙面 | 涂料 / 壁纸 | 内墙净面积 − 湿区瓷砖净面积 | 不含基层处理、抹灰和腻子 |
| 墙面 | 湿区墙砖 | 实际室内左右侧面裁剪到指定高度 | 默认上限 2.4 m，按真实开口形状扣洞；不计独立墙端面及洞口内壁，不含基层抹灰 |
| 天棚 | 基层处理 | 房间净投影面积 | 不含吊顶和灯具 |
| 天棚 | 龙骨 | 净投影面积 | 不含面板、灯具安装和开孔 |
| 天棚 | 面板材料 | 净投影面积 ×（1 + 损耗率） | 默认损耗 5%，不含龙骨、饰面、灯具和安装开孔 |
| 天棚 | 饰面 | 净投影面积 | 包含天棚腻子与乳胶漆；不再单列天棚腻子 |
| 天棚 | 跌级 / 灯槽 | 边界周长 × 0.3 m/m | 初步估算，实际长度需按吊顶图确认；不含灯具 |
| 门窗 | 本体、五金、安装 | 实际门窗数量，分别计樘或套 | 本体不包含五金、安装、门套；可单独启用门套 |
| 水电 | 开关、插座、灯具、给排水点 | 房间类型建议点位，可改整数数量 | 全部标为初步估算 |
| 水电 | 配管 | 净面积 × 面积指标 | 默认 2.5 m/m²，初步估算 |
| 水电 | 配线 | 配管长度 × 导线倍数 | 默认 3，初步估算 |
| 水电 | 给水管 / 排水管 | 每间湿区长度指标 | 默认 15 m / 8 m，初步估算，未读取真实管线路径 |

`FINISH_LAYERS` 包含 `includesBase` 元数据。找平层已包含基层清理、天棚饰面已包含天棚腻子；块料面层和墙面瓷砖不包含基层，因此基层工序单列。若实际承包报价已包含另一条清单的施工内容，应拆分或调整该综合单价后再确认，避免把总包价与分项价同时计取。

净面积和边界周长复用 `regionMetrics`；周长包括内部扣除区域的边界。内部孔洞是否存在需要装修的竖向边界，应按实际方案核对。多边形必须有效且房间净区域不得重叠，重复房间编号、未校准图纸、未闭合墙线不能生成精确清单。

## 实际墙体、门窗与混合区域

实际画墙模型的坐标、墙高、墙厚及开口尺寸以 cm 存储，墙体实体表面坐标以 m 存储。装修墙面只取墙体并集实际裸露的室内左、右侧面，按房间的边界区间裁剪；共墙两侧分别属于相邻房间，高外墙跨多个房间时也分别计量，不把整面墙按中心点分给单个房间。转角处与邻墙侧面共面的短条归入该完整连续侧面，不重复或遗漏；独立墙端面保留真实边界，但不计墙面费用，也不会通过未匹配边界估算重新加入。

门窗洞口已从实际侧面按真实轮廓扣除。洞口内壁保留实体显示，不加入内墙面积、湿区墙砖或涂料用量；墙顶、墙底和独立端面同样不计饰面。一个物理门窗的本体、五金、安装在全工程只计一次，共墙门洞对两边房间的踢脚线均扣减。未能关联房间的门窗不会自动加本体费，页面显示未关联数量提示。

例如净长宽 4 × 3 m、墙高 2.8 m 的房间，未开洞时室内墙面是 `14 × 2.8 = 39.2 m²`；开一处 0.9 × 2.1 m 落地门后，室内墙面是 `39.2 − 1.89 = 37.31 m²`。门的真实洞口内壁不扩大采购和人工用量。

手绘区域没有实际墙体时，按边界周长 × 输入墙高（默认 2.8 m）估算墙面；若只有部分边界匹配实际墙体，匹配部分按实际墙体、剩余部分按输入墙高估算，显示未匹配边界长度并给墙面清单加「估算」标记。由画墙自动生成的房间出现边界与墙体不匹配时会要求重新生成房间，防止把失效几何继续当作精确工程量。

## 档次、材料与单价

档次保留为每个房间的做法选择和报价配置。净面积、周长与公共工序数量不会因选择简装或精装而变化。吊顶、灯槽与门套由独立施工范围开关控制，三档差价需要来自实际材料或施工报价；软件不凭档次编造加价。

地面供应价优先取房间已选的按面积计价材料快照，铺装人工价取同一配置的人工费率；未选材料时，可取生成时保存的材料库瓷砖快照。来源、日期与规格写入备注，Demo 价格标「参考价」。已确认单行价格优先于档次报价，档次报价优先于材料快照。所有缺失价格为 0 且标「待定价」，当前金额只代表已定价部分，不代表完整预算。

「配置不同档次的实际工序报价」可分别填写供应商或施工单位提供的简装、中档、精装综合单价。留空不会生成参考值，明确填写 0 则视为已确认的零价。清单金额 = 当前工程量 × 综合单价；采购损耗已经体现在材料工程量中，不再重复乘损耗。

现阶段地面默认做法按瓷砖找平、粘结、供应、铺装分层。若房间沿用木地板、地毯等已有材料名称和价格，需核对基层与粘结工序是否适用并调整施工报价。门窗本体按实物樘数计，不同规格已写入特征，但同房间同类门窗暂归一行，单价需要按实际规格综合确认。编码是示意编码加分行序号，实际清单规范以当地要求为准。

## 保存、导出与边界

正式参数、工序三档报价、材料快照、手工单行确认价格、启用状态和生成模型保存在 `project.cost.modules.finish`，随完整项目保存与 JSON 导入导出。旧项目没有 `cost` 字段时可正常打开。生成数据不进入几何撤销栈，手工修改单价进入历史。CSV 和打印页继续保留工程量、特征、单价来源与估算标记，统一由总表计取措施和税金。

本模块的水电清单采用净面积和建议点位指标，仍属于方案估算。装修工作台另提供实际设备与线路布置：93 种家具设备含 35 种水电点位、灯具及智能暖通设备；27 种管线路径含电线、网线、冷热水、排水、空调管、新风风管、地暖管、灯带和自定义线材，按真实三维折线长度与用户单价计算。操作见 [室内设备与水电管线](indoor-services.md)。

两种预算口径分别导出；实际点位和路径预算不会自动叠加到本模块的指标估算水电行中。图纸底部及「导出报价」汇总所有楼层的实际材料、设备与管线；造价工作台按启用的专业方案清单汇总。本专业工序仍不包含定制柜体内部结构、异形吊顶结构、暖通系统设计和幕墙，复杂做法可另设材料或自定义设备项。真实平面绘图与三维支持斜墙和圆弧墙，专业方案支持范围以清单参数及生成提示为准。
