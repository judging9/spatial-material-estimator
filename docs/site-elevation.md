# 场地标高与道路贴地

市政道路、桥梁、河流、铺装、管线和设施使用场地的绝对标高。平面位置与高度独立：改变标高不会移动平面路线、改变道路里程或丢失已填的单价。

## 三种简单的高度设置

1. **设置标高 / 整体升降**：输入米制标高，或者整体提高、降低指定距离。已有道路纵断面会整体升降，保留原来的坡差与竖曲线；管线保留节点之间的高度差。
2. **贴到地形**：以对象第一个锚点的真实地形高程为基准，再加相对高度。适合路灯、铺装、桥梁等整体设置。
3. **道路起终点高度 / 随地形**：起终点高度生成一条简单纵坡；随地形依据沿线真实地形生成纵断面。两者会替换原来的变坡点与竖曲线，保留横坡、放坡、采样间距、土方单价和土方平衡配置。

贴地不会自动修改旧对象；只有用户执行操作或创建时选择贴地，才更新标高。地形显示开关、画布缩放和相机位置均不影响计算。

## 高度基准

| 对象 | 输入对应的位置 | 默认贴地偏移 |
| --- | --- | --- |
| 道路、铺装、绿化、路口、环岛 | 顶面 | 0 m |
| 路灯、交通灯、城市设施、护栏、路缘石 | 底部 | 0 m |
| 检查井 | 井底 | −1.5 m |
| 管线 | 管中心 | −0.8 m |
| 桥梁 | 桥面顶面 | +4 m |
| 河流 | 水面 | 0 m |

默认偏移仅是放置初值，用户可以覆盖。它不会确认地基、埋深或排水设计，也不会提供市场价格。道路与桥梁结构层由顶面向下扣除厚度；管井和城市设施从底部向上生成。

已有管线的统一标高可能与首节点中心不同。设置绝对标高沿用原项目的统一基准；贴地使用首节点真实中心，保留原有高差。逐节点匹配埋深会把原节点分别设置为当地真实地形高程加偏移，不新增节点，也不宣称节点之间已完成开挖或水力设计。

## 精度与缺失地形

所有对外设置值与地形坐标、高程使用米；项目中的市政 `elevation` 和管线节点 `z` 保持厘米存储，道路纵断面高程保持米存储。高度范围为 −1000 m 至 +1000 m。非法数字、锁定对象及任何越界节点都会拒绝整个操作，原项目保持不变。

道路随地形使用中心线与真实 TIN / DEM 三角形边界的交点，逐段内插地形高程；每个相邻交点区间都检查中点是否被有效地形覆盖。它不会用粗采样跳过山峰，也不会连接两侧有数据的 NoData 缺口。共线的冗余变坡点只按浮点舍入精度合并。

当前纵断面格式最多支持 100 个实际变坡点。若真实坡折超过上限，操作会拒绝并提示缩小道路范围或降低地形网格密度，不会自动平滑或省略实际山峰。道路贴地只确定中心线高程，完整施工范围的挖填与边坡覆盖仍由现有土方计算独立检查。

属性摘要的地形覆盖和低于地形提示检查控制点及中点，属于采样提示。它不等同于全路线、全路面的连续地形覆盖证书。人工绘制的纵断面也不会被标记为自动贴地。

## 模块接口

纯逻辑位于 `static/studio/lib/municipal-elevation.ts`：

- `setMunicipalElevation(project, id, elevationMeters)`：设置绝对标高。
- `shiftMunicipalElevation(project, id, deltaMeters)`：整体升降。
- `setRoadEndpointElevations(project, id, startMeters, endMeters)`：生成两个控制点的简单纵坡。
- `alignMunicipalToTerrain(project, id, { offset?, follow? })`：首锚点整体贴地；`follow: true` 为道路生成精确地形纵断面，或逐节点匹配管线埋深。
- `terrainReferenceElevation(project, elementOrId)`：首锚点真实地形高程，未校准或无有效覆盖时返回 `null`。
- `municipalElevationSummary(project, elementOrId)`：真实高度基准、锚点偏移与明确标注的采样提示。

所有编辑接口返回项目深拷贝，不改变输入对象；原有来源元数据、单价、损耗、人工、固定费用及道路隧道里程区间保持不变。

单元测试为 `tests/municipal-elevation.test.mjs`。默认验证构建后发布目录的 JS；使用独立构建目录时可设置 `SITE_ELEVATION_BUILD` 为包含 `lib` 的输出目录。
