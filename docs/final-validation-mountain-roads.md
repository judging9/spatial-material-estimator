# 山地道路与设施标高：开发及验收记录

日期：2026-11-08。依据 `next_improvements.txt` 的山地道路遮挡、隧道及便捷自定义高度要求，保留现有 TypeScript、Canvas / WebGL 与 Python 服务架构。

## 完成内容

- 道路、桥梁、管线、路灯、检查井及其它市政设施可按米输入绝对标高、±1 m 整体升降、选择离地高度或埋深并贴地。道路可直接输入起终点高度，生成均匀纵坡；整体升降保留旧变坡点与竖曲线。
- 新建对象支持贴地或手动高度；按尺寸添加窗口也明确提供放置方式，手填高度不会被外部设置悄悄覆盖。道路贴地通过真实地形三角形边交点生成纵断面，保留不可省略的山峰和坡折；缺测、范围或数量上限错误原子拒绝。
- 矩形及分片拱形隧道可设置水平里程区间、净高与衬砌厚度。内外衬砌、开放门户、二维虚线区间及洞口符号由实际路线生成，支持入口和洞内相机定位。
- 地形表面只减去侵入真实隧道净空的部分，山顶、原始 DEM / TIN 与 NoData 保留。实景按真实山体遮挡拾取，剖视及隐藏模式允许实际点击选择地下设施，显示切换不改变工程、预算或保存状态。
- 普通路床挖填排除隧道里程，洞内不生成穿过山体的放坡；仍保留道路铺筑及结构层工程量。隧道施工可按真实三维长度独立计价，材料、人工和固定費分开，用现有十进制金额引擎处理。
- 隧道价格支持现有来源关联和独立调价。手工改价清理旧供应商与日期归因，保留规格、地区和后续可刷新关联。无效参数清空旧计算预览。
- 保存、重开、完整 JSON、CSV 和正式打印报价保留真实隧道几何、计量依据与来源。修复三维导航焦点导致控件宽度变化、地形按钮移位的实际点击问题。

## 当前专业范围

每条道路支持一个连续隧道区间，地形建议取最长连续埋入区间。三维地形为测量 / 用户概念地形表面，未提供岩层实体或自动洞门、支护、围岩、通风、消防及结构规范设计。覆土为中心线真实地形内插提示，不代替全宽勘测；综合单价范围由使用者确认。原启动方式仍为 `启动.bat` / `start-studio.bat`。
