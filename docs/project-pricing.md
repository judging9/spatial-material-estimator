# 批量报价与工程用量

在「工程总览」进入「批量报价」或「工程用量」。两个视图使用同一份真实工程数据，涵盖已汇入项目总预算的装修、土建和市政计价项。

## 填写报价

1. 先在工程中创建对象、设置材料并启用需要计价的项目。未汇入总预算的专业、未启用的计价项不会出现在报价列表里。
2. 有待完善项目时默认先显示这些项目。可通过专业、楼层、单位、状态和搜索缩小范围。
3. 逐行填写单价、人工单价和损耗率，或勾选多个项目统一填写。跨计量单位选中时不能统一金额类字段，以免把元/m²当作元/m或元/kg；只有所选项共同支持的损耗率才能批量填写。
4. 统一填写面板中的空白表示不修改。逐行价格清空是否允许由原计价规则决定：支持待报价的项目会保留并显示待完善；已启用的模板计价不能清空以免被移出预算，可明确填写0保留免费项。
5. 修改先留在报价草稿中。逐行显示原值→新值，底栏显示当前金额和应用后的金额。刚完成补价的行会保留在待完善视图中，方便核对。
6. 核对后点击「应用报价」，全部变更作为一次工程操作应用。之后可一次撤销或重做，再保存工程。

无效数字不会应用到工程。修正输入后才能应用整份草稿。关闭、返回总览或定位对象时，未应用的草稿需要确认放弃；若原工程另有修改，草稿会受到保护并禁止覆盖新数据。

## 核对用量并导出

「工程用量」按实际规格、单位、单价和计价规则归并，保留来源对象。展开分组后可点击来源定位到原对象。分组区分材料、设备、施工、运输等计价类别；采购用量与净施工量分别显示。

用量清单始终反映已应用的当前工程。存在未应用的报价草稿时，视图会提示清单仍是当前工程数据并禁用导出。先应用或放弃草稿，再导出CSV，或通过「打印 / PDF」使用浏览器打印对话框保存PDF。

未确定的工程量或价格会显示待确认状态，已确认部分单独显示。不得把含待确认事项的已确认小计当作最终完整报价。

对于原计价规则确认用量为零、无需报价的项目，空单价显示「零量无需单价」；与有用量但尚未填写价格的项目分别显示。导出始终按当前工程重新计算，过期的缓存预算或清单会被拒绝。

## 计量边界

- 批量报价修改已启用项目的价格和损耗，几何、数量规则及固定费用仍由原工程维护。
- 道路跨路运输单价会参与最小费用调配，改价后路线分配和运输数量会按规则重新计算。
- 「材料与计价主项费」包含材料、设备以及按主项计价的施工和运输费用；它不是只含材料采购的统计口径。
- 未校准区域、无效几何、缺少设计参数或未填写价格会保留相应待完善提示，不会生成猜测面积、用量或价格。
- 未包含、未启用的工程内容须回到原对象中开启；这份列表不代替工程的完整性检查或专业设计校核。

对应纯逻辑模块为`project-price-edit.ts`与`project-quantities.ts`，界面草稿与持久化项目相互独立。后续可在保留这些契约的前提下接入材料数据库、采购系统或服务端存储。

## 验证记录

本轮统一构建与类型检查通过，全量 1080 项单元测试通过。批量报价与用量清单 16 项、工程总览 15 项、原图纸工作台 37 项真实浏览器检查通过，覆盖补价、非法输入、撤销、保存重开、真实 CSV/PDF/JSON 导出及二维、三维操作。新工作台检查了 640、900、1100、1440 四种窗口宽度，保留视觉审查截图。

两层验收工程地砖净量为 16 m²、含 5% 损耗采购量为 16.8 m²；100 元/m² 材料费为 1680 元，25 元/m² 人工费为 400 元。汇入其他装修、土建与市政项，加一次工程固定费及 9% 税后，总预算为 3971.96 元。

验收使用隔离数据，未修改用户工程数据库。230 个生成 JS / source map 文件与实际提供的文件 SHA256 一致。记录见 `artifacts/project-pricing/final-validation.json`，截图与实际导出文件位于同目录。继续使用原启动方式；旧发行 ZIP 尚未更新。
