# 场地预设、道路与河桥

继续使用原来的 `启动.bat` / `start-studio.bat`，进入顶部「04 市政」。没有图纸时，软件自动建立米制空白场地；已有图片仍须先校准比例。新功能在当前源码中，旧发行 ZIP 的功能范围以其版本说明为准。

## 用预设完成第一个工程

左侧「完成工程」提供三步状态：确定真实尺寸、布置场地设施、填写价格与检查。点击「用预设开始场地」，选择方案并设置中心位置、支路延伸距离和车道数：

| 预设 | 实际生成的可编辑对象 |
| --- | --- |
| 十字路口 | 一个四支路路口、四条道路、四套信号灯 |
| 八支路交汇 | 一个八支路路口、八条道路、八套信号灯 |
| 环岛道路 | 一座带真实中心岛孔洞的环形路、四条接入道路 |
| 跨河桥梁 | 一条河流、一座桥梁、两侧桥头道路 |

这些预设只提供可修改的尺寸与布置，所有单价留空。生成会追加到当前场地，整个操作可一次撤销。支路延伸距离表示从场地中心到道路末端的距离；中心位置应给道路和路口留足空间。

选中左侧项目或画布中的设施，右侧修改名称、尺寸、节点与价格。「检查」汇集实际待填价及计量说明，点击条目直接定位到对应设施。全部必要参数确认后，再保存或导出完整报价；空白单价保持待填写，明确输入 `0` 表示确认零价。

在米制绘图工程中，右侧「在三维中定位查看」可一键进入三维并聚焦选中设施。信号灯提供「在三维中查看灯头」，自动面向灯头，方便检查红、黄、绿状态；相机变化不修改工程量或报价。二维总览会优先显示选中设施的标签，在低倍率下隐藏小设施标签并避让重叠文字；放大或选中即可查看细节。

## 道路、路口与信号灯

道路可选择双向 2、4、6、8 车道，分别表示每个方向 1、2、3、4 条车道。总宽按以下用户参数计算：

`道路总宽 = 车道数 × 单车道宽 + 中央分隔带宽`

例如单车道宽 350 cm、中央分隔带 100 cm 时，双向四车道总宽 15 m，双向八车道总宽 29 m。也可选择「按自定路宽」，直接修改总宽。旧工程未配置车道布局时，继续采用原来填写的宽度。

路口的支路数可设为三、四或八。三支路为 T 形，四支路为十字形，八支路每隔 45° 布置；整体旋转可改变朝向。支路过短、路面边界自交或外形超出画板时，软件会拒绝保存该修改并提示调整。

环岛可设置中心岛半径、环形道路宽和支路延伸。环形轮廓采用 128 边圆形控制边界；真实中心岛从路面净量扣除，接入支路与环形路面的重叠不重复计量。二维、三维和报价使用同一几何。

道路标线、通行方向箭头、路口停止线与人行横道用于方案表达，随父设施选中。信号灯可设置朝向和红、黄、绿展示状态，二维与三维同步显示；信号灯按套填写供货及安装价格。本功能不模拟交通流或自动计算信号配时。

## 河流、桥梁和地形

河流沿中心线生成真实廊道。右侧填写宽度、槽深和水面标高，按面积、长度或矩形河槽体积计价：

`河槽估算体积 = 河道净平面面积 × 用户槽深`

选择河流后点击「按这条河流开槽」，设置河岸边坡水平系数。软件沿真实河道路径修改地形；没有地形时建立覆盖河流的平地再开槽，有地形时只降低已知高程，缺测区域不会自动补值。河底目标标高为水面标高减槽深，操作可以撤销。

开槽是一次明确的地形编辑。之后移动河流或修改河深时，可再次开槽；旧槽不会自动填平，可使用地形平整工具或撤销恢复。

桥梁以轴线、桥面宽度、厚度及顶面标高生成三维桥面，可设置中间桥墩间距、墩高和栏杆高。桥梁与地面道路采用独立的施工范围，跨越时不会因平面投影重叠而扣掉桥面量。

桥面主项、桥墩和栏杆可分别计价：

- 桥面按实际面积、主层体积或轴线长度计算，也可添加独立铺装结构层。
- 中间墩按设定的最大间距等分设置在桥梁内部，不含端部桥台；数量为 `max(0, ceil(轴长 / 墩间距) - 1)`，单座桥最多 500 个中间墩。三维中每座墩包含一组墩柱与盖梁，报价按整座填写。
- 栏杆按真实桥面两侧边界长度计米，不包括两端横向栏杆。

新桥默认启用桥墩和栏杆独立报价，价格空白时完整报价待确认。取消某分项的独立报价，表示不另收费，需确认桥面主项综合价格已经包含它。桥墩单价按件、栏杆单价按米填写，属于用户确认的综合供货及施工价。

左侧地形编辑器中的「简单造地形」还可生成平地、丘陵、盆地和河谷。使用「凸起」「凹陷」「平整」「平滑」工具在高程预览中点击或拖动，设置笔刷半径和变化量；「河槽」工具可逐点绘制路径。编辑器内可撤销，确认应用后写入项目。自建和人工塑形高程属于设计方案，应与实测地形区分。

## 保存、导出和计量范围

设施几何、车道布局、支路参数、灯色、桥梁分项价格和地形高程随项目保存。CSV、打印 / PDF 和完整项目 JSON 保留新设施及计量依据，JSON 可以重新导入。市政工作区保留独立预算；也可通过[工程总览](project-overview.md)勾选市政、装修与土建汇入总预算，工程固定费和税金只计算一次。原方案造价总表不自动加入总预算。

当前河槽体积不包含河岸放坡土方、地质分层或水流模拟；桥梁不包含结构受力验算、桥台与基础详算。预设道路和路口属于可编辑的场地方案，不自动保证道路等级、转弯半径、交通组织及安全规范。
