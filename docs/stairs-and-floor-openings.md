# 楼梯与楼板洞设计

源码启动方式保持不变：双击 `start-studio.bat` 或原「启动.bat」。已打开的页面可按 `Ctrl+F5` 加载更新。现有 Windows 1.2.0 ZIP 尚未重新打包。

## 先放楼梯，再匹配楼梯口

1. 在一楼画户型，添加二楼并画出要保留的楼板区域。
2. 回到一楼「装修」，在左侧选择「楼梯」分类并放置预设。
3. 在右侧「楼梯连接与扶手」选择到达楼层。总升高按目标层标高减去起始层标高和离地高度计算。
4. 设置洞口留量，点击「自动匹配楼梯口」。自动选择目标层与梯口相交最多的房间，按楼梯实际轮廓加留量生成洞口，再按房间真实边界裁切。
5. 点击「查看楼梯口」前往上层。移动、旋转和修改楼梯尺寸后，洞口同步更新，洞口编号保留，地面与天花板预算实时重算。

上层没有可开洞的房间时，界面提示先画房间，保留原工程。修改后无法可靠生成地板或扣掉整个房间时，整次操作拒绝并保留原预算。

选「改为手动洞口」会保留当前洞形并停止跟随。删除联动洞会关闭该楼梯的自动匹配；删除源楼梯会移除它生成的洞，撤销同时恢复楼梯和洞口。复制楼层中的洞口转为独立手动洞，避免复制层跟随原楼梯。

## 二楼也能看见来自下层的楼梯

二维在目标层显示真实踏步、上行箭头和「来自一楼」标记。左侧「通往本层的楼梯」可直接返回起始层编辑；也可点击图纸中的楼梯。

三维「只看当前层」仍会显示通往当前层的下层楼梯，保留真实起始标高。点击它会转到来源层选中，保持三维视图。查看全部楼层时，同一部楼梯只显示一份，报价也只在起始层计算一次。

## 九种楼梯与栏杆扶手

当前家具库共 93 种预设，其中楼梯为：

- 直跑、带平台直跑。
- L 型左转、L 型右转、U 型折返。
- 左旋螺旋、右旋螺旋。
- 左转弧形、右转弧形。

宽、深、升高、旋转和离地高度可设置。栏杆支持双侧、左侧、右侧或关闭，扶手高度为 50–150 cm。螺旋与弧梯可调整内圈比例和旋转圈角；螺旋为 180–720°，弧梯为 45–300°。

模型采用真实踏步、转角平台、立柱和连续扶手。螺旋与弧梯使用薄踏板及支撑，保留下方空间。家具高度字段仍代表总升高，扶手高度另加在实际模型上；不把扶手高度计成层间升高。扶手改变外形，楼梯价格继续按用户填写的采购范围和单价计算，不自动编造配件价格。

每部楼梯的费用为「数量 × 单价 + 本项安装 / 运费」。一个图示代表一个摆放项；数量增加不生成额外实例，项目固定费与税在全楼层汇总后只计一次。

## 舒适绘制楼板洞

上层选中房间后，在右侧「楼板与挑空」选择：

| 形状 | 画法 |
| --- | --- |
| 矩形 | 按住起点，拖到对角点，松开完成 |
| 椭圆 | 拖出长宽包围范围，松开完成 |
| 圆形 | 按住圆心，拖出半径，松开完成 |
| 圆环 | 设置内径比例，按住圆心拖出外半径 |
| 自由绘制 | 逐点圈选，点击起点或按 Enter 闭合 |

靠近墙边或墙角时自动吸附。可以贴边，也可稍微画出边界，出界部分会真实裁切；不依靠人为留缝避免报错。完全不与房间相交、无面积或移除整个楼板的操作会拒绝。

「输入洞口尺寸」可直接填写长宽、直径、位置及内径比例。已有洞口旁的编辑按钮可修改尺寸，编号保留；编辑联动洞会先转为手动。`Esc` 取消绘制或弹窗，不留下草稿。删除和修改均可撤销。

## 真实扣量与中央保留岛

地面净面积等于原房间地面减去洞口并集在房间内的实际交集。重叠洞口不重复扣面积；洞口把楼板分成多块时，多块仍属于同一房间，材料和固定费用只计一次。

圆环的中间是保留楼板，采用独立地板片段渲染并加回净面积。螺旋楼梯自动匹配圆环洞，保持中心岛；天花板也沿用同一扣量轮廓。

曲线按最大弦偏差 0.5 cm 的实际多边形计量，二维、三维和报价使用相同坐标。保存保留原房间和洞口数据，地板分片是派生结果，重新加载时重建；项目导入拒绝未信任的派生面积字段。

## 验证与范围

关键测试覆盖贴墙与越界裁切、重叠并集、分裂楼板、中央岛、真实扶手、楼梯升高、移动与旋转联动、同源楼梯显示、十进制报价和保存导出。

楼梯与楼板洞开发轮实际验证：正式构建与 TypeScript 类型检查成功，393/393 项单元测试通过。浏览器主流程 37 项、独立三维流程 14 项、原多楼层流程 17 项及新增楼梯 / 楼板洞流程 22 项全部通过；新增流程无浏览器运行时异常。后端本轮未修改，未重跑 Python 测试。

实际验收中，两层各 36 m²、地面单价 10 元 / m²；直梯宽改为 110 cm 后，自动匹配洞为 120 × 370 cm，扣除 4.44 m²，上层净面积为 31.56 m²。楼梯价格 1000 元及安装费 50 元只计一次，项目总价为 1725.60 元。鼠标移动及旋转 37.27° 后保持真实面积，洞口编号不变。两处重叠手画洞按并集扣除 1.75 m²；穿过房间的 6 m² 洞形成两块真实楼板，但房间材料和固定费仍只计一次。
