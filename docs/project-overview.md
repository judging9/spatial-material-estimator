# 工程总览与总预算

仍使用原来的 `启动.bat` / `start-studio.bat`。点击顶部「工程总览」；较窄窗口只显示图层图标，按钮提示为「工程总览与总预算」。原导出窗口也提供「工程总预算」入口。

## 从设计到报价

总览按当前项目显示四步：确定真实尺寸、绘制与布置、填写材料与价格、检查与导出。点击下一步或专业卡片进入对应工作区。空项目可以直接建立米制画板；市政没有设施时可以选择场地预设。

「待处理」集中列出当前汇入范围的实际缺参数、缺材料、缺单价和墙线问题。「计量说明」保留 Demo 材料、自建概念地形及工程量估算范围。点击对象检查项，会切换到对应专业与楼层、选中对象并居中放大，右侧可继续修改。未启用的门窗本体报价、未配置的墙面饰面不会被擅自加入费用。

底部「批量报价」可集中填写已启用的计价项目，预览后一次应用到原工程；「用量清单」按规格核对净量、含损耗量和来源，并导出 CSV / 打印 PDF。详细操作见[批量报价与工程用量](project-pricing.md)。

预算金额可计算与工程检查完成分别显示。例如仅按件报价的家具已有单价，但图纸还没有比例时，件数金额仍可列示，工程步骤继续提示确定真实尺寸。没有工程内容时总价显示「—」，不会因填写固定费就显示工程完成。

## 选择本次预算范围

装修、土建、市政可以分别勾选汇入。首次默认选择已有实际计价对象的专业；手动修改的范围随项目保存。取消专业只改变本次预算范围，原有对象和价格仍保留。

各专业先按原几何和计价规则计算税前金额。工程总预算采用：

`总税前金额 = 已勾选专业税前金额之和 + 项目固定费`

`税金 = 总税前金额 × 统一税率`

`含税总预算 = 总税前金额 + 税金`

项目固定费与统一税率沿用原项目设置，只在工程总汇中计算一次。区域、构件和计价分项自身的固定费用仍归属原对象。金额沿用十进制计算及整数分汇总，不使用浮点数相加。

原专业工作区的报价继续独立显示，其固定费、税率也沿用项目设置；不要直接把三个专业的含税总价再相加。原「造价」方案总表独立保留，不自动加入工程总预算，避免与实绘工程重复收费。

未填价专业仍在汇入范围时，完整总预算保持待完善，界面与报表明确列出「已定价部分含税小计」。空白单价与明确填写 `0` 的零价是不同状态。未校准的面积、长度和体积继续保持待确认。

## 保存、撤销和导出

总览内的专业范围、固定费、税率、甲方名称、报价编号和备注均进入原保存与撤销流程。可使用总览底部的撤销、重做和保存按钮；保存后重新打开项目可以继续编辑。

CSV 与打印 / PDF 总预算包含已选专业及楼层分项、计量依据、净量与采购量、单价、损耗、人工、对象费用、排除范围和检查说明。对象小计、专业小计与工程总汇是不同层级，不能重复累加。PDF 由原浏览器打印窗口保存。

「完整项目」JSON 保存原图、几何、材料、价格、预算范围与报价信息，同时附带紧凑的总预算快照。计算始终以原始项目数据为准，导出重新计算快照，不能通过修改快照伪造总价。

这一入口帮助完成当前方案和报价，不增加桥梁受力、交通配时或河流水流验算。旧发行 ZIP 尚未更新，当前源码仍沿用原启动方式。

## 验证记录

本轮统一构建、类型检查及全量 1080 项单元测试通过。工程总览 15 项、原工作台 37 项、批量报价与用量清单 16 项真实浏览器检查通过，覆盖补价定位、撤销、保存重开、导出和窄窗口布局。验收使用独立测试数据，未使用用户工程数据库。

工程总览原验收记录见 `artifacts/project-overview/final-validation.json`；本轮综合记录见 `artifacts/project-pricing/final-validation.json`。截图和实际 CSV、PDF、JSON 位于相应目录。
