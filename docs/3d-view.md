# 三维户型与墙体尺寸

先按真实尺寸画平面图，再点击「3D 预览」，即可看到墙体与材料地面。二维墙线、三维模型、地面净面积和材料报价使用同一份项目数据。

## 最简单的开始方式

1. 启动工作台，点击「开始画平面图」。
2. 点击「用长宽快速画房间」，输入室内净宽、净深、墙高和墙厚。例如净宽 4 m、净深 3 m、墙高 2.8 m、墙厚 20 cm，地面净面积是 12 m²。
3. 点击房间添加材料，再点击右上角「3D 预览」。
4. 点击三维中的墙体或地面，在右侧修改尺寸或材料。需要继续画墙时返回「2D 绘图」。

也可逐段画墙：放置第一个墙角，继续点击画墙，或输入下一段的长度与方向。墙线闭合后自动生成房间；未闭合的墙体也能查看三维，但不会生成虚构的房间地面。

## 三维操作

| 操作 | 方法 |
| --- | --- |
| 旋转 | 鼠标左键拖动 |
| 平移 | 鼠标右键拖动，或按住 `Shift` 拖动 |
| 缩放 | 鼠标滚轮，或画布左下角 `+` / `−` |
| 恢复适配 | 点击画布左下角「适配画布」 |
| 编辑单面墙 | 点击实际墙体，在右侧输入尺寸并点击「应用尺寸」 |
| 更换地面材料 | 点击地面，再点击右侧材料卡片 |
| 查看被高墙遮挡的材料 | 点击「低墙查看」；再次点击恢复真实墙高 |
| 查看通往本层的楼梯 | 在楼层下拉菜单选择上层；「只看当前层」也保留下层到达此层的楼梯，点击可返回来源层编辑 |
| 导出视图 | 点击「保存视图」，下载当前三维画面的 PNG |

旋转、平移、缩放和低墙查看只改变展示，不改变项目尺寸、施工面积或报价。低墙模式可以显示房间名称和净面积；左侧「区域名称」控制显示，恢复高墙时标签自动隐藏。

## 设置墙高与墙宽

默认墙高为 **2.8 m**，默认墙宽 / 厚度为 **20 cm**。旧项目中没有墙高的墙体会使用默认高度。

- 单墙设置：点击二维墙线或三维墙体，可修改墙长、墙高和墙厚。墙高支持 **0.5–10 m**，墙厚支持 **1–100 cm**。
- 统一设置：点击画布右上角「墙体尺寸」。选中「同时应用到已有墙体」会统一修改当前所有墙；取消勾选只设置以后新画的墙。
- 修改墙长时，可选择固定起点或终点。相连墙体和 T 接点保持连接；操作支持撤销与重做。

墙长按**墙中心线**计量。快捷房间输入的是**室内净尺寸**。例如中心线长宽 4 × 3 m、墙厚 20 cm，地面净面积是 10.64 m²；快捷房间输入净尺寸 4 × 3 m，净面积是 12 m²。

修改墙高会改变三维高度和已配置墙材的墙面报价，地面净面积保持不变。修改墙厚会更新裸露墙面用量，并重新生成墙内侧净地面区域。墙面材料可按实际面积计价，门窗孔洞按真实轮廓扣除；详细操作见 [墙面材料与门窗开孔](next-improvements.md)。

墙面材料的「全部侧面」只计实际裸露的左、右两侧，独立墙端面、门窗孔洞内壁、墙顶和墙底不加入用量。转角处与相邻墙侧面共面的短条属于该连续侧面，保持完整且不重复。三维高亮和墙面立面预览只显示实际完整边界及孔洞，不显示布尔裁剪碎片的内部接缝；低墙显示使用剖切后的边界，正式报价仍按真实墙高计算。

## 保存与分享

项目会自动保存到当前浏览器的本机存储，也可点击顶部「保存」。墙线坐标、每面墙的高度和厚度、新墙默认尺寸、房间和材料配置，以及全部楼层、楼梯尺寸、扶手参数和联动洞口都会保存。

点击「导出报价」→「完整项目文件」可下载 JSON 并分享给别人。接收者在同一应用中导入后，可以继续编辑二维户型、查看三维模型和计算报价。PNG 保存的是当前三维画面；继续编辑需要完整项目 JSON。

## 当前范围

三维视图支持任意平面角度的直墙、不同墙高和墙厚、多个房间、共享墙、净地面材质和内部孔洞。地面孔洞保持留空，点击孔洞不会误选外围地面材料。隐藏区域会隐藏对应三维地面，墙体仍保留。

上传 PNG、JPG、PDF 后，仍可校准比例、圈选区域、选择材料和导出报价。当前图片识别只提取候选二维区域，**不会自动重建图片中的三维墙体**。要从照片或扫描图开始制作三维模型，需要按照实际尺寸重新绘制墙线。

当前支持门窗及矩形、椭圆、自定义多边形贯通开孔，并可摆放 93 种家具家电预设、修改尺寸与自填价格，详见 [家具与墙面选配](furniture-and-selection.md)。当前已支持圆形墙和圆弧墙，使用最大弦偏差 0.5 cm 的实际墙段生成二维、三维与报价；整组高亮与周长会消除内部接缝，见 [自然墙体与圆弧](natural-walls-and-shapes.md)。当前源码还支持最多 8 个设计楼层、部分二楼 Loft、九种楼梯和可配置高度的天花板，支持当前层 / 全部楼层及天花板显隐，操作见 [多楼层与 Loft](loft-and-furniture.md)。

楼梯包括直跑、平台直跑、L 型左右转、U 型折返、左右螺旋及左右弧形，支持双侧、单侧或关闭扶手和 50–150 cm 扶手高度。二维与三维在上下层显示同一部楼梯，保留真实起始标高，费用只在起始层计算一次。「自动匹配楼梯口」按真实轮廓与洞口留量生成上层洞口，随楼梯位置、旋转和尺寸联动。

楼板洞支持矩形、圆形、椭圆、圆环和自由绘制，以及「输入洞口尺寸」精确设置。贴墙和墙角会吸附，出界部分裁切，重叠洞口并集扣量。圆环中央保留岛与分裂后的地板片段在二维、三维和报价中一致，房间材料及固定费用只计一次。详细操作见 [楼梯与楼板洞设计](stairs-and-floor-openings.md)。通用样条、屋顶和通用三维模型文件导出尚未实现。材料预览用于直观选材，贴图尺寸和外观不作为施工规格。具体单价、损耗与人工费以右侧报价配置为准。

三维视图使用浏览器原生 WebGL，无需安装三维插件或额外下载渲染库。如果浏览器无法启动 WebGL，可继续使用二维设计和报价。三维画布连接中断时，项目数据保留，可切回二维；连接恢复后自动重绘。
