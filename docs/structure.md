# 土建主体结构方案

顶部点击「造价」，打开「土建」页签。设置结构形式、地上层数、层高、基础形式和混凝土强度，点击「生成结构」查看参考柱网与工程量，再点击「生成造价表」。清单综合单价可编辑，修改后按分更新合价。已生成的方案重新生成时保留单价覆盖。

没有平面图时，可直接输入矩形外轮廓长宽。已有图纸必须先校准；墙体户型必须闭合。矩形输入指标准层外轮廓尺寸，与「按长宽画房间」的室内净尺寸不同。

## 外轮廓与层数

墙体平面坐标为厘米。模型以现有净房间与真实墙体占地的平面并集计算标准层投影，重合墙体不重复；正交凹轮廓保留实际面积，内部楼板孔洞扣除面积。内部孔边不当作外墙周长，但计入楼板侧模边界。图纸缩放不会改变工程量，隐藏房间仍保留在计量范围。

参数「层数」表示将一个标准层重复用于方案算量，不生成多层三维建筑。建筑面积是标准层投影乘层数，不能据此声称已按建筑面积规范完成施工图计量。柱网及基坑以外包尺寸作方案参考，凹边界之外的柱和跨越空缺的主梁不生成。现阶段主体结构需要正交平面，斜边可使用用户明确输入的矩形方案。

## 参数

- 结构形式：框架、砖混、框架-剪力墙。砖混柱梁为构造柱、圈梁的参数化方案，未自动设计其布置或截面。
- 地上层数：1–30；层高：2.4–6m。
- 柱边长：250–1200mm；板厚：100–500mm。跨距过大导致参考梁高超过净层高时，要求增加跨数。
- X/Y 跨数：0 为按不大于约6m跨度自动分格，也可输入1–40。柱网中心从外轮廓边缘内移半柱宽。
- 基础埋深：0.2–10m；钢筋含量：0–300kg/m²。
- 框架-剪力墙必须填写混凝土墙总长。软件不从墙的外观判断其结构性质。
- 抗震等级只写入项目特征，不进行抗震或承载力验算。

## 工程量口径

| 分项 | 本阶段口径 |
| --- | --- |
| 平整场地 | 标准层投影，仅计一次 |
| 土方 | 整体外包基坑棱台，工作面每边0.3m、放坡1:0.33、深度=埋深+0.1m；不作为实际独立基坑或土方平衡结果 |
| 回填 / 弃置 | 开挖−基础−垫层；弃置=开挖−回填，未换算松散或压实系数及运距 |
| 独立基础 | 每个柱网节点一个，参考底边不小于1.5m并随柱宽比例放大，高0.5m |
| 条形基础 | 外轮廓周长×0.8m×0.4m；筏板为投影面积×0.4m |
| 垫层 | 基底面积×0.1m，独立/条基/筏板采用各自基底面积 |
| 柱 | 节点数×柱截面²×（层高−板厚）×层数 |
| 梁 | 主梁中心跨度扣柱宽，梁高为跨度/10；次梁净长为主梁净长×1.2、高度按平均跨度/12。只计板下梁身，避免与板混凝土重叠 |
| 板 | 实际标准层投影×板厚×层数。柱已止于板下，板不再重复扣柱体积 |
| 墙 | 外周长+面积/层高×0.5为参考墙长，净高扣板厚、厚0.2m，扣实际门窗轮廓体积；内墙长度仍为指标估算 |
| 框剪墙 | 用户混凝土墙长在方案总墙长中分配混凝土与砌体，洞口体积按长度比例分配，非逐面结构墙详算 |
| 模板 | 柱按四侧、主次梁按板下双侧及底面；板底扣方案柱梁投影并加外边及孔边侧模。次梁投影及接点细部为估算；梁板底投影不重复单列 |
| 钢筋 | 用户kg/m²指标×建筑面积/1000，单位t，非钢筋翻样或配筋设计 |
| 脚手架 / 垂直运输 | 建筑面积方案指标 |

基础、垫层及土方只计一次；地上柱梁板、钢筋等随标准层复制。增加层数不会把基础土方一起乘层数。基础、模板、脚手架、垂直运输等显式措施项目由统一造价汇总分类，不在本模块再计税。

门窗扣量只用于当前户型轮廓，并按参考结构净高裁剪实际开口；用户另外输入矩形方案时，不把原图门窗混入该方案。参考梁高不超过板厚时，不再生成板下梁体积或梁模板。

## 单价与来源

任务书给出的C30混凝土480–560元/m³、模板45–65元/m²、钢筋4200–4800元/t、砌体380–450元/m³区间以中值作参考，并明确标记「参考值，未取当地信息价」。没有给出区间的项目以0作待填写占位，不能当作已完成预算。C25/C35/C40不沿用C30的参考价。

存在匹配单位的非示例材料时，备注记录供货价、来源与日期，综合单价仍为0并标「待定价」，供货参考金额不直接计入合价。材料库材料价不等于含人工机械的完整施工综合价，须取本项施工范围的实际报价后编辑确认。没有匹配供货数据时，可继续使用上述任务书区间中值作为明确标记的参考值。

本模块为后续报价数据接入预留显式元数据：材料 `provenance.priceBasis` 为 `comprehensive-construction` 且 `provenance.taxIncluded` 为 `false` 时，声明该价为包含材料、人工及机械的未税综合施工报价，方可作为综合价参考，仍需核对施工范围。只有材料名称、供应商描述、未知含税口径或明确含税的报价不会触发该规则，避免在统一汇总中重复加税。普通材料库界面仍按供货价格维护；清单行编辑确认是当前直接填写综合施工单价的入口。

价格覆盖保留在项目，材料库后续更新不自动改已保存单价快照。确认单价不改变方案工程量的估算属性。

所有清单编码是任务书中的示意编码，实际以适用地区、项目及现行清单规则为准。所有自动布置及由参数推算的量在界面和导出中标为方案估算。

## 范围

本模块用于方案比选和投资估算，不替代施工图预算、招标控制价、结构设计或施工依据。不做荷载、抗震、配筋、基础沉降、地下室、人防、钢结构、装配式、屋顶、楼梯、斜墙或异形柱。详细梁柱接点、模板接触面、土方调配及钢筋明细需要专项施工图算量。
