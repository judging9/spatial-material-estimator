# 家具、斜墙和精准墙面选择验收

验收日期：2026-11-07。本轮更新当前源码和 `static/studio` 编译产物，原启动方式保持不变；未重新生成历史 1.2.0 Windows 压缩包。

## 实现范围

- 家具在图纸上独立添加、选择和拖动，提供沙发、床、桌、椅、柜及自定义外形。实际宽、深、高与旋转可编辑，3D 使用相同的真实尺寸。
- 单价由用户填写，数量按整数件数计价。家具价格为空时保持待填写；明确填写零价才视为完成。安装 / 运费仅收取一次，家具与材料统一使用十进制定点金额引擎及项目税率。
- 家具不属于面积区域，不扣施工面积，不因隐藏图示而漏计报价。一次拖动对应一次撤销；Esc、失去指针捕获和取消操作恢复原位。校准后超图幅家具保留实际尺寸并可以继续编辑。
- 鼠标可以自由绘制任意角度直墙，Shift 临时约束水平 / 垂直；也可按长度及自定义角度输入。净房间扣除真实墙厚，斜墙实体、开孔和裸露面使用实际几何。
- 左侧 / 右侧施工范围控制同一组实际计价面。2D 高亮这些面在俯视图中的边线；3D 只高亮所选真实表面，排除墙顶、墙底及非墙饰面的门窗实体。
- 保存、重开、撤销、CSV、项目 JSON 和打印 / PDF 报价包含家具数据。价格输入优先展示，尺寸与摆放位于其后；家具名称显示在外形上方。

## 当前边界

家具使用简洁的参数模型，暂不导入 GLB / OBJ 或厂家模型。件数表达同型号采购数量，每条记录只有一个摆放位置；多处独立摆放可分别添加。摆放不进行家具与墙的碰撞约束。未校准图片仅显示家具位置标记，校准后才生成真实尺寸脚印。

本记录是此前家具与斜墙功能的历史验收。该次验收中墙面的全部侧面包含完整洞口内壁；随后「连续墙面与装修模式」更新已改为只计实际裸露的左右侧面，洞口内壁与独立端面不计饰面，详见 [当前装修验收](decoration-acceptance.md)。门窗实体仍按实际深度显示。土建、市政指标估算的适用范围保持原有说明。
