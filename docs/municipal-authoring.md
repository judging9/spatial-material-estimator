# 市政道路与城市设施绘制

继续使用项目原来的 `启动.bat` 或 `start-studio.bat` 启动，在工作台切换到“市政”。场地可以从空白米制画板开始，也可以导入图纸后完成比例校准。

## 画道路并连接路口

1. 在左侧“拖出一条道路”选择双向 2、4、6 或 8 车道。
2. 设置单车道宽和中央分隔带宽；这里的输入单位为米。道路总宽由这两个尺寸和车道数共同确定。
3. 在画布上按住鼠标左键，从起点拖到终点后松开，即可创建一段道路。也可以逐点点击画折线，按 Enter 完成，按 Esc 取消。
4. 起点靠近道路、桥梁端点或路口支路端面时，画布显示连接提示并吸附到真实端点。从路口继续向外画时，轻微的鼠标偏差会沿支路方向对齐，斜向道路也适用。
5. 需要临时自由绘制时按住 Alt；按住 Shift 可以约束绘制方向。选择已有道路后可拖动端点调整连接，右侧节点列表也可以输入精确坐标。

车道快选保留你明确填写的车道数和尺寸。下方“市政设施”中的基础道路、桥梁入口会自动跟随连接口的路宽和车道，独立绘制时使用各自的默认尺寸。

路口支持三、四、八支路，支路数与双向车道数分别设置。选中路口或环岛后可以修改支路长度、旋转角、车道布局及中心岛半径。八支路口需要足够长的支路容纳路宽，尺寸不合理时会提示修改。环岛中心岛从路面净面积中扣除。

未显式选择车道或宽度时，使用基础“道路”或“桥梁”工具会继承连接端口的实际路宽和车道布局；孤立道路默认宽 6 m。使用车道快选则优先保留你明确设置的布局。连接按实际标高判断：新道路的起点可以继承目标标高，已有路线的末端只连接标高相容的设施。桥梁或道路跨越地面设施时，保持正确标高即可分别展示与计量。吸附提供几何辅助，放置后仍需核对工程连接关系。

## 沿实际边界生成路缘石

选中道路或桥梁，点击右侧“沿两侧生成路缘石”，生成独立、可编辑、按米计量的路缘石。选中路口时，同一按钮沿外侧边界生成并保留支路入口。选中环岛后，还可以点击“沿中心岛生成路缘石”。

生成的路缘石位于路面外侧，默认宽 15 cm、高 20 cm、深 30 cm；桥梁旁的路缘石沿用桥面标高。一次生成可以通过一次撤销移除，重做恢复整批。已覆盖的同宽、同标高共线路缘石不会重复生成；隐藏已有路缘石仍视为已覆盖。更改已有路缘石规格或位置后，重新生成前请检查实际重叠。

每段路缘石的材料和人工单价需要自行填写。道路纵坡或横坡导致边缘高程变化时，当前批量生成会提示暂不支持，避免把变高程边界当成水平边界计量；道路和桥梁的连接辅助仍使用实际端点标高。

## 添加城市设施

左侧“城市设施预设”提供 32 种预设，可以输入名称搜索，并筛选交通与停车、街景与绿化、市政配套、公共空间类别。

| 设施类型 | 操作 | 计价依据 |
| --- | --- | --- |
| 长椅、充电桩、树木、候车亭、停车位、消火栓等 | 选预设后点击放置；右侧修改尺寸、高度和朝向 | 按填写的同规格件数 |
| 道路护栏、场地围栏 | 拖画一段或逐点画实际走向，Enter 完成 | 按真实路径长度；也可切换外形体积 |
| 人行道、自行车道、停车场铺装 | 逐点圈选实际范围，点击起点或 Enter 闭合 | 按实际净面积或厚度对应体积 |

设施的二维符号和三维造型随尺寸及朝向同步更新。预设提供的是可编辑的示意尺寸，不带市场价格；三维造型用于布置与预算表达。道路、铺装和绿化的同标高重叠部分按先放置对象归属扣除，不重复计入净面积。

“同规格数量”用于汇总预算，并不自动复制场地中的三维对象。需要表现每个对象的位置时，逐一放置或使用“复制设施”，然后按各对象实际数量填写。护栏长度来自路线，人行道面积来自边界，不能通过修改外包尺寸代替真实图形。

## 填写价格并核对预算

选中对象，在右侧填写材料单价、采购损耗、施工人工和本项固定费。材料费使用含损耗用量，人工使用净工程量：

```text
采购用量 = 净工程量 × (1 + 损耗率 / 100)
材料费 = 采购用量 × 材料单价
人工费 = 净工程量 × 人工单价
本项小计 = 材料费 + 人工费 + 附加结构层费用 + 本项固定费
工程总预算 = 汇入的分项合计 + 工程固定费 + 一次工程税金
```

材料单价空白表示待报价，明确填写 0 才表示已经确认的零价。未校准图纸的长度、面积和体积显示待确认，不输出推测工程量。设施可直接按件报价；涉及真实尺寸的场地仍应确认比例。

例如，净铺装面积 300 m²、材料 45 元/m²、损耗 8%、人工 12 元/m²、固定费 100 元，对应采购量 324 m²、材料费 14580 元、人工费 3600 元、本项小计 18280 元。这是一组操作示例，实际单价由项目负责人填写。

顶部总览入口在市政模式显示为“市政”，可以确认本次汇入的专业、工程固定费和统一税率。“用量清单”按实际规格和原计价来源汇总，可以展开每项来源并定位对象。不同单位的工程量分别列示，金额沿用原分项的舍入结果。

## 保存与交付文件

点击顶部“保存”，将场地、比例、坐标、路口与车道参数、设施朝向和价格保存到本机；通过“打开项目”重新加载。需要在另一台电脑继续编辑时，导出完整 JSON 项目文件，对方启动软件后导入该文件。

顶部“导出”可以下载报价 CSV、完整 JSON，或打开打印报价单并保存 PDF；工程总览的“用量清单”也支持下载用量 CSV 和打印。原来生成的安装包或 ZIP 不会随源码修改自动更新，正式交付前需要重新构建并打包当前版本。

## 开发验收

完成构建后运行，测试期间保持已服务模块不变：

```powershell
node --check tests/municipal-authoring.e2e.mjs
node tests/municipal-authoring.e2e.mjs
```

该套件通过真实文件选择器导入米制场地，用鼠标拖画四/八车道与斜向连接，检查 Alt 绕过吸附、路缘石入口与重复覆盖、整批撤销重做、32 种设施的搜索分类、按件/长度/面积的手动报价、损耗与人工、工程预算与用量清单、保存重开、实际 CSV/PDF/JSON 导出及再导入，以及 1440、1100、900 三种窗口的二维/三维显示。

测试使用隔离的临时服务器与工程存储，结束时关闭浏览器和服务器。默认在 `artifacts/municipal-authoring` 保留截图、输入工程、导出文件、验收报告与清理凭据；失败时保留画面与工程状态。可通过 `PYTHON`、`CHROME_PATH`、`STUDIO_E2E_ARTIFACTS` 指定本机运行环境。
