# 地形兼容、泵转速与道路土方调配

继续双击项目根目录的 `启动.bat` 或 `start-studio.bat`，进入「04 市政」。本轮沿用原画板、保存方式和报价工作流，没有增加运行依赖。

## 更多真实 GeoTIFF 文件

左侧「测量地形」选择栅格并导入 `.tif` / `.tiff`。现在除无压缩和 Deflate 外，也支持标准 TIFF LZW；LZW / Deflate 的 32 位 / 64 位浮点高程支持 Predictor 3，整数仍支持 Predictor 2。条带、瓦片和 TIFF 大小端均可读取。

高程按文件原始值判断 NoData，再应用 Scale / Offset。坐标单位、原始地理原点和本地放置选择继续保留；不推测高程，也不自动转换坐标投影。明确的经纬度或非米制数据须先在 GIS 中转换，缺单位的文件须实际确认本地米制。损坏文件导入失败时保留原项目。

最多 16384 个像元、文件 8 MB、单个解码块 2 MB。仍不支持 BigTIFF、多页、多波段、旋转或非等距栅格、旧 LSB LZW、JPEG、ZSTD、浮点 Predictor 2 和无压缩 Predictor 3。实现与范围见 [地形说明](terrain.md)。

## 泵转速与定时调速

左侧「管网水力」的设备设置中，为泵填写额定流量 / 扬程曲线，再填写「额定转速比例」。允许 10%～150%，旧项目省略该值时保持 100%。停机使用启停开关；不能用 0% 代替停机。清空转速可保存草稿，但不能产生完成的水力结果。

采用理想泵相似定律：`H_s(Q) = s² × H_1(Q / s)`。输入的额定曲线保持原样，当前有效最大流量为 `s × 额定曲线最大流量`，超范围会停止计算，不外推。

时序事件可选择调速并输入比例；在事件的实际时刻切换，重新求解后续流量、压力和储水量。相同时刻的启停与调速分别作用于设备，随后执行液位自动启停规则。液位规则只改变启停，保留当前转速。结果显示当前比例，调速日志可单独导出 CSV，项目保存初始比例和事件，运行结果重新计算。

这是准稳态管网与真实储水质量守恒模型，未模拟水锤、连续自动调压、实际泵效率或电耗。转速改变不会自动新增预算费用。详见 [管网水力说明](hydraulics.md)。

## 道路调配与运输预算

先导入实测地形，画道路并设置真实纵断面。选中道路，进入「纵断面」，展开「土方平衡与运输预算」。依次填写：

1. 可利用挖方比例（0%～100%）。
2. 每压实方所需天然方（大于零）。
3. 天然方转松方系数（大于零）。

这些值来自实际土质与施工方案，软件不预填系数。路床挖方按天然体积、填方按设计压实体积作为输入：

- 可利用挖方 = 天然挖方 × 可利用比例。
- 填筑天然需求 = 压实填方 × 每压实方所需天然方。
- 场内复用 = 可利用挖方与填筑天然需求中的较小值。
- 借方 = 填筑天然需求 − 场内复用。
- 弃方 = 天然挖方 − 场内复用。
- 运输松方 = 对应天然方 × 天然方转松方系数。

勾选需要计入的费用，再填写实际价格和各自运距。借方材料按天然 `m³` 计价，场内复用、借方和弃方运输按松方 `m³ × km` 计价，单位为 `m³·km`。没有勾选的费用不计入，不要求价格；实际零量不要求价格或运距，导出注明「零量无需单价」。

调配按单条实绘道路计算。道路的「预算份数」只倍计计价工程量，不复制几何，也不自动在多条道路间调配。各项先按总工程量乘单价，再按分舍入，汇入市政预算；原挖填综合单价仍可独立启用，请根据报价范围确认两者是否已包含相同费用。

地形未完整覆盖、放坡交点未确定、未校准、转换参数或必要价格 / 运距缺失时，正式总价显示「待确认」。保留其他已知费用，不能用部分挖方抵扣完整填方。关闭纵断面但仍启用调配时，也保持待确认。

调配参数、几何和价格保存到本机与项目 JSON；重新加载后按真实输入重算。25 列 CSV 与打印 / PDF 报价包含天然方、松方、运距、预算份数和计量口径。操作与控制面算法见 [道路纵断面说明](road-profile.md)。
