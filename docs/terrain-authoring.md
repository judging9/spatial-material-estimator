# 简单制作与修改地形

沿用原来的 `启动.bat` / `start-studio.bat`。进入「04 市政」，打开左侧「场地地形」。无需准备测量文件，也可以从平地开始制作方案场地。

1. 展开「新建平地、丘陵、盆地或河谷」，填写场地宽、长、网格间距、基准高程及起伏高度，点击「生成地形」。平地忽略起伏高度；丘陵向上、盆地和河谷向下变化。
2. 选择「凸起」「凹陷」「平整」或「平滑」，在大幅高程预览中点击或拖动。半径和每次最大变化均使用米；平整另填目标绝对高程。拖动按路径间距重复盖章，同一位置静止不会持续改变高程。
3. 选择「河槽」，输入河底宽、深和岸坡水平系数。例如岸坡 `1.5` 表示每下降 1 m，水平过渡 1.5 m。沿河道逐点点击，点击「完成河槽」或按 Enter。Esc 取消未完成路径。
4. 「撤销」恢复本窗口前一次生成、笔刷拖动或河槽操作，最多保留 20 步。点击「应用地形」后才修改工程；此时项目顶部的撤销、保存、完整 JSON 导出按原流程工作。关闭窗口放弃全部草稿修改。

自建地形在来源中标记「自建概念地形（非实测）」，修改已有测点或 DEM 后标记「人工塑形（非实测现状）」。每个高程均来自用户设置与明确的几何运算，预设不随机生成测量结果。地形变更会进入现有真实三维和道路高程、挖填计算；方案挖填不能代替现场测量工程量。

## 数据与计算范围

- 保留 CSV、ASC 和受支持 GeoTIFF 导入、测点表和 DEM 单元格编辑。NoData 始终保留，不由笔刷或河槽填补；在缺失区域无法计算地形高程。
- 自建栅格最多 16384 个高程点，使用等距方格。宽、长向上取整至完整网格，预览会显示最终尺寸。高程点从场地起点开始，有效内插覆盖到最后一个高程点；栅格外缘半个像元不参与外推。
- 凸起、凹陷使用中心最大、边缘归零的连续衰减。平整按最大变化逐步接近目标，不越过目标。平滑使用操作前的邻点高程，防止循环次序影响结果。
- 河槽默认随当前地面降低指定深度；重复、交叉的路径在一次操作内只按最近距离扣除一次。河流属性中的开槽联动还可以指定绝对河床高程，只开挖，不把更低的原地面填高。
- 本工具是可编辑的地形和河床几何建模，不进行河流洪水、水面回水、冲刷或动态水流模拟。
