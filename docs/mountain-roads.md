# 山地道路、隧道与设施标高

继续使用工程目录的 `启动.bat` 或 `start-studio.bat`。本轮延续原 TypeScript / Canvas / WebGL 与 Python 本地服务，不增加运行时工具。

## 使用方式

1. 在市政工作区创建或导入地形。地形、设施、道路纵断面使用同一绝对高程基准，单位为米。
2. 左侧「新设施放置高度」选择「贴合地形」或「手动标高」。有地形时，新道路跟随真实中心线地形起伏；灯杆落地、管线使用预设埋深、桥面使用预设离地高度。没有地形时沿用设施默认标高。
   「按尺寸添加」窗口也可直接选择放置方式。手动模式采用窗口中填写的标高，并同步到左侧作为下一次添加的默认值；贴地模式会明确说明绝对标高输入的适用范围。
3. 选择设施，在右侧「标高与地形」直接输入米值，或使用 −1 m / +1 m。整体升降保持道路各变坡点、竖曲线和管线各节点的相对高度。
4. 「贴合地形 / 设置离地高度」允许填写离地高度或负埋深。道路可沿地形生成真实纵断面；道路起终点高度可直接生成均匀纵坡。两者会替换旧变坡点与竖曲线，横坡、结构层和计价设置保留，可撤销。
5. 选择道路，打开「穿山隧道」。根据真实地形提示核对开始 / 结束里程，设置拱形或矩形、净高与衬砌厚度。未测范围不会生成假高程。
6. 在二维或三维选中道路，点击右侧「标高与地形」最上方的「查看道路 / 隧道」，自动切换到三维并定位；被地形遮挡时使用剖视。三维悬浮栏也提供「查看道路」「洞口」「洞内」，方便查看整条道路或进入隧道。右侧原有「入口查看」「洞内查看」仍可使用。地形可切换实景、剖视、隐藏：实景保留山顶并按实际山体遮挡拾取，地下道路和隧道主体可能被挡住；剖视显示半透明地形，允许选择地下设施。自动定位和显示切换不修改真实高程、工程或报价。
7. 如需隧道独立施工费，启用计费并填写每米单价、人工与固定费。按三维路线真实长度计量；空白材料单价为待填写，0 为有效单价。道路铺筑和结构层费用仍保留，隧道段上方覆土排除在普通路床挖填之外。

## 计算与保存

- 平面路线使用既有图纸尺度。画布缩放不会影响面积、长度、高程或金额。
- 贴地道路取路线与真实地形三角形边的交点，精确保留山峰和坡折；缺测或超过 100 个不可省略变坡点时，整次操作拒绝，不部分写入。
- 隧道里程使用水平累计距离；计费长度使用道路真实三维纵坡及竖曲线积分。衬砌内表面积和净空体积来自实际显示截面与控制网格。
- 隧道净空只裁去侵入的地形表面片段，保留上方山体表面和原始地形数据；不会把山顶挖成沿线明沟。
- 地形剖视为本地显示状态，工程保存继续包含设施几何、纵断面、隧道区间、截面与价格。JSON 重载、预算、CSV 和报价单使用这些真实数据。

## 当前专业范围

这是布置、计量与预算功能。隧道采用用户定义的矩形或分片拱形截面，可表示开放门户及内外衬砌。未自动设计洞门边坡、围岩支护、防排水、通风消防、规范净空或结构承载；应由对应专业确认，综合施工单价包含范围由使用者填写。

一条道路当前配置一个连续隧道区间。地形建议提示最长连续埋入区间，不能替代勘测或认定整条路线可施工。二维平面仍可调整路线，区间里程会随路线总长按比例调整。
