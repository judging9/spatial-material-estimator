# 栅格地形、道路横断面与管网时序

继续使用 `启动.bat` 或 `start-studio.bat`，打开「04 市政」。新配置保存在原项目中，关闭编辑器不会应用草稿。原测点地形、线性纵坡和无设备管网可以继续使用。

## 导入栅格地形

打开左侧「测量地形」，选择栅格模式并导入 ESRI ASCII Grid `.asc`。文件必须包含行列数、原点、像元尺寸和真实高程；允许 `xllcorner/yllcorner` 或 `xllcenter/yllcenter`，支持 NoData。

本轮接受本地米制数据。ASCII Grid 首行为北侧，导入时将北向 Y 转为画布向下的 Y，并保留原始头信息。应用前检查项目左上角 X/Y 和像元尺寸，按实际坐标对齐道路；系统不会猜测经纬度、投影或偏移。

高程位于像元中心，固定相邻三角片构成计算面。NoData 表示未知高程；只有三个有效顶点的三角片参与显示、插值与土方计量，不跨越缺测点填洞，也不外推边缘的半个像元。完整栅格范围与可插值范围分别显示。

最多支持 16384 个像元。完整网格保存在项目 JSON，三维按批次绘制全部真实三角片。超大数据应先在 GIS 中裁切到工程范围。现已另提供单波段 GeoTIFF 子集导入，但不自动转换地图投影；格式与位置选择见 [地形导入说明](municipal-next.md)。练习文件 [演示栅格](../examples/municipal/演示栅格.asc) 为教学数据，不能用于实际工程测量。

## 竖曲线、横坡与放坡

选择道路，打开右侧「道路纵断面」。中间变坡点可填写对称抛物线竖曲线长度，起终点保持真实路线端点。变坡点高程是两条切线的交点高程，曲线通过处的实际路面高程可能不同。长度必须落在相邻变坡点之间，曲线不得互相重叠。

横断面填写左、右横坡百分数：沿路线起点指向终点区分左右，正值向外升高，负值向外下降。例如左右都填 −2，表示路面从中心向两侧下降 2%。用户提供设计值，系统不自动套用道路等级或规范。

放坡可分别填写左右挖方、填方的水平 / 垂直比、最大找坡宽度和沿线断面间距。水平 / 垂直比为 2 表示每升降 1 m 对应水平 2 m。放坡从真实路床边缘出发，与测量地形求交；路床已扣主路面和附加结构层厚度。

竖曲线按独立的弦高误差控制参数构造三角网，放坡沿线按明确断面间距构造。三维与挖填预算使用同一控制面，调整图表采样间距不会改变计量。弦高误差与断面间距属于几何近似精度，会在报价中注明。

没有地形覆盖、超过找坡宽度、边坡冲突或无法可靠处理的部分占地扣减会保留待确认。系统不会把未知边坡当零量输出完整报价。铺装仍按路面净面积计价，边坡只影响相应路床土方；不会重复收取路面结构层费用。

横坡可使用当前道路的常量值，或启用用户里程表线性过渡；操作见 [横坡过渡](municipal-next.md)。暂未自动设计交叉口接坡、挡墙、护坡结构、分级平台或根据道路等级计算规范超高。

## 泵、阀门和储水池

打开左侧「管网水力」，在压力模式下为管段启用泵，填写用户提供的流量 L/s 与扬程 m 曲线。泵曲线应随流量增大而下降，超出已填写曲线范围不外推；停机视为该设备管段隔断。

阀门支持开关及用户填写的节流局部损失系数 K，也可设置止回。它们参与实际水头和流量方程，关闭设备会改变网络连通性。结果区分别显示摩阻 / 局部损失与泵扬程，不能将泵扬程混当损失。

节点可以设为储水池，填写池底标高、水平面积、最低 / 最高水深与初始水深。总水头为池底标高加当前水深；本地用水需求需要明确填写，无需求填 0。

## 运行时序模拟

从水力编辑器进入时序模拟，设置总时长和步长，添加需求、供水总水头、泵启停、阀门或管段启闭事件。界面的时长和事件时间使用小时，输出间隔使用分钟；内部参数和时序 CSV 使用秒。事件发生后条件保持至下一次修改。模拟使用当前编辑草稿，返回编辑器后仍需点击应用才保存。

每一时刻求解压力网，并按储水池真实流入 / 流出积分水位。自适应积分控制误差，空池或满池处记录边界时刻并停止，不凭空补水或裁掉超量水。结果提供水位、流量、压力和守恒检查，可单独导出时序 CSV。

这是准稳态管网与储水池质量守恒的时序模型，适合检查需求变化、设备调度和水位变化。它没有计算管内弹性压力波，不能作为水锤分析；也未接入暴雨产流、重力管网回水和动态波。阀门当前为节流损失与启闭，尚无自动调压 / 限流阀模型。

网络参数、设备和时序设置保存在项目中，结果重新计算，水力分析不会自动添加材料报价或运行费。另可添加低开高关或高开低关的液位自动策略，详细优先级和操作见 [自动调度说明](municipal-next.md)。
