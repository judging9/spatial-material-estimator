# 空间材料估算 · 使用说明

版本：1.3.0，Windows 10 / 11，64 位。

## 启动

完整解压压缩包，进入「空间材料估算」文件夹，双击「空间材料估算.exe」。运行环境已提供，无需安装 Python、Node.js 或 Blender。三维视图需要可用的 Microsoft Edge 或 Google Chrome 及 WebGL。

请保留整个解压目录，不能只复制 EXE。关闭软件工作窗口即可退出，再次启动后点击顶部文件夹按钮打开已保存项目。

## 做一个房间

1. 点击「开始画平面图」，使用室内净尺寸模板，或逐段画墙并闭合生成房间。
2. 选中区域添加地面材料，填写单价、损耗率和人工单价；选择墙体配置内墙饰面。
3. 使用门、窗和开孔工具填写实际尺寸；需要门窗本体报价时启用「本体与安装报价」。
4. 进入「02 装修」，从左侧家具设备库选择并放置对象，修改尺寸、角度、数量和单价。
5. 使用「水电 · 管线」画出实际走向，填写线路的材料、人工和固定施工费。
6. 点击「3D 预览」查看。拖动旋转，滚轮缩放，右键或 Shift 拖动平移。点击三维画布后可用 WASD、空格和 Ctrl 移动，Esc 释放键盘。

每个家具图示对应一组同型号数量；调整数量不会自动复制摆放。设备按件计价，实际管线按三维路径计长，房间面积使用已校准多边形计算。

## 楼层、楼梯和天花板

通过楼层选择旁的「+」添加空白楼层或复制本层，最多支持 8 层。在下层放置楼梯，选择到达楼层并配置尺寸、栏杆和扶手，然后点击「自动匹配楼梯口」。

独立楼板洞可使用矩形、圆形、椭圆、圆环或自由多边形；洞口可以贴房间边界，只扣除实际相交部分。天花板在选中房间后的「地面 / 天花板」中启用、设置高度并选材。三维可选择当前层或全部楼层。

## 已有图纸

上传 PNG、JPG 或 PDF，选择页面后校准两个已知端点的真实距离，再手绘区域或墙线。缩放不会改变真实面积。图纸图片及 PDF 不自动还原三维墙体；三维模型来自实际绘制的几何。

## 道路、地形和隧道

1. 进入「04 市政」，创建按真实尺寸绘制的场地，或上传底图并校准比例。
2. 从左侧选择道路、交叉口、环岛、河流、桥梁或设施。路线逐点绘制，Enter 或双击结束；「按尺寸添加」可精确输入位置和尺寸。
3. 创建概念地形或导入测点 / DEM，使用地形塑形制作凸起、凹陷和河槽。
4. 左侧「新设施放置高度」选择贴合地形或手动标高。选中设施后，右侧「标高与地形」可输入米制标高、±1 m 升降或设置离地高度 / 埋深。
5. 道路可设置起终点高度，或配置纵断面、竖曲线、横坡及边坡，查看实际工程量与土方分析。
6. 选中穿山道路，点击「穿山隧道」，启用区间，填写开始 / 结束里程、净空、衬砌和截面，再点击「应用隧道」。里程按道路起点累计水平距离。
7. 点击右侧「查看道路 / 隧道」，或三维悬浮栏「查看道路」「洞口」「洞内」。查看道路自动定位，必要时切换剖视。
8. 隧道需要报价时，勾选独立计费并填写每米综合施工、人工和固定费。

地形实景保留山体遮挡；剖视和隐藏地形可以查看地下道路及隧道，查看操作不改变项目、高程或预算。道路目前支持一个连续隧道区间。概念地形用于方案表达，实测工程量应使用测量数据并核对坐标及缺测范围。

## 材料价格、预算与交付

材料预设单价用于熟悉操作，可导入地方 CSV、Excel、粘贴或网页表格。正式工程填写并核对产品规格、地区、日期和来源。空白单价与明确填写 0 区分；未校准或参数缺失时不会输出虚假精确结果。

画布项目预算汇总实际绘制的全楼层区域、墙面、天花板、家具设备、管线和市政设施。顶部「造价」工作台的土建、装修和市政方案按自身参数独立汇总，两套汇总不直接叠加。选定计价范围后，保存项目，导出完整项目 JSON、报价 CSV 或打印 / 保存 PDF。

完整项目 JSON 用于跨电脑工程交接。软件自动保存，也可点击顶部「保存」。本机全部数据位于 `%LOCALAPPDATA%\PlanMatter`；退出软件后复制整个目录可备份全部项目、图纸与材料库。

升级时先关闭旧版本，将新版完整解压到新的文件夹并启动。程序目录可替换，用户数据目录独立保留。

部分土建、钢筋、水电和桥梁方案项目使用指标估算。软件不进行自动结构承载力、抗震、围岩支护、通风消防或施工规范设计。详细操作及计量范围见同目录「使用说明.html」。
