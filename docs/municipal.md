# 市政工程方案造价

本文件说明原「造价 → 市政」参数化方案清单。当前源码另外提供顶部「04 市政」独立场地绘图工作台，可实际绘制道路、铺装、管线、井、灯、绿地和路缘石，并自填价格计算预算；操作见 [市政场地设计与预算](municipal-design.md)。两种预算分别汇总，不自动相加。

本专业在现有造价工作台内生成道路、排水、电气、绿化及可选桥梁的方案级清单。输入是米制路线及参数化横断面，不是纵横断面施工设计。

## 三步操作

1. 顶部选择「造价」→「市政」。手工输入道路长度，或选择「在图纸上画中心线」，按校准后的真实比例读取各段长度。
2. 输入红线宽、车行道宽、单侧人行道宽。根据项目需要展开结构层、排水、路灯、绿化和土方措施分组；桥梁默认关闭。
3. 点击「生成市政造价」，查看横断面示意、里程桩号及清单，再逐行填写当地综合单价。修改参数后重新生成，已确认的同一清单单价继续保留。

中心线点坐标、长度和宽度使用 m；结构层厚度为 cm；管径 DN 与实际外径为 mm。红线宽度是范围校验参数，车行道与两侧人行道总宽不能超过它。绿化带使用合计宽度参数，实际位置仍需核对红线。

## 工程量口径

| 项目 | 计算依据 |
| --- | --- |
| 路床整形 | 长度 ×（车行道宽＋2 × 单侧人行道宽） |
| 道路结构层 | 各层铺设面积 × 厚度；厚度由 cm 转 m |
| 沥青按吨计量 | 体积 × 密度，默认 2.4 t/m³ 为任务书给定假设，可在结构层参数中修改 |
| 人行道铺装 | 长度 × 2 × 单侧人行道宽，面层另列，不含已计共用基层 |
| 路缘石 | 两侧长度合计 2L |
| 清表、路基回填 | 有效路幅面积 × 平均清表深度；回填按可修改比例初估 |
| 雨水和污水管道 | 各自按路线长度列项，DN、外径、基础及沟槽分别计算 |
| 检查井 | ceil（长度 / 间距）＋1，两端各一座；长度为零时井数为零 |
| 管道基础 | 长度 ×（外径＋0.4m）× 0.1m |
| 沟槽开挖 | 长度 ×（外径＋0.6m）×（槽底埋深＋0.2m）× 放坡超挖系数 |
| 沟槽回填 | 开挖－管道占位－沟槽内井占位－管道基础，结果不小于零 |
| 余方弃置 | 开挖－回填，未包含运输距离和土质转换 |
| 路灯 | ceil（长度 / 灯杆间距）＋1，双侧布置乘二；长度为零时为零 |
| 电缆 | 长度 × 1.1 余量系数 × 布置侧数 |
| 手孔井 | 每套灯杆一座 |
| 绿化 | 长度 × 绿化带总宽；乔木按网格株距密度，灌木和草坪按 30% / 70%，种植土按 0.3m |
| 桥梁 | 跨度 × 桥宽 × 综合指标单价，默认不生成 |
| 围挡、导行、临排 | 围挡优先采用实测封闭长度，未填时 2L；其余按路线长度初估 |

默认沥青层仅作用于车行道，基层和垫层作用于全路幅，避免与另列的人行道面层重复。每层可选 m²、m³ 或 t；按 m² 计量时厚度只作为项目特征，不额外乘入工程量。

雨水、污水按两条独立路线和沟槽估算，不代表同槽敷设。外径未填时暂用 DN，按真实管材外径填写后重算。井占位只扣计入沟槽范围的体积，两端按半井，井所在区段不再重复扣圆柱管占位。井外扩挖、井体材料与结构做法没有拆分精算，检查井综合单价应明确包含相应施工范围。

里程表按每 100m 分段，最后一段保留实际余长。横断面仅显示所填宽度和结构层，竖向不按比例。

## 价格和汇总

清单采用统一 `CostItem`、BigInt 十进制金额与全项目汇总。市政模块不单独计税。围挡、交通导行和临时排水分类为显式措施项目；总体措施费率另由汇总页显示并调整，避免混入专业分部分项再计算一次。

没有可靠综合单价时显示待填写，默认零金额不是零造价承诺。材料单价不自动冒充含人工、机械和安装的综合单价。桥梁唯一内置参考值取任务书 3000–6000 元/m² 区间的中值 4500，页面和导出都标为参考指标，不能当作当地信息价。

桥梁提示为：按桥面面积综合指标估算，不含征地拆迁、管线迁改、交通导改，误差可达 ±40%，仅用于投资匡算。该提示按任务书给定，不能解读为经过项目校准的准确率。

## 范围

本模块不做纵断面设计、土方平衡调配、管网水力计算、管径选型、桥梁结构计算、交通组织设计、征地拆迁、管线迁改、地铁或隧道。路基土方、管井占位、灯杆布置、电缆余量、绿化密度及桥梁均为方案假设；不能直接用于施工依据或招标控制价。

清单编码为任务书示意编码，实际编码、特征、综合单价和计量规则应以当地采用的规范和工程资料为准。

## 验证

`tests/municipal.test.mjs` 验证 1000m × 12m 路床为 12000m²、4cm 沥青为 480m³ / 1152t、50m 井距为 21 座、30m 单侧灯距为 35 套、沟槽量随管径与埋深变化、空路线无虚构数量、稳定清单与价格覆盖、真实折线长度，以及无效参数拒绝。
