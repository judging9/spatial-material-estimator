# 造价功能总览

空间材料估算 1.2.0 的顶部「造价」入口提供汇总、土建、装饰装修和市政四个页签。先生成所需专业，再核对工程量和实际单价，最后使用统一汇总导出方案造价。1.2.0 已通过独立发行目录的造价流程验收；既有 Windows 1.1.0 压缩包保留原内容，不含新增造价功能。

| 专业 | 输入与输出 | 操作和计算依据 |
| --- | --- | --- |
| 土建 | 正交户型外轮廓或矩形方案、标准层参数 → 基础、梁柱板、模板、砌体、钢筋、土方 | [土建主体结构方案](structure.md) |
| 装饰装修 | 校准后的房间、实际墙体、空间类型、施工范围和档次报价 → 地面、内墙、天棚、门窗、水电 | [装饰装修做法](finish.md) |
| 市政 | 路线长度或校准中心线、横断面参数 → 道路、排水、电气、绿化与可选桥梁 | [市政工程方案造价](municipal.md) |
| 汇总 | 三专业及手工清单 → 分部分项、措施、其他费用、规费、税金、含税小计 | [造价工作台操作与口径](cost-workbench.md) |

使用者的五步流程、保存与备份见 [软件使用说明](client-user-guide.html)。源码启动、构建及测试命令见 [README](../README.md)。

## 共同口径

三专业复用同一份清单模型和十进制金额计算，每行合价按分舍入，再汇总项目费用。单价编辑实时生效；工程量参数修改后需点击本专业生成按钮。造价工作台独立汇总，不再叠加原材料报价，也不自动带入原报价的附加费和税率。

清单单价分为「待定价」「参考价」「已确认」。待定价行以 0 占位，金额只代表已定价部分，不能视为完整预算。参考值和示例材料应换为适用地区、日期、规格及施工条件下的实际报价。材料供应单价不能直接当作包含人工、机械、辅材和安装的综合价；装修供应和安装等分列项目须按各自行范围填写。

总表与分专业 CSV 保留项目特征、工程量、单价、合价、估算和价格备注。打印 / PDF 保留相同依据及估算提示。项目保存包括专业参数、单价快照或覆盖、手工项及统一费率；旧 JSON 没有造价字段时仍可打开，进入造价页显示空态。

## 已知范围

- 当前三维编辑仍是单层正交墙体。土建层数表示复制一个标准层的方案工程量；基础和土方只计一次，装修房间不随之复制。
- 自动柱网、次梁、内部墙长、基坑、模板接点、钢筋指标、水电管长与建议点位、市政土方和桥梁均含方案假设。按图纸坐标计算面积不等于已经完成施工图全专业精算。
- 不进行结构承载力与抗震验算、钢筋翻样、机电管线综合、水力计算或桥梁结构设计。市政不含征地拆迁和管线迁改，装修不含家具、软装及家电等模块文档列出的范围。
- 清单编码为任务书示意，需按当地采用的现行清单规范核对。统一税率和措施费率由用户设置，不自动套用当地计费规定。
- CSV 可直接用 Excel 打开；PDF 通过浏览器「打印 / 保存 PDF」生成。页码排版取决于浏览器对打印页脚规则的支持。

本功能用于方案比选和投资估算，不能替代施工图预算、招标控制价或施工依据。
