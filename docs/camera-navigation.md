# 三维视角移动

使用原来的 `启动.bat` 或 `start-studio.bat` 启动，绘制房间或场地后切换到“3D 预览”。鼠标旋转、右键平移、滚轮缩放和“适配画布”继续可用。

## 用键盘查看工程

点击三维画布，或点击画布左下方的“开始移动”，随后按住：

| 按键 | 作用 |
| --- | --- |
| W / S | 沿当前视角的水平朝向前进 / 后退 |
| A / D | 向当前视角左侧 / 右侧平移 |
| Space（空格） | 竖直上升 |
| Ctrl | 竖直下降 |
| Esc | 释放键盘，停止当前移动 |

同时按两个 WASD 键可以斜向移动，斜向速度经过归一处理。前后移动保持当前高度；观察方向较陡时也不会因为按 W 而直接向地面下钻。键盘同时平移相机与观察中心，鼠标操作仍沿用原来的旋转和平移方式。

速度下拉框提供精细、步行、场地、远景和山地速度，单位为 m/s。默认“自动”依据实际场景尺寸和当前查看距离调整：看整个场地时移动较快，定位长椅、房间或小设施时自动降速。“适配画布”和对象属性中的“在三维中定位查看”可以快速回到工程或目标。

## 输入与保存

移动仅在三维画布获得焦点时生效。点击项目名称、属性输入框或其他控件后停止移动；打开设置等对话框、切回二维、离开窗口或按 Esc，也会清除当前按住的键。返回画布后重新按键即可继续。

Ctrl+S 保存，Ctrl+Z 撤销，Ctrl+Shift+Z 重做继续保留。输入框中的 W、A、S、D 正常作为文字输入。未聚焦三维画布时，原有 W 画墙快捷键继续可用。

键盘查看只改变当前视角，不修改墙体、区域、道路、设施、材料价格或工程预算，也不会产生工程的未保存改动。此功能提供自由查看辅助，当前不进行人体与墙体、地形的碰撞检测。

## 开发验收

完成前端构建后运行，测试期间保持已服务的模块不变：

```powershell
node tests/camera-navigation.e2e.mjs
```

套件使用真实文件选择器和房间模板建立场地、房间，以实际键盘事件验证相机方向、竖直位移、速度、WebGL 像素变化和预算保持；检查输入、保存撤销、对话框、二维切换、Esc 和真实窗口失焦时没有按键残留，并检查 1440、1100、900 三种视口的工具布局。

部分无界面 Chromium 会将所有标签页视为聚焦。套件会尝试关闭浏览器焦点模拟，再激活另一个真实标签页；如果环境仍未产生真实失焦或页面隐藏，会在 `acceptance.json` 和 `run-receipt.json` 的 `limitations` 中注明该子项未完成浏览器验证，只由控制器测试覆盖，不计作浏览器通过项。不会伪造失焦事件。

所有工程使用隔离临时数据库和浏览器存储，不修改实际用户项目。默认在 `artifacts/camera-navigation` 保存输入文件、截图、结果和服务清理凭据；运行环境可通过 `PYTHON`、`CHROME_PATH`、`STUDIO_E2E_ARTIFACTS` 指定。
