## 启动

推荐 Windows 10/11、64 位 Python 3.11 或更新版本，以及当前版本的 Chrome / Edge。PNG/JPG 解码和 PDF 渲染使用 Windows 原生组件；自动识别封闭区域还需要 NumPy。

```powershell
python -m pip install requests openpyxl numpy
python app.py --port 8770 --no-auto-update
```

启动后打开 <http://127.0.0.1:8770>，也可双击 `start-studio.bat`。新工作台推荐端口为 8770；`app.py` 和原 `启动.bat` 的默认端口仍为 8765。首次使用自动识别前请先安装上述依赖。关闭命令行窗口或按 `Ctrl+C` 退出。

| 地址 / 参数 | 用途 |
| --- | --- |
| `/`、`/studio` | 图纸材料工作台 |
| `/legacy` | 原报价单、材料库、价格更新和抓取源 |
| `--port 8766` | 更换本地端口 |
| `--no-browser` | 不自动打开浏览器 |
| `--no-auto-update` | 不启动旧版后台价格抓取，适合完全离线操作与测试 |

```powershell
python app.py --port 8770 --no-browser --no-auto-update
```

图纸解析、区域编辑、项目保存和报价计算在本机完成。默认后台价格更新会访问国家统计局公开数据源；可以用 `--no-auto-update` 关闭。服务默认只监听 `127.0.0.1`。

## 做第一份图纸报价

### 从画墙开始（推荐）

1. 点击首页「开始画平面图」。不用上传图片，也不用校准比例。
2. 点击画布放置第一个墙角，继续点击画墙，支持任意角度直墙，并自动吸附端点和墙上的连接点。按住 `Shift` 临时锁定水平 / 垂直方向；也可在底部输入下一段墙的真实长度与方向，选择「角度」输入精确方向后点击「画下一段」。未选起点时从画板内的默认起点开始。
3. 墙线连回起点后自动生成房间，点击「完成绘制」或按 `Enter` 结束墙链。继续画分隔墙，可以将空间划为多个房间。
4. 完成户型后点击顶部「02 装修」或画布「开始装修」，选家具预设、点击图纸放置，再填写尺寸与价格。点击房间添加材料；点击墙线可编辑长度、墙高和墙厚。修改长度时会保持相连墙体及 T 接点的连接，面积和报价同步更新；需要继续画墙时点击「01 绘图」。
5. 也可使用「用长宽快速画房间」输入室内净宽、净深、墙高和墙厚，自动生成四条墙。

墙长输入指墙中心线长度，施工面积按墙内侧计算。例如中心线 4 × 3 m、墙厚 20 cm，净面积是 10.64 m²；快捷模板输入净尺寸 4 × 3 m，则净面积为 12 m²。墙未闭合或无法可靠计算墙厚时显示原因并暂停对应报价。房间拆分会继承材料单价，手工数量需重新填写；合并不同材料的房间会要求重新选材。

当前源码支持任意角度直墙、共享墙、T 接点、交叉分隔墙及内圈孔洞。选择墙体可添加门、窗及矩形、椭圆或自定义多边形开孔，墙中心线仍保持连接。已支持圆形墙与三点 / 参数圆弧墙，按整组管理、选材和报价；通用样条暂不支持。左侧「绘图设置」可定义矩形或不规则边界，并为旧项目整理墙体连接。墙厚过大、区域分裂、内部死端、零宽墙桩、同一直边厚度突变等无法可靠生成净轮廓的情况会明确报错。斜墙房间按真实墙体占地扣除净面积，不使用包围盒近似；土建方案算量仍要求正交户型，斜墙项目可另选矩形方案。画板初始覆盖 24 × 18 m，最多 200 段墙线。

新平面图默认采用自然墙连接，斜墙 T 接点在主墙近侧收齐，避免多余突出块。旧项目保留原连接方式，可点击「整理墙体」升级并撤销。绘图边界检查完整墙厚、接点和家具占地，越界操作整次拒绝。圆形墙两击完成，圆弧墙三击完成；曲线按最大弦偏差 0.5 cm 的实际折线计量，整组材料与固定费用只计一次。操作及验证记录见 [自然墙体、边界与圆弧](docs/natural-walls-and-shapes.md)。

### 查看三维户型

点击画布右上角「3D 预览」，可直接旋转查看墙体与材料地面。拖动旋转，右键或 `Shift` 拖动平移，滚轮缩放；点击墙体修改尺寸，点击地面选择材料。返回「2D 绘图」即可继续画墙。

「墙体尺寸」可统一设置墙高和墙厚，也可取消「同时应用到已有墙体」，只设置以后新画的墙。默认墙高 2.8 m、墙厚 20 cm；旧项目自动兼容。墙高会更新已配置墙材的墙面报价，地面净面积保持不变；墙厚会重新计算墙面及地面用量。「低墙查看」方便查看室内材料，不改真实墙高；「保存视图」导出当前三维画面为 PNG。

三维模型由用户实际绘制的墙线生成。上传的图片或 PDF 仍使用二维圈选与报价流程，当前不会自动推断三维墙体。三维视图需要浏览器支持 WebGL。详细操作与范围见 [三维使用说明](docs/3d-view.md)。

### 墙面材料、门窗和价格更新

展开左侧「墙体」后选择墙，在右侧添加墙面材料，选择「左右两侧墙面」、左侧或右侧。左右相对于墙起点朝终点的方向，与屏幕或相机方向无关；二维与三维高亮随右侧施工范围更新。用量只计真实裸露的左右侧面，剔除相接和重合的内部面，并扣除实际门窗孔形；独立墙端面、洞口内壁、墙顶和墙底保留实体显示，不计饰面。共面的分片合为完整轮廓，孔洞留空，不显示内部裁剪接缝。转角与邻墙侧面共面的部分归属该连续侧面，不漏计、不重复。图纸工作台的原材料报价不单独计门窗本体；1.2.0 装饰装修清单会按实际门窗记录，分列本体、五金及安装。

例如净尺寸 6 × 4 m、墙厚 20 cm、墙高 2.8 m 的闭合房间，双侧面积为 `(内周长 20 + 外周长 21.6) × 2.8 = 116.48 m²`；1 × 1 m 贯通孔扣双侧 2 m²。旧项目加载时按当前口径重新计算墙材用量，保留几何、配置与用户单价。

左侧「更新 / 导入材料价格」提供官方报价读取以及地方 CSV、Excel、粘贴和网页表格导入，预览确认后写入材料库。保留来源、地区、日期和原始单位；已有项目保留单价快照，点击属性面板「应用材料库单价」才更新。详细流程见 [材料价格、墙面报价与门窗开孔](docs/next-improvements.md)。

### 摆放家具与按件报价（当前源码）

画出闭合房间后进入顶部「02 装修」；图片或 PDF 可在上传后进入。左侧「家具 · 设备」提供 93 种预设，包括常用家具家电、九种楼梯以及 35 种水电点位、灯具、智能与暖通设备，支持分类筛选与搜索，预设区可独立滚动。点选后在图纸点击放置，`Esc` 取消。拖动二维家具调整位置，拖动外侧圆形手柄自由旋转，按住 `Shift` 以 15° 吸附；右侧可精确填写尺寸、角度、离地高度、同型号数量、单价及本项安装 / 运费。三维中也可点选家具查看属性。「复制一件」保留尺寸与单价并生成独立摆放项，可撤销。模板只提供可修改的尺寸，不提供价格，一个图示代表一组同型号家具或设备，增加数量不会自动复制摆放实例。

家具设备材料费按数量 × 单价计算，本项安装 / 运费只加一次，与区域材料、墙面和管线报价一起计入画布底部项目总价，项目税率统一计算。家具不改变房间净面积；隐藏只影响显示，仍计入报价。未填写单价时标为待填，不能导出正式报价；明确填写 0 为有效单价。图片图纸须校准后才显示真实家具尺寸，未校准时仅显示位置标记。保留八种通过本机 Blender 5.2.3 LTS 生成的原创本地模型，建模源为 `development_assets/furniture-presets.blend`；其余 85 种使用原创参数几何和 SVG 缩略图，包含屏幕、滚筒、柜门、真实楼梯踏步以及面板插孔、按钮、栅格和设备壳体。软件运行无需 Blender 或网络，尚未提供 GLB / GLTF 模型导入。操作、公式与功能范围见 [家具、斜墙与选中高亮](docs/furniture-and-selection.md)及[多楼层、Loft 与家具家电](docs/loft-and-furniture.md)。

### 插座、电线、网线与室内设备（当前源码）

「水电点位」提供五孔、防水、地插、USB、空调插座和三脚插头，单联、双联、三联、双控及调光开关，配电箱、弱电箱、网络 / 电视面板、冷 / 热水口、地漏、水阀和分水器。「灯具」提供筒灯、射灯、灯带控制器、壁灯、吊灯和线性灯；「智能与暖通」提供路由器、无线 AP、暖气片、新风口、排风扇、温控器、烟感、智能面板和可视门铃。这 35 种新设备只提供建议尺寸和安装高度，价格由用户填写。

小型点位在二维显示清楚的符号并便于点选，三维仍保持真实厘米尺寸。原生平面图中，壁装设备靠近墙时按点击侧吸附，背板贴墙，正面朝外，宽度沿墙；远离墙面或地面、吸顶设备可自由摆放。离地高度指设备底部距本层地面，可随时修改。

切换「水电 · 管线」，从 27 种电线、网线、光纤、同轴线、给排水、空调暖通、地暖和灯带预设选择线材，也可用自定义线材 / 管道。逐点画实际走向，`Enter` 或双击结束、`Esc` 取消；端点、点位与墙边提供吸附。节点可拖动并精确输入坐标、高度，也可添加竖向段。路径按真实三维长度计算，净用量含每条预留和并行条数，采购量再计损耗，材料费、人工费和固定施工费分别填写并实时汇总。设备按件、线路按米，不从房间面积推测长度或填入市场价格。各层独立保存，项目 JSON、CSV 和 PDF 保留线路及设备报价；隐藏不免除费用。详细公式与范围见 [室内设备与水电管线](docs/indoor-services.md)。

### 二楼、Loft 与天花板（当前源码）

画布顶部楼层选择旁的 `+` 可添加空白楼层或复制本层布局，支持最多 8 层，各层独立画墙和装修。二楼只画部分户型即可形成 Loft，二维保留下层淡色参考，三维可切换当前层或全部楼层。楼层设置可修改层高与楼板厚度；层高决定上层标高，墙高仍可独立设置。

在下层放置九种楼梯之一并选择目标层，升高随层高自动更新，扶手可选双侧、单侧或关闭。点击「自动匹配楼梯口」生成随楼梯位置、角度和尺寸同步的上层洞口；上下两层的二维和三维均显示同一部楼梯，预算只计一次。手画洞口支持拖拽矩形、圆、椭圆、圆环和自由多边形，贴墙吸附、真实裁切、重叠去重，圆环中央保留楼板。房间属性的「地面 / 天花板」可启用天花板、设置高度并配置多项材料。底部报价统一汇总所有楼层，项目附加费与税金只计一次；JSON、CSV 与打印 / PDF 保留各层配置和明细。详细操作见 [Loft 使用说明](docs/loft-and-furniture.md)和[楼梯与楼板洞设计](docs/stairs-and-floor-openings.md)。

### 使用已有图片或 PDF

1. 点击「上传图纸」或拖入 PNG、JPG、PDF，文件上限 64 MB，图片上限 3200 万像素。PDF 可选择页面，每次编辑一页。
2. 点击「校准图纸比例」，优先使用两点校准：选两个已知端点，输入实际距离。也支持比例尺与 DPI、已知实际宽度。
3. 使用「绘制区域」逐点圈选空间，点击起点或按 `Enter` 闭合。选中区域后可拖动和删除顶点，使用「绘制孔洞」扣除柱、井等不施工部分。
4. 为区域添加材料。可按净面积、边界周长或手工数量计量，设置材料单价、损耗、人工单价及附加费。
5. 在「管理材料库」中建立自己的材料、产品图和价格；内置木地板、瓷砖等均标为示例材料，价格仅供演示。
6. 查看底部报价汇总，设置项目附加费和税率，然后保存或导出。

画布缩放和平移不会改变原图坐标、面积或报价。未校准时，依赖实际面积/长度的用量和金额保持待确认状态；有待确认用量的项目不能导出正式报价。

### 封闭区域识别与 PDF

「识别封闭区域」对当前图像的真实像素进行灰度阈值、轻微闭合处理、白区连通分量和边界提取，返回可编辑的候选多边形及孔洞。需在预览中确认后加入项目；空白图或未闭合图可能返回零个候选。

该功能不会读取墙体语义、标注尺寸、材料类别或 CAD 图层。门洞、大缺口、扫描阴影、密集文字、页框和线条断裂会造成漏检或误检；线条支持度仅用于辅助判断，结果应逐一核对，也可直接手动圈选。

PDF 使用 Windows `Windows.Data.Pdf.PdfDocument` 逐页栅格化，元数据取保存图像的真实像素尺寸，避免显示 DPI 导致边界错位。切换 PDF 页面会重新开始该页的区域和校准；先保存已有项目。图片经过缩放或重新扫描后，原比例尺可能失效，DPI 不明确时使用两点校准。

## 报价与导出

### 从户型到总造价

1. 画墙闭合生成房间，或上传图纸、校准并圈选区域。
2. 点击顶部「造价」，在土建设置标准层与基础参数，依次点击「生成结构」「生成造价表」。只估装修时可跳过土建。
3. 在装饰装修页核对房间类型、装修档次和施工范围，点击「生成装修造价」或「一键精装」；后者使用中档方案，不会自动编造档次单价。
4. 如有室外工程，在市政页设置路线长度、横断面和施工范围，再生成市政造价。逐行确认各专业工程量、规格及综合单价。
5. 回到汇总页设置措施费率、暂列金额与统一税率，保存项目，再导出总表 CSV 或打印 / 保存 PDF。

总造价独立汇总这三份清单，不再加上画布底部原材料及家具报价；原报价中的附加费和税率也不自动搬入造价总表。装修材料供应与安装人工、基层等工序分列，应按每行范围填写对应单价。多楼层项目中的三专业方案仍按当前层户型和原有参数生成；土建「层数」只复制标准层的方案工程量，不自动创建设计楼层或复制装修房间。全楼层材料、家具和天花板报价使用画布底部汇总。完整费用公式、单价状态与操作说明见 [造价工作台](docs/cost-workbench.md)。

### 原材料报价

```text
净面积 = 外轮廓面积 − 孔洞面积
采购量 = 净用量 × (1 + 损耗率 / 100)
材料费 = 采购量 × 材料单价
人工费 = 净用量 × 人工单价
家具材料费 = 同型号数量 × 家具单价
家具小计 = 家具材料费 + 本项安装 / 运费
管线净用量 =（真实三维路径长度 + 每条预留长度）× 并行条数
管线采购量 = 管线净用量 ×（1 + 损耗率 / 100）
管线小计 = 管线采购量 × 材料单价 + 管线净用量 × 人工单价 + 本项固定施工费
税前小计 = 所有楼层区域、墙面与天花板材料费 + 人工费 + 家具设备小计 + 管线小计 + 各项固定费用 + 项目附加费
含税总价 = 税前小计 + 税前小计 × 税率 / 100
```

金额使用十进制计算并按分舍入。已有区域保存材料单价和损耗快照，之后修改材料库价格不会自动改变已有报价。

「导出报价」提供：

- **完整报价 CSV**：按楼层标注区域、墙面、天花板、家具设备和管线明细，记录净面积或真实长度、采购量、损耗、单价、人工、固定费用及税额，包含各层小计，可用 Excel 打开。
- **打印 / 保存 PDF**：报价页包含各楼层平面示意和明细，在浏览器打印对话框中选择「另存为 PDF」。如未打开报价页，请允许本地站点弹出窗口。
- **完整项目 JSON**：包含当前页图像、比例、全部楼层几何、家具设备摆放、管线节点、楼板洞、天花板与报价参数和材料快照，支持导入后继续编辑。

项目 JSON 包含当前页的栅格图像，而非整个多页 PDF。迁移后若要再次识别或切换原 PDF 的其他页面，需保留本地 `data/drawings` 中的原文件，或重新上传原 PDF。
